以下にペルソナAのペインポイントを5つ示す
# ペルソナA ペインポイント
- 相手の真意がわからない    発言の意味は理解できても、遠回しな拒否や暗黙の意図を読み取れない
- 暗黙の期待・ルールがわからない    明確な指示がなく、何をどこまでやればよいのかわからない
- 適切なコミュニケーション方法がわからない    報連相、根回し、反対意見の伝え方など、状況に応じた対応を判断できない
- 失敗の原因がわからない    上司から注意されても、何が問題で次にどう改善すべきかわからない
- 安心して練習・相談できる場所がない    職場で失敗するリスクを避けながら、実践的な対応力を身につける機会がない

# ペルソナB ペインポイント
- やりたいものづくりができない    メーカーに入社したが、業務がパワポ作成中心で、手を動かす機会がない
- ハードウェアの知識が足りず焦る    ドメイン知識の不足で業務についていけず、海外出張や成果にも手が届かない
- 自分で進める道筋を作れない    マイルストーンが設定されておらず、自走して進めるのが苦手
- 専門領域の違いで認識がずれる    自分は電気電子、周囲は機械系が多く、お互いの既知・未知を把握できないまま話して困る
- 気軽に試して失敗できる場所がない    ハードウェアは壊しそうで抵抗があり、すぐ作って試せる環境がない

# ペルソナB 背景・志向
- 人との交流や、異なる文化・国の人の話を聞くことにやりがいを感じる
- 海外出張などの未経験の体験をしたい
- 情報系の「すぐ作って試せる」環境に憧れがある
