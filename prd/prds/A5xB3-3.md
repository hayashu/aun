# PRD: プロジェクト管理の経験者が週1回のオフィスアワーで、評価と切り離して進め方の相談に乗る社内の進め方相談窓口（A5xB3-3）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A5×B3（安心して練習・相談できる場所がない × 自分で進める道筋を作れない）の版3。方向性は「場・仕組みを変える（チーム／組織向け）」。版1は個人のミニプロジェクト練習帳、版2は同期との進捗バディを扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門ではマイルストーンを決めずに仕事が渡されることが多く、進め方は担当者に任されている。

仕事の進め方に困ったとき、相談できるのは直属の上司だけである。しかし上司は評価者でもあるので、**進め方がわからないと相談すると、計画性がないと評価されそうで相談しにくい**。社内には、大きなプロジェクトを何度も回してきたプロジェクト管理の経験者がいるが、若手が個人の仕事の進め方を相談できる経路はない。進め方の相談ができないまま、若手は一人で抱え込む。

**誤解の実態**: Bさんは評価資料の作成で区切りを作れず、締め切り直前まで遅れに気づかなかった。上司に早めに相談すればよかったが、計画性がないと思われるのが怖くて相談できなかった。Aさんも、調査の仕事をどう区切ればよいか迷っていたが、相談相手がいなかった。社内のプロジェクト管理部門には、仕事の区切り方を教えるのが得意なベテランがいた。そのベテランは、若手の相談に乗りたいと思っていたが、相談の窓口はなかった。

**気づきの実態**: 問題は個人の相談の勇気ではなく、**評価と切り離された、進め方の相談先がない**ことである。評価者ではない、進め方の専門家に相談できる窓口があれば、若手は安心して相談できる。相談の中で、区切りの作り方や見積もりの仕方を具体的に学べる。

**練習機会の実態**: 社内のプロジェクト管理の研修は年に一度の座学で、個人の仕事の相談はできない。プロジェクト管理部門は大きなプロジェクトの支援が中心で、個人の相談は受けていない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げ、職場側の「ローコンテキスト化」を対策に掲げている。若手が仕事の進め方を相談できる窓口の有無は、社内で把握されていない。

## Goals / Non-Goals

**Goals**

- 若手が、評価と切り離して進め方を相談できる（月あたりの相談件数を効果指標とする）
- 相談が、具体的な区切りの作り方につながる（相談のあと、本人が仕事を区切りに分けて進めた割合を効果指標とする）
- 一人で抱え込む時間が減る（「進め方に困ったときに相談できる場所がある」の自己申告を効果指標とする）

**Non-Goals**

- 上司への報告の代替（窓口は進め方の相談に限り、業務の報告は上司に行う）
- 相談内容の上司への共有（相談の内容は本人が望まない限り上司に伝えない）
- 仕事の代行（相談員は進め方を一緒に考えるだけで、仕事を代わりにしない）
- 個人の練習帳（版1）、同期との進捗バディ（版2）の範囲

## Proposed Solution / Feature Description

社内に**週に1回、2時間の「進め方相談のオフィスアワー」**を設け、その運営をWebで支える仕組みを提供する。相談員は、プロジェクト管理の経験者が持ち回りで務める。若手は、相談したい仕事の概要と困っていることを書いて、20分の枠を予約する。相談の内容は、本人が望まない限り上司に伝えない。

**主要な構成要素**:

- **相談員の登録** — プロジェクト管理の経験者が、相談員として登録し、担当するオフィスアワーの日を選ぶ
- **相談の予約** — 若手が、仕事の概要（中身は伏せてよい）、締め切り、困っていること（区切り方、見積もり、優先順位など）を書いて、20分の枠を予約する
- **相談のまとめ** — 相談のあと、相談員が「この仕事の区切り方の例」と「次にやること」を一行ずつ書いて本人に渡す
- **上司に伝えない** — 相談の記録は本人と相談員だけが見られる。本人が望めば、上司に共有できる
- **よくある相談** — 相談の内容を一般化し、「よくある相談と区切り方の例」として社内に公開する。同じ悩みを持つ人が、予約の前に読める

## User Stories

- **US-001 上司に進め方を相談すると評価に響きそうな問題**
  利用者（Bさん）は、評価者ではない相手に、仕事の進め方を相談したい。それにより、一人で抱え込んで締め切り直前まで遅れに気づかない事態を避けたい。
  背景: 現状は進め方の相談先が上司しかなく、計画性がないと思われそうで相談できない。

- **US-002 仕事の区切り方を具体的に学ぶ機会がない問題**
  利用者（Aさん）は、自分の仕事を例に、区切り方を具体的に教わりたい。それにより、研修の座学では身につかなかった進め方を、実際の仕事で使えるようにしたい。
  背景: 現状はプロジェクト管理の研修が座学で、自分の仕事にどう当てはめればよいかわからない。

- **US-003 若手の相談に乗りたいのに窓口がない問題**
  利用者（プロジェクト管理部門のベテラン）は、若手の仕事の進め方の相談に乗りたい。それにより、自分の経験を若手に伝えたい。
  背景: 現状は個人の相談を受ける窓口がない。

## Open Questions

- 相談員が週に2時間を確保できるか。相談員の部署の理解が必要になる
- 相談の内容を上司に伝えないことが、組織として受け入れられるか
- 相談が特定の時期に集中した場合、どう対応するか
- **モックで確かめたいこと**: 若手が仕事の概要と困っていることを書いて予約するまでの流れが、気軽にできると感じられるか
- **モックで確かめたいこと**: 相談のまとめの「区切り方の例」を見て、本人が自分の仕事に当てはめられると感じられるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **相談員が集まらない** — 経験者が忙しい → オフィスアワーが開けない → 窓口が形だけになる。軽減: 月に1回から始め、相談員を数人の持ち回りにする
- **上司との関係** — 上司に伝えない相談 → 上司が不信を抱く → 組織の中で問題になる。軽減: 窓口は進め方の相談に限ることを明記し、制度の存在は管理職に説明する
- **仕事の代行の期待** — 相談員に仕事を任せようとする → 相談員が困る → 窓口の目的からずれる。軽減: 相談は区切り方を一緒に考えるまでとし、相談のまとめを本人が実行する形にする
- **情報の扱い** — 仕事の内容を他部署の人に話す → 情報の扱いに問題が出る。軽減: 仕事の中身は伏せてよいことを示し、相談員にも守秘を求める
