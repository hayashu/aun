# PRD: 資料の型を1枚フォーマットで明文化し、浮いた時間をものづくり枠に回すチームの資料ダイエット（A2xB1-3）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A2×B1（暗黙の期待・ルールがわからない × やりたいものづくりができない）の版3。方向性は「場・仕組みを変える（チーム／組織向け）」。版1は作成者個人の型のチェック、版2は依頼者と作成者の合意を扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門の業務の多くは会議資料のパワーポイント作成で、2人とも、本当はものづくりにもっと時間を使いたいと思っている。

部門の資料には、**誰も書いていない型**がある。結論は1枚目、数字には前回比、部長向けは3枚以内、色は2色まで。この型は、長くいる社員が過去の資料から自然に覚えたもので、新しく来た人は作り直しを繰り返して覚えるしかない。しかも、型を覚えたところで資料作成の量は減らず、ものづくりの時間は戻ってこない。

**誤解の実態**: Bさんは評価結果の報告資料を、課長の指摘で3回作り直した。部長向けは3枚、結論は先頭、前回比を入れる、という型を、一つずつ指摘されて知った。Aさんも同じ週に、色の使い方で作り直した。部門全体では、週の定例会議のために毎週十数本の資料が作られており、そのうち何本が作り直しになっているかは誰も数えていない。部門長は「若手にものづくりの機会を」と言うが、資料の量はそのままである。

**気づきの実態**: 問題は個人が型を知らないことだけではない。**型が暗黙のままであることと、資料の量が多すぎること**の二つが重なっている。型を明文化すれば作り直しは減る。しかし、浮いた時間の使い道を決めなければ、別の資料作成で埋まるだけである。

**練習機会の実態**: 部門の資料テンプレートは色とロゴを決めているだけで、構成の決まりはない。資料の量を見直す場もない。定例会議は毎週同じ形式で、資料が本当に必要かを問う人はいない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げ、職場側の「ローコンテキスト化」を対策に掲げている。部門の資料作成にかかる総時間は測られていない。

## Goals / Non-Goals

**Goals**

- 資料の作り直しが減る（定例会議の資料のうち、差し戻しがあった割合を効果指標とする）
- 資料作成の総時間が減る（チームの週あたりの資料作成時間の合計を効果指標とする）
- 浮いた時間が、ものづくりに使われる（チームのものづくり枠として確保された時間を効果指標とする）

（一つめは型の明文化で、二つめは資料の量の見直しで届く。三つめは、浮いた時間を確保する取り決めがなければ届かない）

**Non-Goals**

- 資料の自動作成（資料の量を減らすことが目的で、作成を自動化して量を保つことではない）
- 個人の資料作成時間の評価（遅い人を責める道具にしない）
- 会議そのものの廃止（会議は残し、資料の形を変える）
- 個人の型の学習（版1）、依頼者との合意（版2）の範囲

## Proposed Solution / Feature Description

チームの資料の型を**1枚フォーマット**として明文化し、定例会議の報告をこの1枚に統一する。あわせて、チームの資料作成時間を週ごとに記録し、減った時間を**ものづくり枠**としてカレンダーに確保する。型を見えるようにすることと、浮いた時間を守ることを、一つの仕組みにする。

**主要な構成要素**:

- **1枚フォーマット** — 結論、数字（前回比つき）、課題、次の一手の4欄からなる1枚の書式。チームの暗黙の型を、この書式に埋め込む。新しく来た人も、書式を埋めれば型を守れる
- **型の説明書** — 書式の各欄について、「なぜこの順序か」「どこまで書くか」を短く説明する。暗黙だった理由を言葉にする
- **資料の棚卸し** — 定例会議で使われる資料を一覧にし、それぞれ「1枚に置き換えられる／口頭で済む／このまま必要」を、チームで月に一度判断する
- **作成時間の記録** — チームの資料作成時間を週ごとに集計する。個人別には出さない
- **ものづくり枠** — 減った時間をもとに、チームの各メンバーに週何時間かのものづくり枠をカレンダーで確保する。枠の中では資料作成を頼まない取り決めにする

## User Stories

- **US-001 暗黙の型を作り直しで覚える問題**
  利用者（Bさん）は、チームの資料の型を、最初から書式として知りたい。それにより、3回作り直して型を一つずつ覚える事態を避けたい。
  背景: 現状は型が誰の頭の中にもあり、文書にはない。作り直しのたびに、ものづくりに使うはずの時間が削られる。

- **US-002 型を覚えても資料の量が減らない問題**
  利用者（Aさん）は、資料作成で浮いた時間を、ものづくりに使いたい。それにより、作り直しが減っても別の資料で時間が埋まる状態を変えたい。
  背景: 現状は浮いた時間の使い道が決まっておらず、すぐに別の依頼で埋まる。

- **US-003 資料の量が見えない問題**
  利用者（部門長）は、チームが資料作成にどれだけ時間を使っているかを知りたい。それにより、「若手にものづくりの機会を」という方針を、実際の時間で裏付けたい。
  背景: 現状は資料作成の総時間が測られておらず、方針と実態のずれが見えない。

## Open Questions

- 1枚フォーマットで足りない報告（詳細な評価データなど）をどう扱うか。添付として残すか
- ものづくり枠を守る取り決めが、急ぎの依頼で破られないか
- 作成時間の記録を、メンバーが正直に続けるか
- **モックで確かめたいこと**: 1枚フォーマットを埋める画面で、型の説明を見ながら迷わず書けるか
- **モックで確かめたいこと**: チームの作成時間の減少と、ものづくり枠の確保が並んで見えたとき、「時間が戻ってきた」と感じられるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **フォーマットの形骸化** — 1枚に収まらない → 添付資料が増える → 結局作成時間は減らない。軽減: 添付の枚数にも上限を設け、棚卸しで見直す
- **ものづくり枠の侵食** — 急ぎの依頼が入る → 枠が資料作成に使われる → 制度が形だけになる。軽減: 枠が使われなかった週を振り返りで共有し、部門長が理由を確かめる
- **記録の負担** — 作成時間を記録する → 手間が増える → 記録が止まる。軽減: 資料1本ごとに時間帯を選ぶだけの入力にする
- **特定の人のための仕組みと見られる** — 外国籍社員や若手への配慮に見える → 周囲が反発する → 導入が止まる。回避: チーム全員の資料作成時間を減らす取り組みとして導入する
