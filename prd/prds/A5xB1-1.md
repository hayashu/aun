# PRD: 業務につながる小さなものづくりを、自分のペースで練習して記録する練習プラン帳（A5xB1-1）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A5×B1（安心して練習・相談できる場所がない × やりたいものづくりができない）の版1。方向性は「当事者の行動を支える（個人向けツール）」。版2は社内の作り手との1対1の相談、版3は社内ものづくりサークルを扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門の業務の多くは会議資料のパワーポイント作成で、実際に手を動かして作る機会は少ない。

2人とも、ものづくりの力を身につけたいと思っている。しかし、**業務の外で安心して練習できる場所がない**。職場の試作室は業務のためのもので、練習に使うのは気が引ける。自宅で練習しようにも、何を作れば業務の力につながるのかがわからない。思いつきで電子工作キットを買っても、業務とのつながりが見えず、途中でやめてしまう。練習したことを誰にも見せる場がないので、上達しているのかもわからない。

**誤解の実態**: Bさんは、ものづくりの力をつけようと、通販で電子工作のキットを3つ買った。1つ目は完成させたが、2つ目は途中で止まり、3つ目は箱を開けていない。業務で使う技術（電源回路、ノイズ対策、筐体への組み込み）とつながっている気がしなかったからである。Aさんは、3Dプリンタで治具を作る練習をしたいと思っていたが、何から始めればよいかわからず、半年たっても始めていなかった。2人とも、練習の場と道筋がないことで、ものづくりから遠ざかっていた。

**気づきの実態**: 練習が続かない理由は、意欲の不足ではなく、**練習が業務とつながっていないこと**と、**練習の記録が残らないこと**にある。業務で使う技術から逆算した小さな課題を、段階的に並べれば、練習は業務の力につながる。記録を残せば、上達が見え、業務でのものづくりの提案材料にもなる。

**練習機会の実態**: 社内の技術研修は年に数回の集合研修で、自分のペースで練習する仕組みはない。市販のキットは趣味向けで、業務とのつながりは示されていない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。若手が業務外でものづくりを練習している状況は、部門では把握されていない。

## Goals / Non-Goals

**Goals**

- 業務につながる練習を、続けられる（練習プランの課題のうち、完了したものの割合を効果指標とする）
- 練習が業務の力につながっていると感じられる（「練習が業務に役立っている」の自己申告を効果指標とする）
- 練習の記録が、業務でのものづくりの提案材料になる（練習の記録を使って業務の提案をした件数を効果指標とする）

**Non-Goals**

- 教材やキットの販売（課題の道筋を示すだけで、物は売らない）
- 練習の採点や他人との比較（自分のペースで進めることを目的にする）
- 社内の作り手との相談（版2）、社内ものづくりサークル（版3）の範囲

## Proposed Solution / Feature Description

業務で使う技術（電源回路、ノイズ対策、筐体への組み込み、治具づくりなど）を選ぶと、**その技術につながる小さな課題を、段階的に並べた練習プランを示す**個人向けWebツールを提供する。課題ごとに、必要な部品と道具、所要時間の目安、業務とのつながりが書かれている。終わった課題は写真と一行のメモで記録する。

**主要な構成要素**:

- **技術の選択** — 業務で身につけたい技術を一つ選ぶ。いまの業務で困っていることから選ぶこともできる
- **段階的な課題** — 選んだ技術につながる課題を、3〜5段階で並べる（例: ノイズ対策＝①ノイズを測る、②コンデンサで減らす、③配線で減らす、④筐体で減らす）。各課題に、所要時間の目安と、業務のどの場面に役立つかを書く
- **必要なもの** — 課題ごとに、必要な部品と道具、費用の目安を示す。社内で借りられる道具には印を付ける
- **練習の記録** — 終わった課題を、写真と一行のメモで記録する。うまくいかなかった課題も記録できる
- **練習のまとめ** — 記録した課題を、技術ごとにまとめて見られる。業務でのものづくりを提案するときに、練習の成果として示せる

## User Stories

- **US-001 練習が業務につながらず続かない問題**
  利用者（Bさん）は、業務で使う技術につながる練習を、段階的に進めたい。それにより、キットを買っても途中でやめてしまう状態を変えたい。
  背景: 現状は思いつきでキットを買い、業務とのつながりが見えずにやめてしまう。ものづくりの力がつかないまま、資料作成の業務が続く。

- **US-002 何から始めればよいかわからない問題**
  利用者（Aさん）は、身につけたい技術の最初の一歩を知りたい。それにより、半年たっても始められない状態を変えたい。
  背景: 現状は練習の道筋がなく、何から手をつければよいかわからない。

## Open Questions

- 業務につながる課題を、技術ごとにどこまで用意できるか。課題の質が練習の続きやすさを左右する
- 自宅での練習に必要な道具の費用を、本人が負担できるか。社内で道具を借りられる仕組みが必要か
- **モックで確かめたいこと**: 技術を選んで段階的な課題が並んだとき、「これなら続けられそう」と感じられるか
- **モックで確かめたいこと**: 練習のまとめを見て、業務での提案に使えそうだと感じられるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **続かない** — 一人で練習する → 途中で止まる → 記録が途絶える。軽減: 課題を1回1〜2時間で終わる大きさにし、版3のサークルと組み合わせる
- **費用の負担** — 部品や道具を自分で買う → 費用がかさむ → 練習をやめる。軽減: 社内で借りられる道具を示し、費用の少ない課題から並べる
- **安全上の事故** — 自宅で電気の工作をする → 事故が起きる → 本人が怪我をする。軽減: 課題は低電圧のものに限り、安全上の注意を各課題に表示する
- **業務外の負担** — 業務時間外の練習を求められていると感じる → 負担になる → かえって意欲が下がる。軽減: 練習は本人の希望で行うものであり、業務の評価に関係しないことを明記する
