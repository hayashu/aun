# PRD: 業務の外の小さな個人プロジェクトで「計画→実行→振り返り」を一周練習するミニプロジェクト練習帳（A5xB3-1）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A5×B3（安心して練習・相談できる場所がない × 自分で進める道筋を作れない）の版1。方向性は「当事者の行動を支える（個人向けツール）」。版2は同期との進捗バディ、版3は社内の進め方相談窓口を扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門ではマイルストーンを決めずに仕事が渡されることが多く、進め方は担当者に任されている。

Bさんは、マイルストーンが決まっていないと、自分で区切りを作って進めるのが苦手である。この力を伸ばしたいと思っているが、**安心して練習できる場所がない**。業務で練習すれば、失敗したときに締め切りに遅れ、上司や同僚に迷惑がかかる。計画の立て方の本を読んでも、実際にやってみないと身につかない。業務の外で、失敗しても誰にも迷惑がかからない小さな題材で、計画を立てて、実行して、振り返る経験を積む場がほしい。

**誤解の実態**: Bさんは、計画の立て方を身につけようと、プロジェクト管理の本を読んだ。WBS（作業の分解）やマイルストーンの考え方は理解したが、実際の業務で使おうとすると、どこから手をつければよいかわからなかった。業務で試して失敗すると締め切りに遅れるので、結局いつもの進め方に戻った。Aさんも、業務の進め方を改善したいと思っていたが、業務の中で新しい方法を試すのはためらわれた。2人とも、練習する場がないまま、計画を立てる力が伸びなかった。

**気づきの実態**: 計画を立てる力は、計画→実行→振り返りを何周も回すことで身につく。業務では一周に数週間から数か月かかり、失敗の代償も大きい。業務の外の小さな題材（2週間で終わる個人のものづくり、資格の勉強、自宅の片付けなど）なら、一周を短く回せて、失敗しても誰にも迷惑がかからない。2人には、そうした練習の道筋がない。

**練習機会の実態**: プロジェクト管理の研修はあるが、座学が中心で、自分で一周を回す経験にはならない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。若手が計画を立てる力を練習する機会の有無は、部門では把握されていない。

## Goals / Non-Goals

**Goals**

- 計画→実行→振り返りを、安心して何周も練習できる（完了したミニプロジェクトの数を効果指標とする）
- 振り返りから、自分の計画の癖を知る（ミニプロジェクトのうち、振り返りで「次に変えること」を一つ以上書けた割合を効果指標とする）
- 練習で身につけた進め方を、業務に持ち込める（「練習した進め方を業務で使った」の自己申告を効果指標とする）

**Non-Goals**

- 業務のプロジェクト管理（練習は業務の外の題材で行う）
- 練習の成果の評価（自分のための練習で、他人に見せる必要はない）
- 同期との進捗の見せ合い（版2）、社内の相談窓口（版3）の範囲

## Proposed Solution / Feature Description

業務の外の小さな題材で、**2週間で一周する「ミニプロジェクト」を、計画→実行→振り返りの順に進める**個人向けWebツールを提供する。題材を選ぶと、ゴールの決め方、区切りへの分け方、振り返りの問いが順に示される。一周終わるたびに、自分の計画の癖がたまっていく。

**主要な構成要素**:

- **題材の選択** — 2週間で終わる小さな題材を選ぶ（個人のものづくり、資格の勉強の一章、自宅の片付け、料理の練習など）。業務とは関係ないものを選ぶことを勧める
- **ゴールと区切り** — ゴールを一文で書き、3〜4個の区切りに分ける。区切りごとに、終わったと判断する基準と日付を書く。分け方の例を示す
- **毎日の一言** — 毎日、その日に進んだことを一行書く。書くだけで、進み具合が見える
- **振り返りの問い** — 2週間たったら、「ゴールに届いたか」「どの区切りで予定とずれたか」「次に変えること」の3つの問いに答える
- **計画の癖** — 複数のミニプロジェクトの振り返りをまとめ、「最初の区切りが大きすぎる」「途中で区切りを見直さない」のような癖を示す
- **業務への持ち込み** — 振り返りで見つけた癖と対策を、業務の仕事を受けたときに見返せるようにまとめる

## User Stories

- **US-001 業務で計画の練習をすると失敗の代償が大きい問題**
  利用者（Bさん）は、失敗しても誰にも迷惑がかからない題材で、計画を立てて実行し、振り返る練習をしたい。それにより、自分で区切りを作って進める力を身につけたい。
  背景: 現状は計画の練習を業務でしかできず、失敗すると締め切りに遅れる。だから新しい進め方を試せず、いつもの進め方に戻る。

- **US-002 本で読んだ計画の立て方を実際に使えない問題**
  利用者（Aさん）は、本で読んだ計画の立て方を、小さな題材で実際に試したい。それにより、業務で使う前に、自分に合う進め方を見つけたい。
  背景: 現状は本の知識を業務で試すのがためらわれ、身につかない。

## Open Questions

- 業務の外の題材で練習した進め方が、業務に役立つか。題材の性質が違いすぎないか
- 業務の外で練習を続ける時間と意欲があるか
- **モックで確かめたいこと**: 題材を選んでゴールと区切りを決めるまでが、10分以内で終わるか
- **モックで確かめたいこと**: 振り返りの問いに答えたあと、計画の癖を見て「次はこう変えよう」と思えるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **続かない** — 業務の外の練習 → 忙しくなるとやめる → 一周を回せない。軽減: 題材を2週間で終わる小さなものに限り、毎日の一言は一行だけにする
- **業務との距離** — 題材が業務と違いすぎる → 練習が業務に役立たない → 意欲が下がる。軽減: 業務への持ち込みの画面で、練習で見つけた癖を業務の場面に当てはめる問いを示す
- **業務外の負担** — 業務時間外の練習を求められていると感じる → 負担になる → かえって疲れる。軽減: 練習は本人の希望で行うものであり、業務の評価に関係しないことを明記する
- **自己批判の強化** — 振り返りでずれが見える → 自分を責める → 練習をやめる。軽減: 振り返りの問いを「次に変えること」で終わらせ、前向きな形にする
