# PRD: 「壊してよい」がはっきりした部署の試作棚と練習用ジャンク機材の貸出制度（A1xB5-3）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A1×B5（相手の真意がわからない × 気軽に試して失敗できる場所がない）の版3。方向性は「場・仕組みを変える（チーム／組織向け）」。版1は許可の言葉を読む個人の練習、版2は機材ごとの許可の範囲の明示を扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門には試作機や評価ボード、測定器があるが、若手が自由に触れる機会は少ない。

部門には、使い終わった試作品や旧型の評価ボードが棚に眠っている。誰のものか、触ってよいのか、捨ててよいのかは決まっていない。先輩に聞けば「好きにしていいんじゃない」と言われるが、**その言葉が本当に自由を意味するのかは誰にもわからない**。結果として、若手が壊すことを前提に試せる機材は、部門に一つもない状態になっている。

**誤解の実態**: Bさんは棚にあった旧型の評価ボードで、部品の付け替えを練習したいと考えた。近くの先輩に聞くと「たぶん誰も使ってないから、好きにしていいんじゃない」と言われた。Bさんは「たぶん」が気になり、持ち主を探したが見つからず、結局触らなかった。Aさんは別の試作品を「誰も使っていない」と聞いて分解したところ、品質部門が不具合の再現用に保管していたものだとわかり、問題になった。この件のあと、部門では棚のものに誰も手を出さなくなった。

**気づきの実態**: 問題は個人の読み取りの力ではない。**「壊してよいもの」と「壊してはいけないもの」の区別が、部門として決まっていない**ことが原因である。区別がない限り、許可の言葉はすべて「たぶん」になり、慎重な人は触らず、触った人はときどき外す。どちらも、試して学ぶ機会を失う。

**練習機会の実態**: 社内の技術研修には実習があるが、決められた手順をなぞるもので、自分で試して壊す経験にはならない。自宅で試すには、部品と測定器をそろえる費用がかかる。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げ、職場側の「ローコンテキスト化」を対策に掲げている。部門の棚に眠る試作品の数と、その扱いは記録されていない。

## Goals / Non-Goals

**Goals**

- 若手が壊すことを前提に試せる機材が、部門に用意される（試作棚に登録された機材の数を効果指標とする）
- 若手が実際に手を動かして試す機会が増える（試作棚からの貸出件数を効果指標とする）
- 棚のものを誤って使ってしまうトラブルが減る（保管品を誤って使った件数を効果指標とする）

**Non-Goals**

- 研修カリキュラムの作成（試作棚は自由に試す場であり、決められた手順をなぞる場ではない）
- 試した結果の評価（何を作ったかを評価すると、失敗を避けるようになる）
- 全社の資産管理の見直し（一つの部門の棚から始める）
- 個人の練習（版1）、機材ごとの許可の明示（版2）の範囲

## Proposed Solution / Feature Description

部門に**「壊してよい」がはっきりした試作棚**をつくり、その貸出をWebで管理する仕組みを提供する。棚に入れる機材は、持ち主と上長が「壊してよい」と確認したものだけで、登録時に確認者の名前が残る。棚の外にある機材には「保管中」の札を付け、許可の言葉を推測する必要をなくす。

**主要な構成要素**:

- **棚への登録** — 使い終わった試作品や旧型の機材を、持ち主が登録する。上長が「壊してよい」と承認したものだけが棚に並ぶ。承認者の名前を表示することで、「たぶん」をなくす
- **保管中の札** — 棚に入れないものには「保管中（理由・保管者）」の札を付ける。理由は「不具合の再現用」「顧客への返却予定」など選択式にする
- **貸出と返却** — 若手は棚の一覧から機材を選び、貸出を記録する。返却時に、壊れた／部品を使い切ったも、問題のない返し方として選べる
- **試したことのメモ** — 返却時に、何を試したかを一行で残せる（任意）。他の若手が、同じ機材で何ができるかを知る手がかりになる
- **棚の一覧** — 部門長が、棚の機材数と貸出件数を見られる。棚が空なら、登録を呼びかける
- **部品の補充** — 練習用の部品（抵抗、コネクタなど）を棚に備え、補充を申請できる。第2段階に置き、現時点のプロトタイプには入っていない

## User Stories

- **US-001 「たぶん好きにしていい」で手を出せない問題**
  利用者（Bさん）は、壊してよい機材を、誰にも確かめずに見つけたい。それにより、許可の言葉の「たぶん」を推測して結局何もできない事態を避けたい。
  背景: 現状は棚の機材の扱いが決まっておらず、許可の言葉はすべて曖昧になる。慎重な人ほど、試す機会を失い続ける。

- **US-002 保管品を誤って使ってしまう問題**
  利用者（Aさん）は、触ってはいけない機材が、見てすぐわかるようにしたい。それにより、「誰も使っていない」という言葉を信じて保管品を分解する事態を避けたい。
  背景: 現状は保管品と不要品の区別がなく、聞いた言葉に頼るしかない。外すと問題になり、その後は誰も棚に触れなくなる。

- **US-003 部門に試せる場がない問題**
  利用者（部門長）は、若手が壊すことを前提に試せる機材を、部門として用意したい。それにより、資料作成だけで技術の感覚が育たない状態を変えたい。
  背景: 現状は眠っている機材があるのに、扱いが決まっていないため使われない。

## Open Questions

- 上長が「壊してよい」の承認を出すことに、責任を感じてためらわないか
- 試作棚に十分な数の機材が集まるか。集まらなければ、仕組みだけがあって中身がない
- 壊したときに、安全上の危険（電源、バッテリー）はないか。棚に入れる機材の条件をどう決めるか
- **モックで確かめたいこと**: 棚の一覧で、「壊してよい」と承認者がひと目でわかり、安心して借りられるか
- **モックで確かめたいこと**: 返却時に「壊れた」を選ぶことが、気まずさなくできるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **棚が空になる** — 登録が面倒 → 機材が集まらない → 仕組みが形だけになる。軽減: 年度末の片付けの時期に、登録を呼びかける
- **安全上の事故** — 壊してよい機材で試す → 電源やバッテリーで事故が起きる → 制度が止められる。軽減: 棚に入れる機材の安全条件を決め、危険のあるものは登録できないようにする
- **承認者の負担** — 承認を求められる → 上長が責任を恐れる → 承認が出ない。軽減: 承認は「部門として不要」の確認に限り、壊れた結果の責任は問わないことを明記する
- **評価への転用** — 貸出件数や試したことのメモが残る → 評価に使われる → 義務的になる。軽減: 個人別の貸出件数を集計せず、評価に使わない方針を明記する
