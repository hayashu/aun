# PRD: 昼休みと終業後に、部署を問わず集まって作れる社内ものづくりサークルの運営キット（A5xB1-3）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A5×B1（安心して練習・相談できる場所がない × やりたいものづくりができない）の版3。方向性は「場・仕組みを変える（チーム／組織向け）」。版1は個人の練習プラン、版2は社内の作り手との1対1の相談を扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門の業務の多くは会議資料のパワーポイント作成で、実際に手を動かして作る機会は少ない。

社内には、ものづくりをしたい人が部署をまたいでいる。しかし、**業務の外で集まって作る場がない**。一人で練習すると続かず、相談相手もいない。職場の試作室は業務のためのもので、練習に使うのは気が引ける。Bさんは、研究室時代に研究そのものより同期や先輩との交流が楽しかったと感じており、一人で黙々と練習するより、人と一緒に作るほうが続くと思っている。

**誤解の実態**: Bさんは電子工作のキットを一人で始めたが、途中でやめてしまった。Aさんも3Dプリンタで治具を作る練習をしたかったが、一人では始められなかった。同じ工場には、昼休みに一人で基板をいじっている試作部門の社員や、休日に3Dプリンタで作品を作っている生産技術部門の社員がいた。しかし、お互いに存在を知らず、それぞれ一人で作っていた。もし集まる場があれば、BさんもAさんも、作り手と一緒に練習を続けられたはずである。

**気づきの実態**: 問題は個人の意欲ではなく、**部署をまたいで集まって作る場がない**ことである。場があれば、一人では続かない練習も、人と一緒なら続く。その場で、自然に相談もできる。業務の評価と関係のない場なので、失敗しても気にならない。

**練習機会の実態**: 社内には運動や趣味のサークルはあるが、ものづくりのサークルはない。会議室や試作室を業務外に使う手続きも決まっていない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げ、職場側の「ローコンテキスト化」を対策に掲げている。業務外で社員が交流しながら学ぶ場の有無は、社内で把握されていない。

## Goals / Non-Goals

**Goals**

- 部署をまたいでものづくりに集まる場ができる（月あたりのサークルの活動回数と参加者数を効果指標とする）
- 一人では続かなかった練習が続く（サークルの参加者のうち、3か月以上続けて参加した割合を効果指標とする）
- 作る中で、自然に相談ができる（「サークルで相談できる相手ができた」の自己申告を効果指標とする）

**Non-Goals**

- 業務としてのものづくり（サークルは業務外の活動で、業務の成果は求めない）
- 参加の義務化（参加は自由とし、参加しないことで不利にならない）
- 個人の練習プラン（版1）、1対1の相談（版2）の範囲

## Proposed Solution / Feature Description

社内に**部署を問わず参加できるものづくりサークル**をつくり、その運営をWebで支えるキットを提供する。活動は昼休みの30分と、月に2回の終業後1時間。場所は会議室か、業務外に使ってよいと認められた試作室の一角。参加者は、作っているものを登録し、困っていることを書いておくと、詳しい参加者が声をかけられる。

**主要な構成要素**:

- **活動の予定** — 昼休みと終業後の活動日時と場所を一覧にする。参加したい回に印を付ける
- **作っているものの登録** — 参加者が、いま作っているもの（基板、治具、3Dプリント作品など）と、困っていることを一行で登録する
- **教えられることの登録** — 参加者が、教えられること（はんだ付け、3D設計、回路設計など）を登録する。困っていることと教えられることが合う人を示す
- **道具の一覧** — サークルで使える道具（はんだごて、テスタ、3Dプリンタなど）と、その置き場所、使い方の注意を一覧にする
- **作品の共有** — 完成した作品や途中経過を、写真と一行で共有する。他の参加者が一言を返せる

## User Stories

- **US-001 一人で練習しても続かない問題**
  利用者（Bさん）は、ものづくりの練習を、人と一緒に続けたい。それにより、一人で始めて途中でやめてしまう状態を変えたい。
  背景: 現状は一人で練習するしかなく、途中で止まる。人と一緒に作る場がない。

- **US-002 始めるきっかけがない問題**
  利用者（Aさん）は、作り手が集まる場に参加して、ものづくりを始めるきっかけを得たい。それにより、一人では始められなかった治具づくりを始めたい。
  背景: 現状は何から始めればよいかわからず、相談できる相手もいない。

- **US-003 一人で作っている作り手どうしが出会えない問題**
  利用者（試作部門の社員）は、社内でものづくりをしている人とつながりたい。それにより、一人で作るより楽しく、若手にも教えられるようにしたい。
  背景: 現状は社内の作り手どうしが存在を知らず、それぞれ一人で作っている。

## Open Questions

- 会議室や試作室を業務外に使うことを、会社が認めるか。安全管理の責任を誰が負うか
- 道具や材料の費用を誰が負担するか
- 昼休みや終業後の活動に、参加者が集まるか
- **モックで確かめたいこと**: 困っていることと教えられることが合う人が示される画面で、自然に声をかけたくなるか
- **モックで確かめたいこと**: 活動の予定と作っているものの一覧を見て、初めての人でも参加しやすいと感じられるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **参加者が集まらない** — 業務外の活動 → 忙しい人が参加しない → サークルが続かない。軽減: 昼休みの短い時間から始め、気軽に参加できる形にする
- **安全上の事故** — 業務外で道具を使う → 事故が起きる → 活動が禁止される。軽減: 道具の使い方の注意を一覧に載せ、電源や高電圧を使う作業は経験者と一緒に行うことを決める
- **一部の人の集まりになる** — 常連だけが集まる → 新しい人が入りにくい → 広がらない。軽減: 初めての人向けの回を月に一度設ける
- **業務の延長と見られる** — サークルが業務の一部と思われる → 参加が義務に感じる → 楽しさが失われる。軽減: 業務の評価と関係がないことを明記する
