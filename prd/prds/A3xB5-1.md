# PRD: 機材を壊したとき・試作が失敗したときの伝え方を、安全に練習できる失敗報告トレーナー（A3xB5-1）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A3×B5（適切なコミュニケーション方法がわからない × 気軽に試して失敗できる場所がない）の版1。方向性は「当事者の行動を支える（個人向けツール）」。版2は試す前の「やってみる宣言」、版3はチームの責めない失敗共有会を扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門には試作機や評価ボードがあるが、若手が自由に触れる機会は少ない。

Bさんは、ハードウェアを壊すことへの不安が強い。その不安の大きな部分は、**壊したときにどう伝えればよいかがわからない**ことにある。誰に、いつ、どの順で、どんな言葉で伝えれば、責められずに済むのか。伝え方がわからないので、壊すこと自体を避けるようになり、試すこと全体から遠ざかっている。Aさんも、失敗を報告したときの伝え方で以前に注意を受け、それ以来、試作に手を出すことをためらっている。

**誤解の実態**: Aさんは以前、評価ボードの電源を誤って逆につなぎ、部品を一つ焼いてしまった。どう伝えればよいかわからず、その日は誰にも言わずに帰った。翌日、先輩がボードの異常に気づき、Aさんに聞いた。Aさんが「昨日やってしまいました」と答えると、先輩は「壊したことより、すぐ言わなかったことが問題」と言った。Aさんは壊したことを責められたと感じ、それ以来試作に手を出さなくなった。Bさんはこの話を聞いて、壊したときの怖さをさらに強く感じるようになった。

**気づきの実態**: 先輩が問題にしたのは、壊したことではなく、伝え方とタイミングだった。すぐに、何が起きたか、いまどうなっているか、何をしたかを伝えれば、多くの場合は「次から気をつけて」で済む。しかし2人はこの伝え方を知らず、知らないから怖く、怖いから試さない。伝え方を練習する場があれば、壊すことへの怖さの一部は小さくなる。

**練習機会の実態**: 失敗の報告を練習する機会はない。実際に壊したときが初めての報告になり、そのときは動揺していて、うまく伝えられない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。若手が失敗を恐れて試作を避けている状況は、部門では測られていない。

## Goals / Non-Goals

**Goals**

- 失敗したときに、すぐに報告できるようになる（実際に失敗したとき、報告までにかかった時間の自己申告を効果指標とする）
- 失敗の報告が、先輩や上司に一度で伝わる（報告のあとに聞き返された項目の数の自己申告を効果指標とする）
- 壊すことへの怖さが和らぎ、試作に手を出せるようになる（「試作に手を出すことへの怖さ」の自己申告を効果指標とする）

**Non-Goals**

- 機材の操作方法や安全教育（既存の研修の領域。ただし安全上の緊急対応は既存の手順に従うことを示す）
- 失敗の責任の判断（誰の責任かを判定しない）
- 実際の報告の代行（練習の場であり、報告するのは本人である）
- 試す前の宣言（版2）、チームの失敗共有会（版3）の範囲

## Proposed Solution / Feature Description

試作の失敗の場面（部品を焼いた、ボードを落とした、測定器の設定を壊した）を示し、**本人が報告の言葉を先に書いてから、伝わりやすい報告の型と、相手の反応の例を返す**練習用Webツールを提供する。実際に壊す前に、壊したときの伝え方を安全な場所で練習しておく。

**主要な構成要素**:

- **失敗の場面** — 「評価ボードの電源を逆につなぎ、部品から煙が出た」のような場面を示す。本人の職場に近い場面を選べる
- **自分の報告を書く** — 本人が、誰に、いつ、どう伝えるかを先に書く。型を見る前に書かせることで、自分の癖に気づける
- **報告の型** — 書いたあとに、伝わりやすい型（すぐに・何が起きたか・いまの状態・自分がしたこと・相談したいこと）を示し、本人の報告と並べて比べる
- **相手の反応の例** — 本人の報告に対して、先輩や上司がどう反応しやすいかを例で示す。すぐに伝えた場合と、翌日伝えた場合の違いを示す
- **自分の報告の型** — 練習を重ねると、本人の言葉で書いた報告の型がたまる。実際に失敗したときに、すぐに見返せる
- **緊急時の案内** — 煙や発火など安全に関わる場面では、まず既存の安全手順に従うことを最初に表示する

## User Stories

- **US-001 壊したときの伝え方がわからず試作を避ける問題**
  利用者（Bさん）は、機材を壊したときにどう伝えればよいかを、壊す前に練習しておきたい。それにより、壊したときの怖さを小さくし、試作に手を出せるようになりたい。
  背景: 現状は失敗の伝え方を知らず、壊すこと自体を避ける。試す機会を自分から手放している。

- **US-002 すぐに言わなかったことで責められる問題**
  利用者（Aさん）は、失敗したときに、すぐに、伝わる形で報告できるようになりたい。それにより、壊したことより報告の遅れで責められる事態を避けたい。
  背景: 現状は動揺して報告を先延ばしにし、遅れたことで注意を受ける。注意を受けたあとは、試作から遠ざかる。

## Open Questions

- 失敗の場面を練習することが、かえって失敗への怖さを強めないか
- 相手の反応の例が、本人の職場の先輩や上司の実際の反応と合うか
- **モックで確かめたいこと**: 先に自分の報告を書いてから型と比べる順序で、本人が自分の癖に気づけるか
- **モックで確かめたいこと**: 相手の反応の例を見て、「すぐに伝えれば大丈夫」と怖さが和らぐか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **怖さの増幅** — 失敗の場面を繰り返し見る → 失敗の怖さを想像する → かえって試作を避ける。軽減: 反応の例では、すぐに伝えた場合の穏やかな反応を中心に示す
- **練習止まり** — 練習はできる → 実際の失敗で動揺して使えない → 行動が変わらない。軽減: 自分の報告の型をスマートフォンですぐ見返せるようにする
- **安全の軽視** — 報告の練習に気を取られる → 安全上の緊急対応を後回しにする → 事故が大きくなる。軽減: 安全に関わる場面では、既存の安全手順を最初に表示する
- **文化的な単純化** — 「日本の職場は失敗に厳しい」と一般化する → 偏見を強める。軽減: 反応の例は職場によって違うことを明記し、本人の職場の様子を書き足せるようにする
