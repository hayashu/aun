# PRD: 持ち主が「ここまで触ってよい」を明示する機材の触っていい度ラベル（A1xB5-2）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A1×B5（相手の真意がわからない × 気軽に試して失敗できる場所がない）の版2。方向性は「2人の間をつなぐ（コミュニケーション設計）」。版1は許可の言葉を読む個人の練習、版3は部署の試せる場の制度を扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門には試作機や評価ボード、測定器があるが、若手が自由に触れる機会は少ない。

機材を持つ先輩は、若手に試してほしいと思っている。だから「好きにいじっていいよ」と声をかける。しかし先輩の頭の中には、「この部品は替えがないから触らないでほしい」「電源電圧はここまで」のような**言葉にしていない条件**がある。先輩にとっては当然すぎて、言う必要を感じない。若手はその条件を読めず、触らないか、触って外すかのどちらかになる。

**誤解の実態**: 先輩はBさんに旧型の評価ボードを渡し、「好きにいじっていいよ」と言った。先輩の頭の中では、「部品の付け替えまで自由、ただしFPGAの書き換えは復旧が面倒なのでやめてほしい」という範囲だった。Bさんはどこまでが許されるのかわからず、ほとんど触らずに返した。先輩は興味がないのだと受け取り、次の機会にはBさんに声をかけなかった。Aさんは、別の先輩の測定器を「空いてたら使っていいよ」と言われて使い、予約表に書かなかったことで注意を受けた。

**気づきの実態**: 許可の範囲は、持ち主の頭の中にある。持ち主が言葉にしない限り、使い手は推測するしかない。持ち主は、自分の言葉に条件が足りないことに気づかない。使い手は、確かめると「信頼されていない」と受け取られるのではないかと心配して聞かない。**許可の形**に、範囲を書く場所がないことが問題である。

**練習機会の実態**: 機材の管理台帳はあるが、所在と校正日を記録するためのもので、「誰がどこまで触ってよいか」は書かれていない。貸し借りは口頭で行われ、条件は残らない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。機材の貸し借りで、条件の行き違いがどれだけ起きているかは測られていない。

## Goals / Non-Goals

**Goals**

- 若手が許可された機材を、触らないまま返す件数が減る（貸し出した機材のうち、使い手が実際に試した割合を効果指標とする）
- 許可の範囲の行き違いによる注意やトラブルが減る（貸し借りで条件の行き違いが起きた件数を効果指標とする）
- 持ち主が許可の範囲を言葉にする手間が小さい（ラベルを付けるのにかかった時間を効果指標とする）

**Non-Goals**

- 機材の資産管理・校正管理の置き換え（既存の台帳はそのまま使う）
- 機材の使用の監視（誰がいつ使ったかを細かく記録すると、使い手が萎縮する）
- 許可の言葉を読む個人の練習（版1）、部署の試せる場の制度（版3）の範囲

## Proposed Solution / Feature Description

機材ごとに、持ち主が**「触っていい度」を段階で選んで付けるラベル**を提供する。段階は「見るだけ／電源を入れて測ってよい／部品を付け替えてよい／分解・改造してよい」の四つ。段階に加えて、「これだけはやめてほしいこと」を一行書ける。ラベルは機材に貼るQRコードから見られ、貸し出すときに持ち主がスマートフォンで1分以内に設定できる。

**主要な構成要素**:

- **触っていい度の段階** — 持ち主は四つの段階から一つを選ぶ。選ぶだけで、使い手は範囲がわかる
- **やめてほしいこと** — 段階の中でも例外がある場合に、一行で書く（例:「FPGAの書き換えはしないでください」）
- **使う前の手順** — 予約表への記入、使ったあとの片付けなど、使う前に知っておくべき手順を選択式で付ける
- **使い手からの質問** — 使い手は、ラベルを見たうえでわからないことがあれば、その場で持ち主に質問を送れる。質問の入口があることで、確かめることが自然な手順になる
- **壊したときの連絡先** — 万一壊したときに誰に連絡すればよいかを表示する。壊したときの手順が決まっていることで、使い手の不安を下げる

## User Stories

- **US-001 許可の範囲がわからず触れない問題**
  利用者（Bさん）は、渡された機材をどこまで触ってよいかを、持ち主に聞かずに知りたい。それにより、壊すのが怖くて何もせずに返す事態を避けたい。
  背景: 現状は許可の範囲が持ち主の頭の中にしかなく、確かめにくい。触らずに返すと、持ち主には興味がないと受け取られ、次の機会を失う。

- **US-002 言葉にしていない条件で若手に注意してしまう問題**
  利用者（先輩）は、機材を貸すときに、自分にとって当然の条件を手間なく伝えたい。それにより、若手が条件を外して注意しなければならない事態を避けたい。
  背景: 現状は条件を言葉にしないまま貸し、外されてから注意する。注意された若手は、その後機材に触れなくなる。

## Open Questions

- 四つの段階で足りるか。機材の種類（測定器、試作機、評価ボード）によって、段階の意味が変わる
- 持ち主がラベルを付けるのを面倒に感じないか。最初に付けたあと、更新されるか
- 「分解・改造してよい」の機材が少ないと、試せる場の不足は解決しない。版3との組み合わせが必要か
- **モックで確かめたいこと**: 持ち主がラベルを1分以内に設定でき、手間に感じないか
- **モックで確かめたいこと**: 使い手がラベルを見て、「ここまでなら安心して試せる」と感じられるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **ラベルが付かない** — 持ち主が面倒がる → ほとんどの機材にラベルがない → 元の口頭に戻る。軽減: 貸し出しのたびに1分で設定できる形にし、前回の設定を引き継ぐ
- **安全側に寄りすぎる** — 持ち主が「見るだけ」ばかり選ぶ → 試せる範囲が広がらない → 目的を果たさない。軽減: 段階ごとの機材数を部署で共有し、版3の試せる場と組み合わせる
- **ラベルの過信** — ラベルどおりに使えば大丈夫と思う → ラベルにない危険を見落とす → 事故が起きる。軽減: 安全上の注意は既存の手順書に従うことを明記する
- **質問の負担** — 質問が持ち主に集中する → 持ち主が貸すのを嫌がる → 機材が出回らない。軽減: よくある質問をラベルに追記できるようにする
