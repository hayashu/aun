# PRD: 練習用キットと「はんだ→測定→改造」の段階課題、相談役をそろえた部署の壊してよい練習カリキュラム（A5xB5-3）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A5×B5（安心して練習・相談できる場所がない × 気軽に試して失敗できる場所がない）の版3。方向性は「場・仕組みを変える（チーム／組織向け）」。版1は一人で使う仮想ベンチ、版2は先輩との練習課題の交換日記を扱う。A1×B5-3（試作棚）は壊してよい機材を置く場所、本PRDは壊すことを前提にした段階的な練習の道筋と相談役を扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門には試作機や評価ボードがあるが、若手が自由に触れる機会は少ない。

部門には、若手がハードウェアの手を動かす力を身につけるための**練習の道筋がない**。新人研修では実習があるが、決められた手順をなぞるもので、壊すことを前提にした練習ではない。配属後は、業務の試作で手を動かすしかなく、業務の試作では失敗が許されない。結果として、壊すのが怖い若手は手を動かさず、手を動かさないので力がつかない。部門長は若手の手を動かす力が育たないと感じているが、練習の場を用意する仕組みがない。

**誤解の実態**: Bさんは、壊すことへの不安から、配属後3年間でほとんど実物を触ってこなかった。業務の試作は先輩が担当し、Bさんは資料作成を担当していた。Aさんも、はんだ付けを新人研修で一度やっただけで、その後は触っていなかった。部門の若手の多くが同じ状況だった。部門長は「若手に試作を任せたいが、任せられる力がない」と言い、若手は「練習する場がないので力がつかない」と感じていた。

**気づきの実態**: 問題は個人の意欲ではなく、**壊すことを前提にした練習の道筋と、練習中に相談できる相手が、部署に用意されていない**ことである。練習用のキットと、段階的な課題と、相談役がそろっていれば、若手は壊すことを恐れずに練習できる。練習で力がつけば、業務の試作も任せられるようになる。

**練習機会の実態**: 部門の研修予算は集合研修に使われ、若手が自分のペースで練習するための機材や課題は用意されていない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げ、職場側の「ローコンテキスト化」を対策に掲げている。部門の若手が手を動かす練習をしている状況は把握されていない。

## Goals / Non-Goals

**Goals**

- 若手が、壊すことを前提に段階的な練習を進められる（カリキュラムの課題を完了した若手の数と、完了した課題の数を効果指標とする）
- 練習中に相談できる相手がいる（相談役への相談件数を効果指標とする）
- 練習を終えた若手に、業務の試作が任される（カリキュラムの最終段階を終えた若手のうち、半年以内に業務の試作を任された割合を効果指標とする）

**Non-Goals**

- 新人研修の置き換え（新人研修はそのまま残し、カリキュラムは配属後の練習として加える）
- 練習の成績による評価（課題の完了を人事評価に使わない）
- 一人の仮想ベンチ（版1）、先輩との交換日記（版2）の範囲

## Proposed Solution / Feature Description

部署に**壊してよい練習用キットと、「はんだ付け→測定→改造」の段階的な課題、そして練習中に相談できる相談役をそろえた練習カリキュラム**を用意し、その運営をWebで支える仕組みを提供する。若手は自分のペースで課題を進め、困ったら相談役に聞く。各段階の最後には、相談役と15分の確認を行い、次の段階に進む。

**主要な構成要素**:

- **練習用キット** — 段階ごとに、壊してよい練習用の基板と部品のセットを用意する。キットは部署の棚に置き、若手は自由に持ち出せる
- **段階的な課題** — 第1段階（はんだ付け：部品を付ける、外す）、第2段階（測定：テスタやオシロスコープで測る）、第3段階（改造：部品を替えて特性を変える）の3段階で、各段階に5つ程度の課題を並べる
- **課題の進み具合** — 若手は、終えた課題に写真と一行のメモを付けて記録する。自分の進み具合が一覧で見える
- **相談役** — 部署のベテランが持ち回りで相談役を務める。若手は、困ったことをいつでも相談役に送れる
- **段階の確認** — 各段階の最後に、相談役と15分の確認を行う。相談役は課題の写真を見て、次の段階に進んでよいかを一緒に決める。点数は付けない
- **部署の一覧** — 部門長が、カリキュラムを進めている若手の数と、各段階の人数を見られる。個人別の進み具合は出さない

## User Stories

- **US-001 壊すのが怖くて3年間実物を触ってこなかった問題**
  利用者（Bさん）は、壊してよいキットで、段階的にハードウェアの練習をしたい。それにより、壊すことへの怖さを乗り越え、手を動かす力を身につけたい。
  背景: 現状は練習の道筋がなく、業務の試作では失敗が許されないので、手を動かさないまま時間が過ぎる。

- **US-002 練習中に相談できる相手がいない問題**
  利用者（Aさん）は、練習で困ったときに、すぐに相談できる相手がほしい。それにより、一人で練習して行き詰まる状態を変えたい。
  背景: 現状は練習の相談相手がおらず、困ったところで止まってしまう。

- **US-003 若手に試作を任せられる力が育たない問題**
  利用者（部門長）は、若手が手を動かす力を身につける道筋を、部署として用意したい。それにより、若手に業務の試作を任せられるようにしたい。
  背景: 現状は練習の場がなく、若手の手を動かす力が育たない。

## Open Questions

- 練習用キットの費用を、部署の予算でまかなえるか
- 相談役を務めるベテランの時間を、業務として認めてもらえるか
- 若手が業務の合間に練習する時間を確保できるか
- **モックで確かめたいこと**: 段階的な課題の一覧を見て、壊すのが怖い若手でも「第1段階からなら始められそう」と感じられるか
- **モックで確かめたいこと**: 段階の確認で、相談役と一緒に次に進むかを決める流れが、試験ではなく励ましとして受け取られるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **練習の時間がない** — 業務が忙しい → 練習が進まない → カリキュラムが形だけになる。軽減: 週に1時間を練習の時間として業務の中で認めてもらう
- **安全上の事故** — 練習ではんだごてや電源を使う → 事故が起きる → カリキュラムが止められる。軽減: 第1段階の最初に安全の課題を置き、電源を使う課題は相談役の付き添いを条件にする
- **試験のように感じる** — 段階の確認がある → 合格・不合格の試験と受け取る → 若手が萎縮する。軽減: 確認は点数を付けず、次に進むかを一緒に決める場であることを明記する
- **評価への転用** — 進み具合が記録される → 人事評価に使われる → 練習が義務になる。軽減: 部門長には個人別の進み具合を出さず、評価に使わない方針を明記する
