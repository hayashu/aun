# PRD: 電気と機械の担当者が互いの分野を教え合う、質問の遠慮をなくす知識交換ペア（A3xB2-2）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A3×B2（適切なコミュニケーション方法がわからない × ハードウェアの知識が足りず焦る）の版2。方向性は「2人の間をつなぐ（コミュニケーション設計）」。版1は個人の質問の下ごしらえ、版3は部署の質問タイムを扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門は機械系の社員が多く、筐体・機構・材料の知識が前提として会話が進む。

Bさんは機械の知識が足りず焦っているが、先輩に質問するときに**遠慮**がある。質問は一方的に先輩の時間をもらうことで、自分は何も返せないと感じている。どう切り出せば迷惑にならないか、どこまで聞いてよいかもわからない。一方で、部門の機械の担当者の中には、電気の知識が足りないと感じている人もいる。基板の発熱やノイズの話になると、ついていけないことがある。しかし、ベテランが若手に電気のことを聞くのは、立場上やりにくい。

**誤解の実態**: Bさんは筐体の材料の選び方を機械の先輩に聞こうとしたが、先輩の時間を取るのが申し訳なくて、聞けずに一人で調べ続けた。同じ週、その機械の先輩は、Bさんの基板のノイズ対策の話が理解できず、設計レビューで的外れな質問をしてしまい、恥ずかしい思いをした。先輩もBさんに聞けばよかったが、若手に教えを請うのはためらわれた。2人とも、相手が自分の知りたいことを知っているのに、聞かずに困っていた。

**気づきの実態**: 質問が一方通行だと、聞く側には遠慮が生まれ、聞かれる側には負担が生まれる。互いに教え合う関係なら、遠慮も負担も対等になる。Bさんには機械の先輩に教えられる電気の知識があり、先輩にはBさんに教えられる機械の知識がある。しかし、教え合う関係をつくる場面がないので、2人とも一人で困り続ける。

**練習機会の実態**: 部門のOJTは、先輩が後輩に教える一方向の形しかない。分野をまたいで教え合う仕組みはない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。分野をまたいで知識を交換している組み合わせは、部門では把握されていない。

## Goals / Non-Goals

**Goals**

- 若手が質問をためらう遠慮が減る（ペアの相手に質問した回数を効果指標とする）
- 分野をまたぐ知識が、双方向に行き来する（ペアの間で、両方向の質問があった割合を効果指標とする）
- 両者の知識不足への焦りが減る（「相手の分野の話についていける」の自己申告を効果指標とする）

**Non-Goals**

- 体系的な研修の置き換え（ペアは日々の質問を交わす関係で、研修ではない）
- ペアの評価（教えた回数や上達度を評価に使わない）
- 個人の質問の準備（版1）、部署の質問タイム（版3）の範囲

## Proposed Solution / Feature Description

分野の違う2人を**「知識交換ペア」として組み合わせ、互いに教え合う関係をつくる**Webの仕組みを提供する。ペアは、自分が教えられる分野と、知りたい分野を登録した人の中から組まれる。ペアは週に一度、15分ずつ互いの分野の質問に答える時間を持つ。教え合いが対等なので、質問の遠慮がなくなる。

**主要な構成要素**:

- **教えられること・知りたいことの登録** — 各自が、教えられる分野と、知りたい分野を登録する（例: 教えられる＝回路・ノイズ、知りたい＝材料・筐体設計）
- **ペアの提案** — 教えられることと知りたいことが逆になっている2人を、ペアとして提案する。両者が承諾したらペアになる
- **質問の置き場** — ペアの間で、次の時間に聞きたい質問を書いておく場所。両方の質問が並んで見えるので、どちらか一方だけが聞いている状態にならない
- **週15分ずつの時間** — 週に一度、30分の時間を2人で予約し、前半15分で一方の質問、後半15分でもう一方の質問に答える
- **教え合いの記録** — 話した内容を一行ずつ残す。互いに何を教え、何を教わったかが見える

## User Stories

- **US-001 先輩の時間をもらうのが申し訳なくて聞けない問題**
  利用者（Bさん）は、機械の知識を、遠慮せずに聞ける相手がほしい。それにより、一人で調べ続けて時間を失う事態を避けたい。
  背景: 現状は質問が一方的に先輩の時間をもらうもので、何も返せないと感じて聞けない。

- **US-002 若手に教えを請いにくい問題**
  利用者（機械の先輩）は、電気の知識を、立場を気にせずに聞ける相手がほしい。それにより、設計レビューで的外れな質問をする事態を避けたい。
  背景: 現状は若手に教えを請うのがためらわれ、わからないまま会議に出る。

## Open Questions

- 教えられることと知りたいことがちょうど逆になる組み合わせが、十分に見つかるか
- 週15分ずつの時間を、双方が続けて確保できるか
- 立場の違う2人（若手とベテラン）が、対等に教え合えるか
- **モックで確かめたいこと**: 教えられること・知りたいことを登録して、ペアが提案されるまでの流れが自然か
- **モックで確かめたいこと**: 質問の置き場で両方の質問が並んで見えることが、「一方的に聞いているのではない」という安心につながるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **ペアが組めない** — 組み合わせが合わない → ペアが少ない → 仕組みが広がらない。軽減: 完全に逆でなくても、一方の知りたい分野をもう一方が教えられれば提案する
- **一方通行に戻る** — 立場の強い側が教えるばかり → 若手が教える時間がなくなる → 遠慮が戻る。軽減: 15分ずつの時間割を画面で示し、両方の質問の時間を守る
- **続かない** — 業務が忙しくなる → 週の時間が飛ぶ → 関係が途切れる。軽減: 時間が飛んだ週は、質問の置き場でチャットで答える形も許す
- **評価への転用** — 教え合いの記録が残る → 評価に使われる → 形式的になる。軽減: 記録はペアの2人だけが見られる設定にする
