# PRD: 話す2人の「知っている前提」を並べて見せる前提ボード（A3xB4-2）

版: v1（2026-11-22、パイロット） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）は、電気・機械の両チームにまたがる製品改良プロジェクトの調整役を担当している。同じプロジェクトには、電気電子出身で入社3年目のBさん（20代後半）がいる。Bさんの部署は機械系の社員が多く、電気側の話ができる相手が少ない。

この2人が困っているのは、**話している最中に、相手が何をわかっていて何をわかっていないかが見えない**という点である。Bさんの側では、分野が違う相手にどこまで説明すればよいかがわからない。Aさんの側では、わからないと言ってよい場面か、どう聞き返せば失礼にならないかがわからない。片方が説明を省き、もう片方が聞き返さない。こうして、ずれたまま話が終わる。

**誤解の実態**: Bさんは、試作基板の発熱について機械チームの担当者Cさんに相談した。Bさんが「熱設計マージンが足りない」と言うと、Cさんはうなずいた。Cさんはこれを「筐体の外側の温度」の話だと理解した。一方Bさんが言いたかったのは「部品の内部温度が定格に近い」ということだった。この場に同席していたAさんは、話がかみ合っていないかもしれないと感じた。しかし、分野外の自分が口を挟んでよいのか、どう言えばよいのかわからず黙っていた。Cさんは表面温度の対策として塗装の変更を検討し、Bさんは通気口が追加されると思って待った。3週間後の試作で、内部温度の問題は解決していないことがわかった。

**気づきの実態**: ずれは、会話の中では見えない。うなずきは「理解した」とも「聞いている」とも取れる。分野が違う相手は、自分の理解が違っていることにそもそも気づかない。気づいた人がいても、その人が聞き返す型を持っていなければ、気づきは会話に戻らない。今回のAさんは気づいていた。しかし、気づいたことを言葉にする方法がなかった。

**練習機会の実態**: 社内の用語集は分野ごとに作られており、「この言葉は機械の人には別の意味に聞こえる」というずれは載っていない。会議の議事録には結論だけが残り、どこで理解が分かれたかは残らない。聞き返し方の研修は一般論で、技術の打ち合わせにそのまま使えない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げ、対策として「コミュニケーションのローコンテキスト化」を掲げている。一方、分野をまたぐ用語のずれがどれだけ手戻りを生んでいるかは、社内で測られていない。

## Goals / Non-Goals

**Goals**

- 同じ言葉を別の意味で理解したまま話が終わる件数が減る（打ち合わせ後に、言葉の理解が食い違っていたと判明した件数を効果指標とする）
- 打ち合わせの場で、ずれに気づいた人が聞き返す頻度が増える（ボード上で「確認したい」と印を付けた件数と、そのうち実際に会話で確認された割合を効果指標とする）
- 分野外の参加者も、聞き返してよいと感じられる（「わからないと言いやすかった」の自己申告を効果指標とする）

（一つめは結果で、二つめと三つめはその手前の行動である。結果は試作の周期にしか現れないため、当面は二つめを中心に見る）

**Non-Goals**

- 会話の自動録音・自動要約（録音を前提にすると率直に話せなくなる。印を付けるのは参加者自身に限る）
- 用語の正しい意味の判定（分野ごとに正しい意味があり、どちらが正しいかを決めるものではない）
- 個人の理解度の評価（誰がわかっていなかったかを記録すると、印を付けなくなる）
- 話し手個人の事前準備（版1の範囲）
- チームの会議運営のルール化（版3の範囲）

## Proposed Solution / Feature Description

打ち合わせの最中に2人以上で開く**共有ボード**を提供する。話に出た言葉をボードに置き、参加者が各自「わかる／あいまい／わからない」を**他の人の印を見る前に**付ける。全員が付け終えると、印がそろって表示される。ずれている言葉が目に見えるので、聞き返すきっかけが会話の外から生まれる。さらに、ずれた言葉には、その場で使える聞き返しの一文を候補として出す。

**主要な構成要素**:

- **言葉の置き場** — 打ち合わせ中に出てきた言葉を、誰でもボードに追加できる。分野の違う人が意味を取り違えやすい言葉は、分野別の一覧から候補として出る
- **伏せて付ける印** — 各参加者が、言葉ごとに「わかる／あいまい／わからない」を付ける。他の人の印は、自分が付け終えるまで見えない。先に見せると周りに合わせてしまい、ずれが隠れる。この順序が中核である
- **ずれの表示** — 全員が付け終えると、印が分かれた言葉を上に並べる。「わかる」と答えた人どうしでも意味が違うことがあるため、「わかる」の人には一言で意味を書いてもらい、並べて見せる
- **聞き返しの一文** — ずれた言葉について、その場で使える聞き返し方を候補として出す（例:「いまの『マージン』は、部品の中の温度の話ですか、外側の温度の話ですか」）。相手を正す言い方ではなく、自分の理解を確かめる言い方に限る
- **ずれの記録** — 打ち合わせの終わりに、ずれた言葉と、確認した結果の意味を残す。誰が「わからない」と付けたかは残さない
- **分野間の取り違え一覧** — 記録がたまると、「機械と電気のあいだで取り違えやすい言葉」の一覧になる。社内用語集にない、分野をまたぐずれの資料として使う。第2段階の機能で、現時点のプロトタイプには入っていない

## User Stories

- **US-001 うなずいたまま違う意味で理解している問題**
  利用者（Bさん）は、説明した言葉を相手が同じ意味で受け取ったかを、その場で知りたい。それにより、試作で問題が出る前にずれを直したい。
  背景: 現状はうなずきを理解の合図と受け取って話を終える。ずれは数週間後の試作で結果としてのみ現れ、その時点で試作一回分の時間が失われている。

- **US-002 気づいても口を挟めない問題**
  利用者（Aさん）は、話がかみ合っていないと感じたとき、失礼にならない形でそれを場に出したい。それにより、自分の分野外の話でも、ずれをその場で確認したい。
  背景: 現状は気づいても、言ってよいのか、どう言えばよいのかがわからず黙ってしまう。気づいていても言葉にできなければ、気づかなかったのと結果は変わらない。

## Open Questions

- 打ち合わせの最中にボードを操作する余裕があるか。会話の流れを止めずに印を付けられる仕組みが要る。打ち合わせの最後に5分だけまとめて付ける形の方が現実的かもしれない
- 「わかる」と付けた人に意味を一言書いてもらうのは負担が大きくないか。書かなければ、「わかる」どうしのずれは見えない
- 誰が言葉をボードに置くか。話し手が置くと自分が問題ないと思う言葉は置かれず、聞き手が置くとわからないと認めることになる
- 匿名にすべきか。誰が「わからない」と付けたかを隠すと付けやすくなるが、少人数では推測できてしまう
- **モックで確かめたいこと**: 伏せて付けたあと、そろって表示される瞬間に「ずれている」とひと目でわかる見せ方になっているか
- **モックで確かめたいこと**: 聞き返しの一文の候補を見て、実際にその場で口に出せそうだと感じられるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **会話の中断** — ボード操作に気を取られる → 打ち合わせのテンポが落ちる → 使われなくなる。軽減: 打ち合わせ中は言葉を置くだけにし、印は最後にまとめて付ける流れも選べるようにする
- **わからないと言う恥ずかしさ** — 印が残る → 評価に使われる不安 → 正直に付けなくなる。軽減: 誰が付けたかを記録に残さず、表示も人数だけにする
- **全員「わかる」の錯覚** — 全員が「わかる」と付ける → ずれがないように見える → 意味の違いを見逃す。軽減: 「わかる」の人にも一言の意味を書いてもらい、並べて見せる
- **相手を責める道具になる** — ずれの表示が「説明が下手」の証拠に見える → 話し手が嫌がる → ボードを開かなくなる。軽減: ずれは言葉の性質として表示し、誰の説明が原因かは示さない
- **単独では効かない** — 2人とも使う前提 → 片方だけが開いても意味がない → 導入が止まる。軽減: 版3（チームの仕組み）と組み合わせて会議の型に組み込む前提を明記する
