# PRD: 隣の分野に頼む前に「何で・誰を通して・どの書式で」を確かめる分野別の作法カード（A2xB4-1）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A2×B4（暗黙の期待・ルールがわからない × 専門領域の違いで認識がずれる）の版1。方向性は「当事者の行動を支える（個人向けツール）」。版2は2分野の間で作法を見せ合うシート、版3はプロジェクト開始時の取り決めを扱う。A1×B4（動かせない事情）、A3×B4（伝え方と用語）とは異なり、本セルは「分野ごとの仕事の作法」を扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）は、電気・機械の両チームにまたがるプロジェクトの調整役を担当している。同じプロジェクトには、電気電子出身で入社3年目のBさん（20代後半）がいる。Bさんの部署は機械系の社員が多い。

分野ごとに、**仕事の作法**が違う。機械の人は図面と3Dデータで話し、変更は「設計変更依頼書」を課長経由で出すのが当然とされる。電気の人は回路図と部品表で話し、変更はチャットで担当者に直接頼むことが多い。どちらも自分の分野の作法を当然と思っているので、相手の作法を知らないまま頼み、相手は「頼み方が違う」と感じても口にしない。

**誤解の実態**: Bさんは、基板のコネクタ位置が筐体の穴と合わないことに気づき、機械の担当者にチャットで「穴を3mm右にずらしてもらえますか」と回路図のPDFを添えて頼んだ。機械の担当者は「了解です」と返したが、何もしなかった。機械の作法では、寸法の変更は図面に指示を書き込み、設計変更依頼書を課長経由で出さなければ受け付けられないからである。担当者はBさんがいずれ正式な依頼を出すと思っていた。2週間後、穴の位置が変わっていないことがわかった。調整役のAさんも、機械の作法を知らなかった。

**気づきの実態**: 「了解です」は、機械の担当者にとって「話はわかった」という意味で、「対応する」という意味ではなかった。その裏には、正式な手順を踏んでほしいという暗黙の期待がある。Bさんは電気の作法で頼んだので、それで十分だと思っていた。どちらも、相手の作法が自分と違うことに気づいていない。

**練習機会の実態**: 社内の手続きマニュアルには設計変更依頼書の様式があるが、「どの分野のどんな変更に必要か」は書かれていない。他分野の作法は、外して初めて知る。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。分野をまたぐ依頼が、作法の違いで止まった件数は測られていない。

## Goals / Non-Goals

**Goals**

- 隣の分野への依頼が、作法の違いで止まる件数が減る（依頼のうち、相手の分野の作法に沿って出せた割合を効果指標とする）
- 依頼が止まっていることに早く気づける（依頼から、相手が対応を始めたことを確かめるまでの日数を効果指標とする）
- 隣の分野の作法を、本人が説明できるようになる（作法カードの項目のうち、本人が事前に知っていた割合を効果指標とする）

**Non-Goals**

- 手続きマニュアルの置き換え（正式な手続きは既存のマニュアルに従う。カードは分野ごとの暗黙の作法を補う）
- 依頼の代行（本人が自分で依頼を出す）
- 2分野の間の作法の見せ合い（版2）、プロジェクト開始時の取り決め（版3）の範囲

## Proposed Solution / Feature Description

隣の分野に何かを頼む前に、**相手の分野と頼みたいこと（寸法の変更、部品の変更、評価の依頼など）を選ぶと、その分野の作法をカードで示す**個人向けWebツールを提供する。カードには「何で話すか（図面、3Dデータ、回路図）」「誰を通すか」「どの書式か」「返事の『了解』が何を意味するか」が書かれている。本人はカードを見てから依頼を出し、出したあとに確認の日を決める。

**主要な構成要素**:

- **相手の分野と頼みたいことの選択** — 機械／電気／ソフト／品質などの分野と、頼みたいことの種類を選ぶ
- **作法カード** — 選んだ組み合わせに対して、相手の分野の作法を示す。「機械への寸法変更：図面に指示を書き込む／設計変更依頼書を課長経由／チャットでの依頼は相談扱い」のように書く
- **「了解」の意味** — その分野で返事の「了解」が「話はわかった」なのか「対応する」なのかを示し、対応を確かめる一言の例を添える
- **確認の日** — 依頼を出したら、相手が対応を始めたかを確かめる日を決める。その日に知らせる
- **自分の作法帳** — 外した作法や、新しく知った作法を本人が書き足せる。カードは使うほど本人の職場に合ったものになる

## User Stories

- **US-001 自分の分野の作法で頼んで止まる問題**
  利用者（Bさん）は、機械の担当者に変更を頼む前に、機械の分野ではどんな頼み方が必要かを知りたい。それにより、チャットで頼んで「了解です」と返され、2週間何も進まない事態を避けたい。
  背景: 現状は自分の分野の作法で頼み、相手の分野では正式な依頼と見なされない。止まっていることは、後工程で結果として初めてわかる。

- **US-002 調整役なのに各分野の作法を知らない問題**
  利用者（調整役のAさん）は、各分野の依頼の作法を知り、メンバーの依頼が正しい形で出ているかを確かめたい。それにより、依頼が作法の違いで止まっていることに早く気づきたい。
  背景: 現状は各分野の作法が暗黙で、調整役にも見えない。

## Open Questions

- 作法カードの内容を誰が書くか。各分野のベテランに確かめてもらう必要がある
- 作法は課や担当者によっても違う。カードの内容が本人の職場に合わないことをどう扱うか
- **モックで確かめたいこと**: 相手の分野と頼みたいことを選んで作法カードが出るまでが、依頼を出す前の1分で済むか
- **モックで確かめたいこと**: 「了解」の意味の説明を見て、依頼を出したあとに確認の日を決めたくなるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **作法の一般化** — カードの作法を絶対視する → 担当者ごとの違いを見ない → かえって外す。軽減: カードは「多い作法」として示し、自分の作法帳で上書きできるようにする
- **カードの質** — 作法の書き方が浅い → 実務で使えない → 信頼を失う。軽減: 最初は機械と電気の組み合わせに絞り、ベテランの確認を経たカードだけを載せる
- **手続きの増加** — 作法を守るために書類が増える → 依頼の手間が増える → 依頼をためらう。軽減: 正式な書類が要らない場合（相談段階など）も明示する
- **文化的な単純化** — 「機械の人は堅い」と分野を決めつける → 偏見を生む。軽減: 作法は分野の手順として示し、人柄と結びつけない
