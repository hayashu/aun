# PRD: 自分の仕事を「別分野の人向けに1分で説明する」練習を、本番の前に一人で繰り返せる説明ドリル（A5xB4-1）

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）は、電気・機械の両チームにまたがるプロジェクトの調整役を担当している。同じプロジェクトには、電気電子出身で入社3年目のBさん（20代後半）がいる。Bさんの部署は機械系の社員が多い。

Bさんは、機械系の人に電気の話をするとき、うまく伝わらないことが多い。どの言葉が通じて、どの言葉が通じないのか、どこまで説明すればよいのかがわからない。**この説明の力を練習する場がない**。練習できるのは本番の会議だけで、本番で伝わらなければ、話が先に進まず、相手の時間も取ってしまう。うまく説明できなかった経験が重なると、分野の違う人と話すこと自体を避けるようになる。

**誤解の実態**: Bさんは設計会議で、基板のノイズ対策について機械チームに説明した。「グラウンドのリターンパスが長いので、コモンモードノイズが出ます」と言ったが、機械チームの誰も理解できず、会議は進まなかった。会議のあと、先輩から「機械の人にもわかるように話して」と言われたが、どう言い換えればよいかわからなかった。次の会議でもうまく説明できず、Bさんは会議で発言するのをためらうようになった。Aさんも、調整役として電気と機械の話を橋渡ししようとしたが、どちらの専門用語もうまく言い換えられなかった。

**気づきの実態**: 説明の力は、練習で伸びる。自分の仕事を、別分野の人向けに1分で説明する文を書き、使った専門用語を確かめ、言い換え、もう一度説明する。これを何度か繰り返せば、本番で伝わる説明ができるようになる。しかし今は、練習の場がなく、本番で失敗して学ぶしかない。

**練習機会の実態**: プレゼンテーションの研修はあるが、話し方や資料の作り方が中心で、分野をまたぐ説明の練習はない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。分野をまたぐ説明が伝わらずに会議が進まなかった件数は、部門では測られていない。

## Goals / Non-Goals

**Goals**

- 別分野の人に伝わる説明を、本番の前に準備できる（ドリルで練習した説明のうち、本番の会議で聞き返されずに伝わった割合の自己申告を効果指標とする）
- 分野の違う人と話すことへのためらいが減る（「別分野の人に説明するのが怖くない」の自己申告を効果指標とする）
- 専門用語の言い換えの引き出しが増える（本人の言い換え帳に登録された言い換えの数を効果指標とする）

**Non-Goals**

- 説明文の自動作成（本人が書き、言い換えることが練習になる）
- 話し方や発音の指導（扱うのは説明の中身と言葉選び）
- 異分野の相手との練習（版2）、分野横断の入門会（版3）の範囲

## Proposed Solution / Feature Description

自分の仕事の一場面を選び、**別分野の聞き手（機械、ソフト、営業など）を想定して1分の説明文を書き、使った専門用語を確かめて言い換え、もう一度書き直す**練習を一人で繰り返せるWebツールを提供する。最後に「聞き手に伝えたい3つのこと」が説明に入っているかを本人が確かめる。

**主要な構成要素**:

- **場面と聞き手の選択** — 説明したい仕事の一場面（ノイズ対策、電源の選定など）と、聞き手の分野を選ぶ
- **1分の説明文** — 聞き手に向けて、1分で話せる長さ（300字程度）の説明文を書く
- **専門用語の確認** — 書いた文の中で、選んだ聞き手の分野の人には通じにくそうな言葉に印を付ける。印の判定は、分野ごとの用語の一覧に基づく
- **言い換えの練習** — 印の付いた言葉を、本人が言い換える。言い換えに詰まったら、たとえ（「水道管の太さのようなもの」など）の作り方の例を示す。例は本人が試したあとにしか出さない
- **伝えたい3つのこと** — 説明を書き直したあと、聞き手に伝えたい3つのことを書き、それが説明に入っているかを確かめる
- **言い換え帳** — 練習で作った言い換えを、本人の言い換え帳にためる。本番の会議の前に見返せる

## User Stories

- **US-001 本番の会議でしか説明の練習ができない問題**
  利用者（Bさん）は、別分野の人への説明を、本番の前に一人で練習したい。それにより、会議で専門用語が通じずに話が進まない事態を減らしたい。
  背景: 現状は説明の練習の場がなく、本番の会議で失敗して学ぶしかない。失敗が重なり、会議で発言するのをためらうようになる。

- **US-002 両方の分野の言葉を言い換えられない問題**
  利用者（調整役のAさん）は、電気と機械の専門用語を、それぞれの分野の人向けに言い換える引き出しを増やしたい。それにより、調整役として話を橋渡しできるようになりたい。
  背景: 現状は両方の分野の専門用語を言い換える練習の場がない。

## Open Questions

- 分野ごとの用語の一覧の質が、印の判定の正しさを左右する。一覧を誰が作るか
- 一人で練習した説明が、本番で本当に伝わるか。聞き手の反応がない練習で十分か
- **モックで確かめたいこと**: 説明文を書いて専門用語に印が付き、言い換えて書き直す流れが、10分以内で一周できるか
- **モックで確かめたいこと**: 言い換え帳がたまっていく様子を見て、「別分野の人に話せる」という自信につながるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **一人練習の限界** — 聞き手の反応がない → 本番で伝わらない部分が残る → 自信を失う。軽減: 版2の練習ペアと組み合わせ、一人の練習のあとに相手に試す流れを示す
- **用語の判定の誤り** — 通じる言葉に印が付く → 不要な言い換えをする → 説明が回りくどくなる。軽減: 印は「通じにくいかもしれない」の候補として示し、本人が判断する
- **教材との誤認** — 用語集に見える → 既存の用語集と比べられる → 差別性を失う。回避: 用語を教えるのではなく、本人が言い換える練習の形を守る
- **練習止まり** — 練習はする → 本番で言い換え帳を使わない → 行動が変わらない。軽減: 会議の前に言い換え帳を見返す習慣をつけるよう、本人が会議の予定を登録できるようにする
