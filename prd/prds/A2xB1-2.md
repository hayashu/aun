# PRD: 資料を頼む前に「誰に・何枚・どの粗さで」を合意する資料の完成ライン合意シート（A2xB1-2）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A2×B1（暗黙の期待・ルールがわからない × やりたいものづくりができない）の版2。方向性は「2人の間をつなぐ（コミュニケーション設計）」。版1は作成者個人の型のチェック、版3はチームの資料ルールを扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門の業務の多くは会議資料のパワーポイント作成で、2人とも、本当はものづくりにもっと時間を使いたいと思っている。

課長が資料を頼むとき、言葉は「評価結果、資料にまとめておいて」の一言である。課長の頭の中には、**誰に見せるか、何枚くらいか、どこまで作り込むか**という期待がある。しかし、その期待は言葉にされない。作成者は期待を推測して作り、外れれば作り直す。推測が苦手な人ほど、作り直しに時間を取られる。

**誤解の実態**: 課長はBさんに「評価結果、資料にまとめておいて」と頼んだ。課長は、翌週の部長報告で使う3枚程度のまとめを想定していた。Bさんは評価の詳細を残すための記録だと考え、測定条件からグラフまで10枚で作った。課長は「部長向けだから3枚に」と言い、Bさんは作り直した。課長は「最初に言えばよかった」と思ったが、次の依頼でもやはり一言で頼んだ。Bさんが10枚の資料に使った1日半は、試作基板の評価に使うはずの時間だった。

**気づきの実態**: 課長にとって「資料にまとめて」は、使う場面がわかっている前提の言葉である。Bさんにとっては、使う場面がわからない言葉である。どちらも、期待が言葉になっていないことに気づいていない。依頼の瞬間に「誰向けで、何枚くらいですか」と確かめれば済むが、Bさんは何を確かめればよいかを知らず、課長は確かめられることを想定していない。

**練習機会の実態**: 資料作成の研修では、見やすいスライドの作り方を教える。しかし、依頼者の期待をどう確かめるかは教えない。依頼の場面は口頭で一瞬で終わり、後から振り返ることもない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。資料の依頼で、期待の行き違いによる作り直しがどれだけ起きているかは測られていない。

## Goals / Non-Goals

**Goals**

- 依頼者の期待と違う資料を作ってしまう件数が減る（資料のうち、提出後に枚数や構成の大きな作り直しを求められた割合を効果指標とする）
- 資料1つあたりの作成時間が、依頼者の期待する粗さに合う（依頼者が期待した作成時間と、実際の作成時間の差を効果指標とする）
- ものづくりに使える時間が増える（週あたりの資料作成時間の自己申告を効果指標とする）

**Non-Goals**

- 資料の自動作成（期待をそろえることが目的で、作成の代行はしない）
- 資料の出来の採点（作成者を評価する道具にしない）
- 作成者個人の型の学習（版1）、チームの資料ルール（版3）の範囲

## Proposed Solution / Feature Description

資料を頼むとき、依頼者と作成者が**「誰に見せるか・何枚くらいか・どの粗さか・使う日」の4項目を選択式で合意する**シートを提供する。依頼者が選んで送るか、作成者が選んで確認を求めるかのどちらでも使える。粗さは「メモ書き（30分）／たたき台（2時間）／清書（1日）」のように、作成時間の目安と組で示す。

**主要な構成要素**:

- **完成ラインの4項目** — 見せる相手（課内／部長／他部署／顧客）、枚数の目安、粗さ（メモ書き／たたき台／清書）、使う日を選ぶ
- **粗さと時間の組** — 粗さを選ぶと、その目安の作成時間が表示される。依頼者は、自分が頼んでいる作業の重さを、時間で知ることができる
- **作成者からの確認** — 依頼者が口頭で頼んだ場合は、作成者がシートを埋めて送り、依頼者が「このとおり」か「ここが違う」を返す
- **参考資料の添付** — 依頼者が「この資料と同じくらい」と過去の資料を一つ添付できる。言葉で説明しにくい期待を、例で伝える
- **作成時間の振り返り** — 提出時に実際にかかった時間を記録する。依頼者と作成者が、期待した時間とのずれを見られる

## User Stories

- **US-001 3枚のつもりが10枚になる問題**
  利用者（Bさん）は、資料を頼まれたその場で、誰向けで何枚くらいかを依頼者と確かめたい。それにより、期待と違う資料を作って作り直し、ものづくりの時間を失う事態を避けたい。
  背景: 現状は一言の依頼から期待を推測し、外れると作り直す。作り直しに使った時間は、他の作業から削られる。

- **US-002 頼んだ資料の重さに気づかない問題**
  利用者（課長）は、自分の頼んだ資料が部下にとってどれくらいの作業になるかを知りたい。それにより、必要以上に作り込ませて部下の時間を奪うことを避けたい。
  背景: 現状は依頼の言葉に粗さが含まれず、部下は清書のつもりで作り込む。課長は、それが何時間の作業だったかを知らない。

## Open Questions

- 依頼者がシートを使う手間を受け入れるか。口頭で頼んだあとに作成者が埋める運用が中心になりそうだが、それで依頼者の意識は変わるか
- 粗さの3段階の目安時間が、資料の種類によって大きく違う。目安をどう決めるか
- **モックで確かめたいこと**: 依頼者が4項目を選ぶのに30秒以内で済むか
- **モックで確かめたいこと**: 粗さと作成時間が並んで表示されたとき、依頼者が「そこまでは要らない」と粗さを下げたくなるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **依頼者が使わない** — シートが面倒 → 口頭に戻る → 作成者だけが確認を送る。軽減: 作成者からの確認を主な使い方とし、依頼者は1タップで答えられるようにする
- **粗さの誤用** — 「たたき台」と合意したのに清書の出来を期待する → 結局作り直す → 信頼を失う。軽減: 参考資料の添付で、粗さの例を示せるようにする
- **時間の監視** — 作成時間が記録される → 遅い人が責められる → 正直に記録しなくなる。軽減: 作成時間は依頼者と作成者の2人だけが見る設定にする
- **浮いた時間が別の資料に回る** — 作り直しが減る → 空いた時間に別の資料を頼まれる → ものづくりの時間は増えない。軽減: 版3の資料ルールと組み合わせ、浮いた時間の使い道をチームで決める
