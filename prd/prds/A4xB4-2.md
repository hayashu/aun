# PRD: 手戻りのあと、2つの分野の担当者が各時点の「自分の理解」を並べて分かれ目を探す理解の分かれ目シート（A4xB4-2）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A4×B4（失敗の原因がわからない × 専門領域の違いで認識がずれる）の版2。方向性は「2人の間をつなぐ（コミュニケーション設計）」。版1は個人の手戻り経緯マップ、版3はチームの手戻りレビュー会を扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）は、電気・機械の両チームにまたがるプロジェクトの調整役を担当している。同じプロジェクトには、電気電子出身で入社3年目のBさん（20代後半）がいる。Bさんの部署は機械系の社員が多い。

分野をまたぐ手戻りが起きたとき、電気と機械の担当者は**それぞれ自分の側の経緯しか知らない**。電気側は「機械側から聞いた位置で配置した」と思い、機械側は「変更はちゃんと伝えた」と思う。どちらも嘘はついていない。ただ、同じやりとりを違う意味で理解していた。その理解の分かれ目は、2人の理解を並べてみないとわからない。しかし、手戻りのあとに2人で経緯を話すと、責め合いになりそうで、誰も言い出さない。

**誤解の実態**: 2回目の試作で、基板のコネクタが筐体の開口部と2mmずれていた。機械の担当者は、開口部の位置変更をチャットで「開口部、ちょっと右に寄せます」と伝えていた。機械の担当者にとって、それは確定した変更の連絡だった。Bさんにとっては、まだ検討中の相談に見えた。確定したら正式な図面が来ると思っていた。2人は、同じチャットを違う意味で理解していた。手戻りのあと、2人は気まずくなり、経緯を話すことはなかった。次の試作でも、同じように「確定」と「相談」の取り違えが起きた。

**気づきの実態**: 原因は、どちらかの能力ではなく、**同じやりとりの受け取り方の違い**だった。2人が各時点の自分の理解を書いて並べれば、「チャットのこの一言を、機械は確定、電気は相談と受け取っていた」という分かれ目が見える。分かれ目がわかれば、次からは「確定のときは図面を改版する」のような取り決めができる。しかし、2人で並べる場と型がないので、原因は気まずさの中に埋もれる。

**練習機会の実態**: 手戻りのあとは修正の対応だけが行われ、2人で経緯を振り返る習慣はない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。分野をまたぐ手戻りの原因が、受け取り方の違いだった割合は測られていない。

## Goals / Non-Goals

**Goals**

- 手戻りの原因が、2人の理解の分かれ目として特定される（手戻りのうち、シートで分かれ目が特定された割合を効果指標とする）
- 2人の間で、次の取り決めが決まる（分かれ目が特定された手戻りのうち、取り決めが一つ以上決まった割合を効果指標とする）
- 同じ種類の取り違えが減る（取り決めのあと、同じ種類の取り違えが起きた件数を効果指標とする）

**Non-Goals**

- 責任の判定（どちらが悪いかを決めない）
- やりとりの正しい意味の判定（どちらの受け取り方が正しいかを決めない）
- 個人の経緯マップ（版1）、チームのレビュー会（版3）の範囲

## Proposed Solution / Feature Description

手戻りが起きたあとに、2つの分野の担当者が**主なやりとりの時点ごとに「自分はそのとき、こう理解していた」を、相手の答えを見ずに書き、そのあとで並べて見る**シートを提供する。理解が分かれた時点に印が付く。2人はその時点について、次からどうするかを一つ決める。

**主要な構成要素**:

- **主な時点の選択** — 手戻りに関係する主なやりとり（チャット、会議、図面の受け渡し）を3〜5個選ぶ。調整役が選んでもよい
- **伏せて書く理解** — 2人がそれぞれ、各時点で「そのとき自分はこう理解していた」を一行で書く。確定／相談／参考などの選択肢も選ぶ。相手の答えは、自分が書き終えるまで見えない
- **並べて表示** — 2人の理解を時点ごとに左右に並べる。理解が分かれた時点に印を付ける。最初に分かれた時点が、分かれ目として強調される
- **次の取り決め** — 分かれ目について、2人で次からの取り決めを一つ決める（例:「確定した変更は図面を改版して送る。チャットは相談に使う」）
- **取り決めの記録** — 決めた取り決めを残し、次に同じ相手と仕事をするときに見返せる

## User Stories

- **US-001 同じやりとりを違う意味で受け取っていたことに気づかない問題**
  利用者（Bさん）は、手戻りのあとに、相手とどの時点で理解が分かれたかを知りたい。それにより、次の試作で同じ取り違えを繰り返さないようにしたい。
  背景: 現状は手戻りのあと気まずくなり、経緯を話さない。原因が受け取り方の違いだったとわからないまま、同じ取り違えが次も起きる。

- **US-002 伝えたつもりが伝わっていなかった問題**
  利用者（機械の担当者）は、自分が確定のつもりで送った連絡が、相手にどう受け取られていたかを知りたい。それにより、伝え方を見直したい。
  背景: 現状は「ちゃんと伝えた」と思い、相手の受け取り方を確かめる機会がない。

## Open Questions

- 手戻りのあとの気まずい雰囲気の中で、2人がシートを使ってくれるか。調整役が声をかける必要があるか
- 過去の時点の理解を、正確に思い出せるか
- 理解が分かれた時点が複数ある場合、どれを分かれ目とするか
- **モックで確かめたいこと**: 伏せて書いたあとに並べたとき、理解の分かれ目がひと目でわかるか
- **モックで確かめたいこと**: 分かれ目を見た2人が、責め合いではなく「次はこうしよう」という取り決めに向かえる見せ方になっているか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **責め合いになる** — 分かれ目が見える → どちらの受け取り方が悪いかを議論する → 関係が悪くなる。軽減: 正しい意味を判定せず、「次の取り決め」を決めることを目的として画面に示す
- **記憶の書き換え** — 後から理解を書く → 自分に都合よく思い出す → 分かれ目がずれる。軽減: 時点ごとに実際のやりとりの要約を示し、それを見ながら書くようにする
- **使われない** — 気まずさから言い出さない → シートが使われない → 原因が埋もれる。軽減: 版3のレビュー会と組み合わせ、手戻りの後に使う手順として組み込む
- **評価への転用** — シートの記録が残る → 評価に使われる → 正直に書かなくなる。軽減: 記録は2人と調整役だけが見られる設定にする
