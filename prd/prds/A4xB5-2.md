# PRD: うまくいかなかった実験を先輩と15分見返し、先輩は答えではなく問いを返す実験レビュー（A4xB5-2）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A4×B5（失敗の原因がわからない × 気軽に試して失敗できる場所がない）の版2。方向性は「2人の間をつなぐ（コミュニケーション設計）」。版1は本人の実験ノート、版3は部署の実験デーを扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門には試作機や評価ボードがあるが、若手が自由に触れる機会は少ない。

若手が評価ボードで何かを試してうまくいかなかったとき、**原因を一緒に考えてくれる人がいない**。先輩に聞くと、答えを教えてくれることはあるが、「この値じゃだめだよ、こっちにして」で終わる。答えはわかるが、なぜその値なのか、どう考えればその答えにたどり着けたのかはわからない。次に別の試しでうまくいかなかったとき、また先輩に答えを聞くしかない。若手は試すたびに先輩に頼ることになり、先輩も忙しくなる。

**誤解の実態**: Bさんは評価ボードのノイズ対策でコンデンサの値を変え、ノイズが増えてしまった。先輩に聞くと、「その値だと共振するよ。こっちの値にして」と教えてくれた。Bさんは言われた値に変え、ノイズは減った。しかし、なぜ共振したのか、どうすれば自分で気づけたのかはわからなかった。翌月、別のノイズ対策でまた同じような失敗をし、また先輩に聞いた。先輩は「前にも教えたよね」と少しいらだった。先輩は答えを教えたが、考え方は伝えていなかった。

**気づきの実態**: 先輩は、原因の考え方を知っている。しかし、教えるときは答えだけを伝える。答えを教えるほうが早いからである。若手が自分で原因にたどり着くには、先輩が答えではなく「何が起きたと思う？」「予想と何が違った？」のような問いを返すほうがよい。しかし、そのやり方は時間がかかるので、忙しい先輩は選ばない。短い時間で問いを返す型があれば、先輩も若手も続けられる。

**練習機会の実態**: 部門のOJTは、先輩が答えを教える形が中心で、問いで考えさせる形はない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。若手が同じ種類の失敗を繰り返している件数は、部門では測られていない。

## Goals / Non-Goals

**Goals**

- うまくいかなかった実験の原因を、若手が自分で考えられるようになる（レビューのうち、若手が原因の推測を自分で一つ以上言えた割合を効果指標とする）
- 同じ種類の失敗の繰り返しが減る（レビューした失敗と同じ種類の失敗が、その後に起きた件数を効果指標とする）
- 先輩の負担が増えない（1回のレビューにかかった時間を効果指標とする）

**Non-Goals**

- 技術的な正解の提示を禁じること（問いで考えても答えにたどり着かないときは、先輩が答えを言ってよい）
- 若手の理解度の評価（レビューを評価に使わない）
- 本人の実験ノート（版1）、部署の実験デー（版3）の範囲

## Proposed Solution / Feature Description

若手がうまくいかなかった実験について、**先輩と15分だけ見返す実験レビュー**の仕組みを提供する。先輩には、答えを言う代わりに使う「問いのカード」を示す。問いは「何を予想していた？」「結果はどう違った？」「何が起きたと思う？」「それを確かめるには何を測る？」の順に並ぶ。若手が答えにたどり着けなかったら、最後に先輩が答えと考え方を伝える。

**主要な構成要素**:

- **レビューの依頼** — 若手が、うまくいかなかった実験の内容（変えたもの、予想、結果）を書いて、先輩に15分のレビューを依頼する
- **問いのカード** — 先輩の画面に、4つの問いを順に表示する。先輩は問いを読み、若手の答えを聞く。若手の答えに応じて、次の問いに進むか、掘り下げる
- **若手の答えの記録** — 若手が各問いへの答えを一行ずつ書く。原因の推測にたどり着いた過程が残る
- **最後の答え合わせ** — 問いで原因にたどり着けなかった場合、先輩が答えと「どう考えればそこにたどり着けたか」を一行で伝える
- **15分の時計** — レビューの時間を15分に区切る時計を表示する

## User Stories

- **US-001 答えは教わるが考え方がわからない問題**
  利用者（Bさん）は、うまくいかなかった実験の原因を、先輩の問いに答えながら自分で考えたい。それにより、次に別の試しで失敗したときに、自分で原因にたどり着けるようになりたい。
  背景: 現状は先輩に答えだけを教わり、なぜその答えなのかがわからない。翌月に同じような失敗を繰り返し、また先輩に聞くことになる。

- **US-002 同じことを何度も教えて疲れる問題**
  利用者（先輩）は、若手に答えではなく考え方を伝え、同じことを何度も教えなくて済むようにしたい。それにより、自分の時間を守りながら若手を育てたい。
  背景: 現状は答えを教えるのが早いので答えだけを伝え、若手が同じ失敗を繰り返すたびに教え直している。

## Open Questions

- 先輩が問いで考えさせることに、15分で収まるか。答えを言いたくなる気持ちを抑えられるか
- 若手が問いに答えられず、黙ってしまう場合、どう支えるか
- **モックで確かめたいこと**: 問いのカードを順に進める流れで、若手が自分で原因の推測にたどり着ける感覚があるか
- **モックで確かめたいこと**: 先輩が問いのカードを見ながら、答えを言わずに15分を進められるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **問い詰めに感じる** — 問いが続く → 若手が試されていると感じる → レビューを避ける。軽減: 問いの言い方を柔らかくし、「わからない」も答えとして受け入れることを示す
- **先輩の時間** — 問いで考えさせると時間がかかる → 15分を超える → 先輩が嫌がる。軽減: 15分の時計を表示し、時間が来たら答え合わせに進むようにする
- **答えにたどり着かない** — 問いで考えても原因がわからない → 若手が挫折する → 試すことが怖くなる。軽減: 最後に必ず答え合わせをし、考え方も伝える
- **評価への転用** — レビューの記録が残る → 評価に使われる → 若手が依頼しなくなる。軽減: 記録は2人だけが見られる設定にする
