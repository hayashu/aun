# PRD: 議題ごとに「目的（抽象）→具体例→まとめ（抽象）」の往復の時間枠を入れる会議の往復進行キット（A3xB6-3）

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）は、電気・機械の両チームにまたがる製品改良プロジェクトの調整役を担当している。同じプロジェクトには、電気電子出身で入社3年目のBさん（20代後半）がいる。週次の定例会議には、抽象的な議論を好む課長やベテランと、具体的な事実から話す若手が出ている。

定例会議では、**抽象的な議論と具体的な報告が交互に出てくるのに、今どちらの高さで話しているかが誰にもわからない**。抽象的な人は方針を語り続け、具体的な人は細部を詰め続け、議論が噛み合わないまま時間が過ぎる。会議の最後に決まったことを聞くと、人によって答えが違う。

**誤解の実態**: 定例会議で「次の試作の方向性」が議題になった。課長は「コストと品質のバランスをどう取るか」という抽象的な話を15分続けた。Bさんは途中で「部品Aを別の型番に替えると、単価が20円下がります」と具体的な案を出したが、課長は「今はそういう細かい話じゃない」と言った。その後、ベテランが「結局、具体的に何を変えるの」と言い、議論は最初に戻った。会議は30分延び、最後にAさんが議事録をまとめようとしたが、何が決まったのかを誰も一言で言えなかった。

**気づきの実態**: 良い議論は、抽象と具体を順に往復する。「何のために（抽象）」をそろえ、「たとえば何をするか（具体）」を出し、「つまり何を決めたか（抽象）」でまとめる。会議の進行にこの往復の枠があれば、抽象的な人も具体的な人も、自分の得意な高さで話す時間がわかる。しかし今の会議には議題の一覧しかなく、高さの枠はない。

**練習機会の実態**: ファシリテーションの研修はあるが、受けた人は少なく、定例会議の進め方は主催者のやり方に任されている。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げ、職場側の「ローコンテキスト化」を対策に掲げている。会議の延長や、決定事項が曖昧なまま終わった回数は、記録されていない。

## Goals / Non-Goals

**Goals**

- 議題ごとに、抽象と具体を往復する時間の枠が決まる（往復の枠を使った議題の割合を効果指標とする）
- 会議の最後に決まったことが一言で言える（会議の最後に参加者が書いた「決まったこと」の一致度を効果指標とする）
- 会議の延長が減る（予定の時間を超えた会議の割合を効果指標とする）

**Non-Goals**

- 会議の数の削減や議題の選定（キットは議題の中の進め方を整えるもので、どの会議を開くかは扱わない）
- 参加者の発言の評価（誰が何回話したかを記録しない）
- 一人の下書き（版1）、2人の合図（版2）の範囲

## Proposed Solution / Feature Description

会議の主催者が使う**往復進行キット**を提供する。議題ごとに「目的をそろえる（抽象）」「たとえばを出す（具体）」「決めたことをまとめる（抽象）」の3つの枠と時間を設定し、会議中は画面に今の枠と残り時間を大きく表示する。枠を外れた発言は「次の枠でお願いします」と、メモ欄に一時置きする。

**主要な構成要素**:

- **議題の往復設定** — 主催者が議題ごとに、3つの枠の時間（例: 目的3分・たとえば10分・まとめ2分）を決める。議題の種類（方向性を決める／課題を解く／報告を聞く）を選ぶと、時間の配分の例が出る
- **今の枠の表示** — 会議中、画面に今の枠（「いまは『たとえば』の時間です」）と残り時間を大きく表示する。誰が見ても今の高さがわかる
- **一時置きのメモ** — 今の枠と違う高さの発言（具体の時間に出た抽象の話など）を、次の枠のメモに一時置きする。発言を否定せず、出す時間を後にずらす
- **決まったことの照らし合わせ** — まとめの枠の最後に、参加者が「決まったこと」を一行で書き、並べて表示する。ずれていれば、その場で直す

## User Stories

- **US-001 具体的な案を出すと「細かい話じゃない」と言われる問題**
  利用者（Bさん）は、会議の中で具体的な案を出してよい時間を知りたい。それにより、案を出して否定される状態を変えたい。
  背景: 現状は抽象と具体の時間の区切りがなく、具体的な案が「今はそういう話じゃない」と退けられる。

- **US-002 何が決まったのかを議事録に書けない問題**
  利用者（Aさん）は、会議の最後に決まったことを、参加者と照らし合わせたい。それにより、議事録をまとめるときに迷わないようにしたい。
  背景: 現状は会議の最後に決まったことを誰も一言で言えず、議事録が曖昧になる。

- **US-003 会議が噛み合わずに延びる問題**
  利用者（課長）は、抽象的な議論と具体的な議論が噛み合うように、会議を進めたい。それにより、会議の延長を減らしたい。
  背景: 現状は抽象と具体が交互に出て議論が最初に戻り、会議が延びる。

## Open Questions

- 枠を厳しく守ると、議論の自然な流れを壊さないか
- 主催者が、議題ごとに時間の配分を決める手間を負えるか
- 一時置きのメモに置かれた発言を、発言者が「否定された」と感じないか
- **モックで確かめたいこと**: 今の枠と残り時間の表示を見て、参加者が「いまは具体の時間だ」と一目でわかるか
- **モックで確かめたいこと**: 違う高さの発言を一時置きする操作が、発言者を否定せずに数秒で済むか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **枠の形骸化** — 主催者が枠を守らない → 表示だけが進む → 参加者が無視する。軽減: 最初は一つの議題だけで試し、効果を見てから広げる
- **議論の硬直** — 枠を守ることが目的になる → 大事な発言が後回しになる → 議論が浅くなる。軽減: 主催者が枠を延ばせるようにし、一時置きのメモは必ずまとめの前に見る
- **発言者の萎縮** — 一時置きを否定と受け取る → 発言が減る。軽減: 一時置きの表示を「次の枠で取り上げます」とし、まとめの前に読み上げる
