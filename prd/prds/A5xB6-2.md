## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）は、電気・機械の両チームにまたがる製品改良プロジェクトの調整役を担当している。同じプロジェクトには、電気電子出身で入社3年目のBさん（20代後半）がいる。2人の上司の課長は、方針や考え方を抽象的な言葉で語ることを好む。

抽象と具体の行き来は、一人の練習だけでは身につききらない。実際の会話では、**相手が抽象的な話をしているときに具体で返す、具体的な話をしているときに抽象で返す、という相手に合わせた切り替えが求められる**。しかし、その切り替えを練習する相手がいない。上司相手では失敗できず、同期相手では照れくさい。

**誤解の実態**: Bさんは課長との会話で、課長が抽象的な方針を話しているときに、すぐ具体的な部品の話を返してしまい、「今はそういう話じゃない」と言われることが多かった。逆に、Aさんは、Bさんが具体的な試作の状況を話しているときに、「つまり方向性としては」と抽象的にまとめすぎて、Bさんに「いや、そこまでは言っていない」と言われた。2人とも、相手の話の高さに合わせて返す練習をしたことがなかった。2人は同じプロジェクトにいて話す機会は多いが、練習として話したことはなかった。

**気づきの実態**: 2人で役を決めて、同じ題材を話せば練習になる。一人が「抽象役」として方針を話し、もう一人が「具体役」として例で返す。次に役を交代する。役を演じていれば、失敗しても自分の評価にはならない。Aさんは抽象的な日本語の幅をつかみ、Bさんは抽象へ上げる経験を積める。異なる文化の人と話すことにやりがいを感じるBさんにとって、Aさんとの練習は続けやすい。

**練習機会の実態**: 部門のOJTは業務を通じて行われ、会話の練習をする時間や仕組みはない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。社員どうしが会話の練習をする機会の有無は、部門では把握されていない。

## Goals / Non-Goals

**Goals**

- 2人が、役を交代しながら抽象と具体の切り替えを練習できる（ペアで練習した回数と、役を交代した回数を効果指標とする）
- 相手の話の高さに合わせて返せるようになる（練習のあとの「相手の高さに合わせて返せた」の自己申告を効果指標とする）
- 練習が続く（4週間続けたペアの割合を効果指標とする）

**Non-Goals**

- 相手の評価・採点（練習は役を演じるもので、相手の上手下手を点数にしない）
- 会話の録音（記録されると、気軽に失敗できなくなる）
- 一人のドリル（版1）、部署のワークショップ（版3）の範囲

## Proposed Solution / Feature Description

2人で使う**役割交代の練習ペア**をWebで提供する。週に一度10分、題材カードを一枚引き、一人が「抽象役」、もう一人が「具体役」になって3往復話す。次に役を交代して3往復話す。最後に、お互いに「相手の返しで良かった一つ」を選択式で伝える。

**主要な構成要素**:

- **題材カード** — ものづくりの現場の題材（「次の試作で大事にしたいこと」「良い設計レビューとは」など）を一枚引く。2人が自分の題材を足すこともできる
- **役と往復のタイマー** — 画面に今の役（抽象役／具体役）と、何往復目かを表示する。抽象役には「方針・理由・目的で話す」、具体役には「例・数字・場面で返す」の一言のヒントを出す
- **役の交代** — 3往復したら、画面が役を入れ替える。同じ題材で逆の役をすることで、両方の高さを経験する
- **良かった一つ** — 最後に、お互いに相手の返しで良かった点を一つ、選択式（「例がわかりやすかった」「まとめが短かった」など）と一行で伝える。直したほうがよい点は伝えない
- **練習の記録** — 引いた題材と、役ごとの回数だけを記録する。会話の中身は記録しない

## User Stories

- **US-001 相手の話の高さに合わせて返せない問題**
  利用者（Bさん）は、抽象的な話に具体で返す、具体的な話に抽象で返す練習を、失敗しても困らない相手としたい。それにより、課長に「今はそういう話じゃない」と言われる状態を変えたい。
  背景: 現状は相手の話の高さに合わせて返す練習をしたことがない。

- **US-002 抽象的にまとめすぎる問題**
  利用者（Aさん）は、具体役を演じることで、相手の具体的な話をそのまま受け止める練習をしたい。それにより、まとめすぎて相手に否定される状態を変えたい。
  背景: 現状は相手の具体的な話を、抽象的にまとめすぎてしまう。

## Open Questions

- 週に10分の練習を、業務の時間として認めてもらえるか
- 2人の組み合わせ（AさんとBさん以外）をどう作るか
- 題材カードが、現場の会話に近いものを用意できるか
- **モックで確かめたいこと**: 役のヒントとタイマーを見ながら3往復話す流れが、照れずに始められる程度に軽いか
- **モックで確かめたいこと**: 最後に「良かった一つ」だけを伝え合う形が、次も練習したいと思える終わり方になっているか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **照れくささ** — 同じ職場の人と練習するのが恥ずかしい → 始めない → 仕組みが使われない。軽減: 役と題材を画面が決め、「役を演じている」形にする
- **続かない** — 業務が忙しい → 練習が止まる。軽減: 1回10分に限り、日程を決めずに気が向いたときにできる形にする
- **評価への転用** — 練習の記録が残る → 評価に使われる → 練習が義務になる。軽減: 記録は回数だけにし、2人だけが見られる設定にする
