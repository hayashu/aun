# PRD: 「好きにいじっていいよ」の本当の範囲を読む練習ができる許可ことばトレーナー（A1xB5-1）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A1×B5（相手の真意がわからない × 気軽に試して失敗できる場所がない）の版1。方向性は「当事者の行動を支える（個人向けツール）」。版2は機材の持ち主と使い手の間、版3は部署の試せる場の制度を扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門には試作機や評価ボード、測定器があるが、若手が自由に触れる機会は少ない。

2人とも、実物を触って試したいと思っている。しかし、先輩や上司の「好きにいじっていいよ」「壊さないでね」「空いてたら使っていいよ」という言葉が、**どこまでの許可なのかを読み取れない**。とくにBさんは、ハードウェアを壊すことへの不安が強く、許可の範囲がわからないと手を出せない。結果として、2人とも実物に触れないまま時間が過ぎる。

**誤解の実態**: 先輩はBさんに、旧型の評価ボードを渡して「好きにいじっていいよ」と言った。Bさんは、ハンダ付けで部品を付け替えてよいのか、電源を入れて測るだけなのかがわからず、結局ほとんど触らずに返した。先輩は「興味がないのか」と受け取った。一方Aさんは、測定器について「空いてたら使っていいよ」と言われ、予約表に書かずに使った。実は予約表に書くのが暗黙のルールで、別の人の測定とぶつかり、注意を受けた。2人とも、その後は実物に触ることをためらうようになった。

**気づきの実態**: 許可の言葉には、言われていない条件が含まれている。「好きにいじっていい」は「壊れても困らない範囲なら」、「空いてたら使っていい」は「予約表で確かめてから」の意味を含むことが多い。2人はその条件を推測できず、「どこまでですか」と確かめる一言も持っていない。確かめずに動けば外し、外すのが怖ければ動かない。

**練習機会の実態**: 許可の言葉の読み方を学ぶ場はない。実際の職場で外せば、機材を壊したり、他人の作業を止めたりする代償がある。だから、外してみる経験を安全に積むことができない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。若手が実物に触れる機会の少なさは、部門では測られていない。

## Goals / Non-Goals

**Goals**

- 許可の言葉の範囲を確かめずに、触らないまま終わる件数が減る（許可を受けた機材のうち、本人が実際に使った割合を効果指標とする）
- 許可の範囲を読み違えて注意を受ける件数が減る（機材の使い方で注意を受けた件数の自己申告を効果指標とする）
- 許可の範囲を確かめる一言を出せるようになる（許可を受けたときに範囲を確かめた割合を効果指標とする）

（一つめと二つめは逆向きの失敗である。動かないことと、動いて外すことの両方を減らす。三つめはその両方に効く）

**Non-Goals**

- 機材の操作方法の教育（既存の手順書と研修の領域）
- 許可の範囲の断定（職場や人によって違い、断定すれば誤った確信を与える）
- 機材の持ち主と使い手の間の取り決め（版2）、部署の制度（版3）の範囲

## Proposed Solution / Feature Description

機材や試作品に関する「許可っぽい言葉」の場面を示し、**先に自分で許可の範囲を選ばせてから、ありうる条件と確かめる一言を返す**練習用Webツールを提供する。さらに、本人が実際に言われた許可の言葉を入力し、同じ手順で確かめる一言を作れる。外しても代償のない場所で、許可の範囲を読む経験を積む。

**主要な構成要素**:

- **場面と許可の言葉の設問** — 「先輩が旧型の評価ボードを渡して『好きにいじっていいよ』と言った」のような場面を示す。本人は「見るだけ／電源を入れて測る／部品を付け替える／分解する」のどこまでが許されるかを選ぶ
- **ありうる条件** — 答えたあとに、その言葉に含まれやすい条件（壊れても困らない範囲、予約表で確かめる、使ったら元に戻す）を候補で示す。一つの正解は出さない
- **確かめる一言** — 「部品の付け替えまでやってみてもいいですか」「壊してしまったら困るところはありますか」のように、範囲を確かめる一言を選ばせ、自分の言葉に直させる
- **自分が言われた言葉** — 実際に受けた許可の言葉を入力し、同じ手順で範囲を考え、確かめる一言を作る
- **外し方の記録** — 設問で読み違えた型（範囲を狭く見すぎ／広く見すぎ）を集計し、本人の傾向を示す。狭く見すぎる人には「確かめれば広がる」ことを、広く見すぎる人には「確かめてから動く」ことを返す

## User Stories

- **US-001 「好きにいじっていいよ」で何もできない問題**
  利用者（Bさん）は、許可の言葉がどこまでを含むのかを、その場で確かめる一言を持ちたい。それにより、壊すのが怖くて触らないまま返し、興味がないと思われる事態を避けたい。
  背景: 現状は許可の範囲がわからず、最も安全な「触らない」を選ぶ。機会は戻ってこず、先輩は次から声をかけなくなる。

- **US-002 「空いてたら使っていいよ」で暗黙のルールを外す問題**
  利用者（Aさん）は、許可の言葉に含まれた条件を、使う前に確かめたい。それにより、予約表に書かずに使って他の人の作業とぶつかる事態を避けたい。
  背景: 現状は言葉どおりに受け取って使い、注意を受けて初めて条件を知る。注意を受けたあとは、使うこと自体をためらうようになる。

## Open Questions

- 設問の場面を、本人の職場の機材と慣習にどこまで合わせられるか
- 「範囲を狭く見すぎる」傾向の人に、確かめる一言を出す勇気をどう持たせるか。知識だけでは行動が変わらないかもしれない
- **モックで確かめたいこと**: 範囲を「見るだけ／測る／付け替える／分解」の段階で選ばせる形が、許可の幅を考えるきっかけになるか
- **モックで確かめたいこと**: 外し方の記録で「狭く見すぎ」と示されたとき、責められた感じではなく「確かめれば広がる」と前向きに受け取れるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **範囲の一般化** — 典型的な条件を示す → 「好きにいじっていい＝付け替えまで」と覚える → 職場の実態と合わずに壊す。軽減: 条件は候補として示し、確かめる一言を必ず添える
- **練習止まり** — 設問は解ける → 実際の場面で確かめる一言が出ない → 行動が変わらない。軽減: 自分が言われた言葉の入力から、確かめる一言を作るまでをひと続きにする
- **不安の増幅** — 許可の言葉の裏に条件があると知る → すべての許可を疑う → かえって触れなくなる。軽減: 「本当に自由にしてよい」場合も候補として示す
- **文化的な単純化** — 「日本の許可は条件付き」と一般化する → 偏見を強める。軽減: 個人差・職場差を前提にし、本人の振り返りから傾向を学ぶ形にする
