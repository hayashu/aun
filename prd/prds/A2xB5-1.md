# PRD: 試作室や測定器を初めて使う前に「確かめること」と「聞く相手」を並べる初回利用ナビ（A2xB5-1）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A2×B5（暗黙の期待・ルールがわからない × 気軽に試して失敗できる場所がない）の版1。方向性は「当事者の行動を支える（個人向けツール）」。版2は先輩の初回付き添い、版3は試作室のルールの明文化とお試し枠を扱う。A1×B5（許可の言葉の範囲）とは異なり、本セルは「設備の使い方の暗黙ルール」を扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門には試作室があり、はんだ付けの設備、オシロスコープ、恒温槽などが置かれている。

試作室には、**誰も書いていない使い方のルール**がある。予約は紙の予約表に書く、恒温槽は前日までに担当者に一声かける、使ったあとは測定器の設定を初期値に戻す、昼休みは常連の先輩が使う、などである。長くいる人は自然に守っているが、2人は知らない。Bさんはもともと、ハードウェアを壊すことへの不安が強く、ルールがわからない場所ではなおさら手を出せない。

**誤解の実態**: Bさんは試作基板の温度特性を調べたいと考え、恒温槽を使おうとした。空いていたので設定を始めたところ、品質の担当者が来て「明日から長期試験で使うから、今日は触らないで」と言われた。前日に担当者へ一声かけるのが暗黙のルールだった。Bさんは謝ってその場を離れ、その後は試作室に入るのをためらうようになった。Aさんはオシロスコープを使ったあと、設定をそのままにして戻り、次の人から苦情が出た。

**気づきの実態**: 2人とも、ルールがあるかもしれないとは感じていた。しかし、何を確かめればよいのかがわからなかった。「この設備を使う前に、誰に何を確かめるべきか」の一覧があれば、事前に聞くことができた。今は、外して注意されることでしかルールを知る方法がない。注意されるたびに、試作室に入る心理的な敷居が上がる。

**練習機会の実態**: 試作室の入口には安全上の注意書きがあるが、予約や片付けの作法は書かれていない。新人研修で試作室を見学したが、使い方の作法は説明されなかった。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。若手が試作室を使う頻度は、部門では測られていない。

## Goals / Non-Goals

**Goals**

- 試作室の暗黙のルールを外して注意を受ける件数が減る（試作室の使い方で注意を受けた件数の自己申告を効果指標とする）
- 若手が試作室を使う頻度が増える（月あたりの試作室の利用回数の自己申告を効果指標とする）
- 初めて使う設備でも、事前に確かめてから使える（初めて使う設備のうち、確認リストを見てから使った割合を効果指標とする）

**Non-Goals**

- 設備の操作方法の教育（既存の操作手順書と研修の領域）
- 試作室の予約システムの置き換え（予約は既存の方法で行う）
- 先輩の付き添い（版2）、試作室のルールの明文化（版3）の範囲

## Proposed Solution / Feature Description

試作室の設備を初めて使う前に、**使いたい設備と目的を選ぶと、「使う前に確かめること」と「聞く相手」を一覧で示す**個人向けWebツールを提供する。一覧には、予約の方法、事前に一声かける相手、使ったあとの片付け、混む時間帯などが並ぶ。本人は一つずつ確かめ、わからないものは聞く相手に聞く。

**主要な構成要素**:

- **設備と目的の選択** — 使いたい設備（恒温槽、オシロスコープ、はんだ付け設備など）と目的（短時間の測定、長時間の試験など）を選ぶ
- **確かめることの一覧** — 選んだ組み合わせに対して、「予約表に書く」「前日に担当者へ一声」「使用後は設定を初期値に」のような項目を示す。最初は一般的な候補で、使ううちに本人の職場に合ったものになる
- **聞く相手** — 各項目について、誰に聞けばよいか（設備の担当者、よく使う先輩）を示す。聞く一言の例も添える
- **確かめた印** — 確かめた項目に印を付ける。すべて確かめたら「使う準備ができました」と表示し、試作室に入る心理的な敷居を下げる
- **自分のルール帳** — 実際に使って知ったルールや、注意されたことを書き足せる。次に同じ設備を使うときには、書き足した項目も一覧に出る

## User Stories

- **US-001 暗黙のルールを外して注意され、試作室に入れなくなる問題**
  利用者（Bさん）は、試作室の設備を初めて使う前に、確かめるべきことを一覧で知りたい。それにより、前日の一声を知らずに注意され、試作室に入るのをためらうようになる事態を避けたい。
  背景: 現状はルールを外して注意されることでしか知る方法がない。注意されるたびに、試せる場所が心理的に遠のく。

- **US-002 使ったあとの作法を知らずに苦情が出る問題**
  利用者（Aさん）は、設備を使ったあとに何をすればよいかを知りたい。それにより、次の人に迷惑をかけて苦情が出る事態を避けたい。
  背景: 現状は片付けの作法が書かれておらず、外して初めて知る。

## Open Questions

- 確かめることの一覧の初期値を、誰が作るか。設備の担当者に確かめてもらう必要がある
- 試作室ごとにルールが違う。部門の試作室が複数ある場合、どう扱うか
- **モックで確かめたいこと**: 設備と目的を選んで一覧が出て、すべて確かめるまでの流れが、試作室に行く前の5分で終わるか
- **モックで確かめたいこと**: 「使う準備ができました」の表示を見て、試作室に入る不安が和らぐか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **一覧の不正確さ** — 一般的な候補が職場と合わない → 確かめたのに外す → かえって不安が増す。軽減: 設備の担当者に一覧を確かめてもらい、自分のルール帳で上書きできるようにする
- **聞く相手の負担** — 若手が担当者に聞きに行く → 担当者の手間が増える → 担当者が面倒がる。軽減: 一覧で解決できることを増やし、聞くのは本当にわからないことに絞る
- **確認疲れ** — 毎回一覧を確かめる → 面倒になる → 使わなくなる。軽減: 一度使った設備は、変更点だけを表示する
- **安全情報の誤解** — 一覧に安全上の注意を含めない → 一覧だけで十分と思う → 事故が起きる。軽減: 安全上の注意は既存の手順書に従うことを毎回表示する
