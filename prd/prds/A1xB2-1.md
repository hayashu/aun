# PRD: 先輩の「追々わかるよ」を、今週やる学習課題に変える質問ノート（A1xB2-1）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A1×B2（相手の真意がわからない × ハードウェアの知識が足りず焦る）の版1。方向性は「当事者の行動を支える（個人向けツール）」。版2は質問する人と答える人の間、版3は部署の教える仕組みを扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門は機械系の社員が多く、筐体・機構・材料の知識が前提として会話が進む。

2人とも、ハードウェアの知識が足りないことに焦っている。わからないことを先輩に聞くと、返事は「まあ、それは追々わかるよ」「基礎からやっといたほうがいいね」のような言葉で返ってくる。**その返事が「今は説明する時間がない」なのか、「自分で調べてほしい」なのか、「知らなくても今は困らない」なのかを読み分けられない**。

**誤解の実態**: Bさんは機械の先輩に、筐体の板厚の決め方を聞いた。先輩は「それは追々わかるよ」と答えた。Bさんは「今は知らなくてよい」と受け取って質問をやめた。翌週の設計レビューで、Bさんの基板配置が板厚の制約と合わないことが指摘され、先輩から「この前聞いてたよね、調べなかったの？」と言われた。先輩は「自分で調べてね」のつもりだった。Aさんは別の先輩に「基礎からやったほうがいい」と言われ、材料力学の教科書を最初から読み始めたが、1か月たっても業務で使う範囲にたどり着かなかった。

**気づきの実態**: 返事の意味を確かめる一言があれば、ずれは防げた。「どこを調べればよいですか」「来週のレビューまでに知っておくべきですか」と聞き返せば、先輩は答えたはずである。2人はその一言を出す発想がなく、先輩の機嫌を損ねるのではないかと心配して聞き返さない。焦っているほど、聞き返さずに一人で抱え込む。

**練習機会の実態**: 社内のeラーニングは体系的だが、目の前の業務に必要な範囲を教えてくれない。先輩の返事を学習計画に変える手助けはどこにもない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。若手が業務知識を身につけるまでの期間は、部門では測られていない。

## Goals / Non-Goals

**Goals**

- 先輩の曖昧な返事を受けたあと、確かめずに放置する件数が減る（記録した返事のうち、確認の一言を出した割合を効果指標とする）
- 学習の範囲が業務に近づく（学習課題のうち、2週間以内の業務に関係するものの割合を効果指標とする）
- 知識不足への焦りが下がる（「何から学べばよいかわかっている」の自己申告を効果指標とする）

**Non-Goals**

- ハードウェア知識そのものの教材化（既存の教科書やeラーニングの領域。扱うのは返事を学習課題に変えることである）
- 先輩の本心の断定（言葉から本心は確定できない）
- 先輩への質問の代行（本人の関係づくりにならない）
- 答える側の仕組みづくり（版2・版3の範囲）

## Proposed Solution / Feature Description

先輩に聞いた質問と返ってきた言葉を記録すると、**先に自分で返事の意味を選ばせ、そのあとで解釈の幅と確かめる一言を返し、最後に今週やる学習課題に分解させる**個人向けWebツールを提供する。返事の読み違えを防ぐことと、焦りを具体的な一歩に変えることを、ひと続きで行う。

**主要な構成要素**:

- **質問と返事の記録** — 何を聞き、どんな言葉が返ってきたかを書く。質問の期限（いつまでに必要か）も選ぶ
- **自分の読み** — 解説を見る前に、返事が「今は時間がない／自分で調べて／今は知らなくてよい／基礎から学べ」のどれに近いかを選ぶ
- **解釈の幅と確かめる一言** — 返事がとりうる意味を候補で示し、「来週のレビューまでに必要ですか」「最初に見るべき資料はありますか」のような確かめる一言を選ばせる
- **学習課題への分解** — 返事と業務の期限から、「今週読む資料の章」「実物で確かめること」「次に聞くこと」の三つに分ける。範囲は本人が決め、候補は例として示す
- **知識マップ** — 記録した質問を分野ごとに並べ、どこを学んだか、どこがまだかを見えるようにする。焦りを「わからないことの量」ではなく「次の一歩」に置き換える

## User Stories

- **US-001 「追々わかるよ」で質問をやめてしまう問題**
  利用者（Bさん）は、先輩の曖昧な返事が「今は不要」なのか「自分で調べて」なのかを、その場で確かめる一言を持ちたい。それにより、調べるべきことを調べずにレビューで指摘される事態を避けたい。
  背景: 現状は返事を「今は不要」と受け取って質問をやめる。ずれは翌週のレビューで指摘として現れ、そのときには修正の手戻りが確定している。

- **US-002 「基礎から」で遠回りする問題**
  利用者（Aさん）は、「基礎から学べ」と言われたとき、業務に必要な範囲から学び始めたい。それにより、教科書を最初から読んで1か月たっても業務に届かない状態を避けたい。
  背景: 現状は返事を言葉どおりに受け取り、範囲を絞る方法がわからない。

## Open Questions

- 学習課題の候補を、業務の分野ごとにどこまで用意できるか。候補が的外れなら本人はすぐ使わなくなる
- 先輩の言葉を記録することに抵抗はないか
- **モックで確かめたいこと**: 返事の記録から学習課題への分解までを、5分以内に終えられるか
- **モックで確かめたいこと**: 知識マップを見たときに、焦りが和らぐ感覚があるか（逆に「わからないことの多さ」が目立って焦りが増えないか）

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **先輩を疑う道具になる** — 返事を分析する → すべてを裏読みする → 聞くこと自体が怖くなる。軽減: 解釈の幅は確かめる材料として示し、確かめる一言とセットでしか出さない
- **課題の積み上げで焦りが増す** — 学習課題が増え続ける → 消化しきれない → かえって焦る。軽減: 課題は一度に三つまでとし、終わらないものは次週に送れるようにする
- **教材との誤認** — 学習ツールに見える → eラーニングと比べられる → 差別性を失う。回避: 教材を持たず、本人の質問と返事から始まる形を守る
- **文化的な単純化** — 「先輩の言葉は遠回し」と一般化する → 先輩個人の実態と合わない → 偏見を強める。軽減: 振り返りから相手ごとの傾向を本人が学べるようにする
