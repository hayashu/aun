# PRD: 根回し不要で誰でも5分で「作ってみたいもの」を出せる、部署の月例ものづくり提案会（A3xB1-3）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A3×B1（適切なコミュニケーション方法がわからない × やりたいものづくりができない）の版3。方向性は「場・仕組みを変える（チーム／組織向け）」。版1は本人の提案の組み立て、版2は上司との1on1の質問カードを扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門の業務の多くは会議資料のパワーポイント作成で、実際に手を動かして作る機会は少ない。

部門で新しいことを始めるには、**暗黙の手順**がある。まず係長に相談し、課長に話を通し、関係する部署に一声かけ、それから会議に出す。この根回しの手順を知っている人の提案は通り、知らない人の提案は「聞いていない」で止まる。若手や外国籍社員は、この手順を知らないか、知っていても誰にどう話せばよいかわからない。結果として、ものづくりの提案は、根回しが得意な一部の人からしか出てこない。

**誤解の実態**: Bさんは、評価用の簡易な治具を自作したいと考え、課の定例会議でいきなり提案した。課長は「事前に相談してほしかった」と言い、係長は「聞いていない」という顔をした。提案は「持ち帰って検討」で終わった。同じ時期、別の課の中堅社員は、同じような治具の自作を、係長と課長に順に相談してから提案し、すぐに承認された。Aさんも、根回しの手順を知らないために、提案を出すこと自体をためらっていた。

**気づきの実態**: 問題は、個人が根回しの手順を知らないことだけではない。**提案の通り方が、根回しの上手さに左右される仕組み**になっていることが原因である。根回しの手順を知らなくても、内容で判断される公式の場があれば、若手や外国籍社員も提案を出せる。

**練習機会の実態**: 部門には業務改善提案の制度があるが、年に一度の書類提出で、審査に数か月かかる。ものづくりの小さな提案を、気軽に出して早く判断してもらえる場はない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げ、職場側の「ローコンテキスト化」を対策に掲げている。部門のものづくりの提案が、誰からどれだけ出ているかは測られていない。

## Goals / Non-Goals

**Goals**

- ものづくりの提案が、根回しの上手さに関係なく出される（提案会の提案者のうち、入社5年以内または外国籍の社員の割合を効果指標とする）
- 提案が早く判断される（提案から、可否が決まるまでの日数を効果指標とする）
- 実際にものづくりの機会が増える（提案会で承認された提案の数を効果指標とする）

**Non-Goals**

- 業務改善提案制度の置き換え（大きな改善は既存の制度で扱い、提案会は小さなものづくりに限る）
- 提案者の評価（提案の数や採否を人事評価に使わない）
- 根回しの禁止（根回しをしてもよいが、しなくても提案できる場をつくる）
- 本人の提案の組み立て（版1）、1on1の質問カード（版2）の範囲

## Proposed Solution / Feature Description

部署で**月に一度、30分の「ものづくり提案会」**を開き、その運営をWebで支える仕組みを提供する。誰でも、根回しなしで、5分以内で「作ってみたいもの」を提案できる。提案は事前にWebの1枚の書式で登録し、提案会では課長と係長がその場で「やってみよう／条件付きでやってみよう／今回は見送り（理由）」を決める。

**主要な構成要素**:

- **提案の登録** — 作ってみたいもの、業務とのつながり、必要な時間と材料を、1枚の書式で登録する。登録は提案会の3日前まで
- **提案会の進行** — 当日、登録順に提案者が5分で説明する。進行役の画面に、提案の一覧と残り時間を表示する
- **その場の判断** — 各提案について、課長と係長がその場で三択から決める。見送りの場合は理由を一行書く。「持ち帰って検討」は選べない
- **試作の時間の確保** — 承認された提案には、試作の時間（月何時間か）が割り当てられる。業務時間として認める
- **結果の共有** — 承認された提案の試作結果を、次の提案会の冒頭で2分ずつ共有する
- **提案の一覧** — 過去の提案と判断を一覧で見られる。提案者の名前は本人の希望で伏せられる

## User Stories

- **US-001 根回しを知らずに提案して止まる問題**
  利用者（Bさん）は、根回しの手順を知らなくても、ものづくりの提案を内容で判断してもらいたい。それにより、「聞いていない」で提案が止まる事態を避けたい。
  背景: 現状は根回しの上手さで提案の通り方が決まり、手順を知らない人の提案は会議で止まる。

- **US-002 提案を出すこと自体をためらう問題**
  利用者（Aさん）は、提案を出してよい公式の場がほしい。それにより、根回しの手順がわからないために提案をためらう状態を変えたい。
  背景: 現状は提案を出す正式な経路が年に一度の制度しかなく、小さな提案を気軽に出せない。

- **US-003 若手からの提案が少ない問題**
  利用者（部門長）は、若手や外国籍社員からも、ものづくりの提案が出てくる場をつくりたい。それにより、根回しが得意な一部の人だけが機会を得る状態を変えたい。
  背景: 現状は提案の多くが中堅以上から出ており、若手の希望が見えない。

## Open Questions

- 課長と係長が、その場で判断することに抵抗はないか。予算や人の都合で、その場で決められない提案もある
- 月に一度の提案会に、十分な数の提案が集まるか
- 根回しをした提案と、しなかった提案が、提案会で公平に扱われるか
- **モックで確かめたいこと**: 提案の登録書式が、根回しなしでも業務とのつながりを伝えられる形になっているか
- **モックで確かめたいこと**: 進行役の画面で、5分の説明と三択の判断がテンポよく進められるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **提案が集まらない** — 提案会を開いても誰も出さない → 会が形だけになる → 中止される。軽減: 最初の数回は、課長が若手に声をかけて提案を出してもらう
- **その場の判断の難しさ** — 予算がわからない → 判断できない → 「持ち帰り」に戻る。軽減: 条件付き承認の条件に「予算の確認後」を選べるようにし、判断の期限を決める
- **見送りの心理的負担** — 人前で見送られる → 提案者が傷つく → 次から出さない。軽減: 見送りの理由を一行で示し、次に出し直す方法を添える
- **根回し文化との衝突** — 根回しを重んじる管理職が反発する → 提案会が支持されない → 導入が止まる。回避: 根回しを禁止するのではなく、しなくてもよい場を加えるものとして説明する
