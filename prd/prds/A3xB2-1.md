# PRD: 聞く前に「どこまで調べたか・何を聞きたいか・誰にいつ聞くか」を整える質問の下ごしらえツール（A3xB2-1）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A3×B2（適切なコミュニケーション方法がわからない × ハードウェアの知識が足りず焦る）の版1。方向性は「当事者の行動を支える（個人向けツール）」。版2は分野をまたぐ教え合いのペア、版3は部署の質問タイムを扱う。A1×B2（返事の真意）、A2×B2（暗黙の前提知識）とは異なり、本セルは「質問の仕方」を扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門は機械系の社員が多く、筐体・機構・材料の知識が前提として会話が進む。

2人はハードウェアの知識が足りないことに焦り、先輩によく質問する。しかし、**質問の仕方がうまくいかない**。何も調べずに聞いて「まず自分で調べた？」と言われる。逆に調べすぎて一人で何日も抱え込む。忙しいときに聞いて嫌な顔をされる。質問が漠然としていて、先輩が何を答えればよいかわからない。質問がうまくいかないと、聞くこと自体が怖くなり、知識不足はさらに広がる。

**誤解の実態**: Bさんは、筐体の材料の選び方がわからず、機械の先輩に「材料ってどうやって選ぶんですか」と聞いた。先輩は図面の締め切り前で、「それは範囲が広すぎるな、まず社内の材料基準を見てみて」と短く答えた。Bさんは突き放されたと感じ、その後は聞くのをためらうようになった。Aさんは逆に、熱解析の設定がわからず、3日間一人で調べ続けた。先輩に聞けば10分で解決する内容だった。

**気づきの実態**: 質問がうまくいくかどうかは、質問の中身よりも、**準備と形とタイミング**で決まることが多い。「〇〇を調べて、ここまではわかったが、ここがわからない」と聞けば、先輩は答えやすい。忙しい時間を避ければ、丁寧に答えてもらえる。2人はこの質問の型を知らず、うまくいかなかった理由もわからない。

**練習機会の実態**: 質問の仕方を教わる機会はない。報連相の研修では「わからないことは聞く」と教えるが、どう聞けばよいかは教えない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。若手が質問をためらって一人で抱え込んでいる時間は、部門では測られていない。

## Goals / Non-Goals

**Goals**

- 質問が先輩に答えやすい形で出る（質問のうち、先輩から一度で答えが返ってきた割合を効果指標とする）
- 一人で抱え込む時間が減る（わからないことに気づいてから質問するまでの時間の自己申告を効果指標とする）
- 質問することへのためらいが減る（「先輩に質問しやすい」の自己申告を効果指標とする）

**Non-Goals**

- 質問への自動回答（答えるのは先輩で、ツールは質問の準備を支えるだけである）
- ハードウェア知識の教材化（既存の教科書と研修の領域）
- 分野をまたぐ教え合い（版2）、部署の質問タイム（版3）の範囲

## Proposed Solution / Feature Description

先輩に質問する前に、**「何を知りたいか」「どこまで調べたか」「どこがわからないか」「誰にいつ聞くか」の4つを整える**個人向けWebツールを提供する。整えたあと、質問の文を一つにまとめて示す。さらに、調べ始めてから一定の時間がたったら「そろそろ聞いてよい頃です」と知らせ、抱え込みすぎを防ぐ。

**主要な構成要素**:

- **知りたいことの絞り込み** — 知りたいことを書くと、範囲が広すぎる場合に「いまの業務で必要なのはどの部分か」を答えさせて絞る（例:「材料の選び方」→「この筐体で使える樹脂の候補」）
- **調べた範囲** — どの資料を見て、何がわかったかを一行ずつ書く。調べた範囲を書くことで、先輩は何を答えればよいかがわかる
- **わからない点** — 調べた結果、どこがわからないかを一つに絞って書く
- **聞く相手とタイミング** — 分野に詳しい人を選び、聞くタイミング（相手が忙しそうでない時間、チャットか対面か）を決める
- **質問文のまとめ** — 4つの答えから、「〇〇について、△△を見て□□まではわかりました。××がわからないのですが、教えていただけますか」という形の質問文を作る。本人の言葉に直させる
- **抱え込み時計** — 調べ始めてから決めた時間（例: 1時間）がたったら、「そろそろ聞いてよい頃です」と知らせる

## User Stories

- **US-001 漠然とした質問で突き放されたと感じる問題**
  利用者（Bさん）は、先輩に質問する前に、知りたいことを絞り、調べた範囲を伝えられる形に整えたい。それにより、「範囲が広すぎる」と言われて聞くのが怖くなる事態を避けたい。
  背景: 現状は思いついたままに質問し、先輩が答えにくい形になる。短い返事を突き放されたと受け取り、次から聞かなくなる。

- **US-002 調べすぎて一人で何日も抱え込む問題**
  利用者（Aさん）は、一人で調べる時間の目安を持ち、そろそろ聞くべき頃を知りたい。それにより、10分で解決することに3日を使う事態を避けたい。
  背景: 現状は「自分で調べてから聞く」を守ろうとして、どこまで調べればよいかわからず抱え込む。

## Open Questions

- 抱え込み時計の時間を、何を基準に決めるか。わからないことの種類によって違う
- 質問文を整える手間が、かえって質問のハードルを上げないか
- **モックで確かめたいこと**: 4つの項目を埋めて質問文ができるまでが、3分以内で終わるか
- **モックで確かめたいこと**: 範囲が広い質問を絞り込む流れで、本人が「これなら聞ける」と感じられるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **質問のハードルが上がる** — 準備に手間がかかる → 質問するのが面倒になる → 質問が減る。軽減: 急ぎのときは「わからない点」だけで質問文を作れる短い流れを用意する
- **型通りの質問** — どの質問も同じ形になる → 先輩が機械的に感じる → 関係が冷える。軽減: 質問文は候補として示し、本人の言葉に直すことを求める
- **時計の圧迫感** — 時計が動く → 焦りが増す → 調べることに集中できない。軽減: 時計は「聞いてよい頃」の目安として示し、責める表示にしない
- **相手の偏り** — 詳しい先輩ばかりを選ぶ → その人の負担が増える → 答えが遅くなる。軽減: 同じ分野の詳しい人を複数示す
