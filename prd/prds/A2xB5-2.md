# PRD: 慣れた先輩が初回だけ一緒に使い、暗黙のルールをその場で伝える試作室の付き添い予約（A2xB5-2）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A2×B5（暗黙の期待・ルールがわからない × 気軽に試して失敗できる場所がない）の版2。方向性は「2人の間をつなぐ（コミュニケーション設計）」。版1は個人の初回利用ナビ、版3は試作室のルールの明文化とお試し枠を扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門には試作室があり、はんだ付けの設備、オシロスコープ、恒温槽などが置かれている。

試作室の使い方の暗黙のルールは、**一緒に使ったことのある人から人へ伝わる**。長くいる人は、先輩と一緒に作業する中で、予約の書き方や片付けの作法を自然に覚えた。しかし、ここ数年は試作の機会が減り、若手が先輩と一緒に試作室に入る機会がほとんどない。ルールを伝える経路が途切れている。

**誤解の実態**: Bさんは恒温槽を使おうとして、品質の担当者から「明日から長期試験だから触らないで」と言われた。前日に一声かけるのがルールだった。Aさんはオシロスコープの設定を戻さずに戻り、苦情が出た。2人とも、先輩と一緒に試作室を使ったことが一度もなかった。一方、部門には試作室の常連で、若手に教えたいと思っている先輩が何人かいた。先輩たちは、若手が試作室に来ないのは興味がないからだと思っていた。

**気づきの実態**: ルールを知っている先輩と、知りたい若手がいるのに、両者がつながる場面がない。若手は先輩の時間を取ることをためらい、先輩は若手が困っていることを知らない。一度一緒に使えば、ルールはその場で伝わる。文書で読むよりも、隣で見るほうが早く確実に覚えられる。

**練習機会の実態**: 試作室の利用は個人の予約で行われ、誰と一緒に使うかを調整する仕組みはない。OJTの計画にも、試作室の使い方は含まれていない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。若手が先輩と一緒に試作室を使った回数は、部門では測られていない。

## Goals / Non-Goals

**Goals**

- 若手が試作室の設備を初めて使うときに、慣れた人が付き添う（初めて使う設備のうち、付き添いがあった割合を効果指標とする）
- 暗黙のルールを外して注意を受ける件数が減る（付き添いを受けた若手が、その設備の使い方で注意を受けた件数を効果指標とする）
- 付き添いのあと、若手が一人で試作室を使えるようになる（付き添いのあと1か月以内に、同じ設備を一人で使った割合を効果指標とする）

**Non-Goals**

- 設備の操作研修の置き換え（付き添いは暗黙のルールを伝える場で、操作の研修ではない）
- 先輩の指導力の評価（付き添いの回数を評価に使わない）
- 個人の初回利用ナビ（版1）、試作室のルールの明文化（版3）の範囲

## Proposed Solution / Feature Description

若手が試作室の設備を初めて使うときに、**その設備に慣れた先輩に「初回だけ一緒に使ってほしい」と頼める予約の仕組み**を提供する。先輩は、付き添える設備と時間帯を登録しておく。付き添いは30分程度で、先輩は作業の手伝いではなく、予約や片付けの作法を隣で伝える。

**主要な構成要素**:

- **付き添える設備の登録** — 先輩が、付き添える設備と、付き添える時間帯（週に1〜2回、30分など）を登録する
- **付き添いの依頼** — 若手が、使いたい設備と目的を選び、付き添える先輩の時間帯から一つを選んで依頼する。何をしたいかを一行で書く
- **伝えることの目安** — 先輩には、その設備で伝えるとよいこと（予約、事前の一声、片付け、混む時間帯）の目安を示す。先輩はこれを見ながら、自分の言葉で伝える
- **付き添いのあとの一言** — 付き添いのあと、若手は「わかったこと」を一行で書く。先輩は「次は一人で大丈夫」か「もう一度一緒に」を選ぶ
- **付き添える人の一覧** — 設備ごとに、付き添える先輩を一覧で表示する。付き添える人がいない設備は、部門長の一覧で印が付く

## User Stories

- **US-001 一緒に使ってくれる人がいなくてルールを知れない問題**
  利用者（Bさん）は、初めて使う設備を、慣れた人と一緒に一度使いたい。それにより、暗黙のルールを外して注意され、試作室に入れなくなる事態を避けたい。
  背景: 現状は先輩と一緒に試作室を使う機会がなく、ルールは外して注意されることでしか知れない。

- **US-002 若手に教えたいのにきっかけがない問題**
  利用者（試作室の常連の先輩）は、若手に試作室の使い方を伝えたいが、押し付けにならないきっかけがほしい。それにより、若手が試作室に来ないのは興味がないからだという思い込みを確かめたい。
  背景: 現状は若手が困っていることを知らず、教える場面もない。

## Open Questions

- 先輩が付き添える時間を登録してくれるか。登録のきっかけをどう作るか
- 30分の付き添いで、暗黙のルールを十分に伝えられるか
- 付き添いを依頼することが、若手にとって気が重くないか
- **モックで確かめたいこと**: 若手が設備を選んで、付き添いを依頼するまでの流れが、気軽にできると感じられるか
- **モックで確かめたいこと**: 先輩が「伝えることの目安」を見て、何を伝えればよいかが迷わずわかるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **先輩が登録しない** — 自分の業務が忙しい → 付き添える時間を登録しない → 若手が依頼できない。軽減: 最初は常連の数人に声をかけ、付き添いを業務時間として認めてもらう
- **付き添いの集中** — 特定の先輩に依頼が集まる → 負担が偏る → 先輩が登録をやめる。軽減: 一人あたりの付き添いの上限を設け、他の先輩を勧める
- **作業の代行になる** — 先輩が作業を手伝ってしまう → 若手が自分で使えるようにならない → 次も付き添いが必要になる。軽減: 伝えることの目安に「作業は若手が行う」と明記する
- **評価への転用** — 付き添いの回数が記録される → 評価に使われる → 義務的になる。軽減: 個人別の付き添い回数を集計せず、評価に使わない方針を明記する
