# PRD: 業務と切り離した場で、異分野の相手と5分ずつ自分の仕事を説明し合い「わからなかった言葉」を返し合う説明練習ペア（A5xB4-2）

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）は、電気・機械の両チームにまたがるプロジェクトの調整役を担当している。同じプロジェクトには、電気電子出身で入社3年目のBさん（20代後半）がいる。Bさんの部署は機械系の社員が多い。

分野の違う人に説明するとき、どの言葉が通じていないかは、**相手が教えてくれないとわからない**。本番の会議では、相手は通じない言葉があっても聞き返さないことが多い。聞き返すと話が止まり、自分の知識不足を見せることにもなるからである。説明する側は、相手がうなずいているので伝わったと思い、後でずれが見つかる。安心して「わからなかった」と言い合える練習の場があれば、説明する側は通じない言葉を知ることができる。

**誤解の実態**: Bさんは設計会議で「コモンモードノイズ」という言葉を使ったが、機械チームの誰も聞き返さなかった。Bさんは伝わったと思っていた。後で機械の担当者に雑談で聞くと、「実はあのときの話、よくわからなかった」と言われた。機械の担当者も、Bさんに機械の話をするとき、「ドラフト角」や「ボス」の意味がBさんに通じているかを確かめたことがなかった。2人とも、本番の会議では聞き返せず、互いの説明がどこで通じていないかを知らなかった。

**気づきの実態**: 聞き返せないのは、本番の会議だからである。業務と切り離した練習の場なら、聞き返しても話は止まらず、知識不足を見せることにもならない。互いに説明し合い、「わからなかった言葉」を返し合えば、説明する側は通じない言葉を知り、聞く側は聞き返す練習ができる。

**練習機会の実態**: 分野をまたいで説明を練習する場はない。部署の勉強会は同じ分野の人の集まりで、別分野の人に説明する機会にはならない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。分野をまたぐ会議で、通じない言葉が聞き返されずに残っている状況は測られていない。

## Goals / Non-Goals

**Goals**

- 自分の説明のどこが別分野の人に通じないかを知る（練習で返された「わからなかった言葉」の数を効果指標とする。返された数が多いほど、本番の前に直せる箇所が見つかったとして数える）
- 本番の会議で、別分野の人に伝わる説明ができる（練習のあと、本番の会議で聞き返されずに伝わったと感じた割合の自己申告を効果指標とする）
- 聞き返すことへのためらいが減る（「わからない言葉を聞き返せる」の自己申告を効果指標とする）

**Non-Goals**

- 業務の打ち合わせの代わり（練習の場は業務と切り離し、業務の判断はしない）
- 説明の上手さの評価（相手の説明を採点しない）
- 一人の説明ドリル（版1）、分野横断の入門会（版3）の範囲

## Proposed Solution / Feature Description

分野の違う2人を**説明練習ペア**として組み、月に2回、業務と切り離した30分の練習をする仕組みを提供する。一人が5分で自分の仕事の一場面を説明し、聞き手は「わからなかった言葉」をその場で画面に書き留める。説明が終わったら、わからなかった言葉を返し、説明する側がその場で言い換えてみる。役を交代してもう一度行う。

**主要な構成要素**:

- **ペアの組み合わせ** — 分野の違う希望者を2人組にする（電気と機械、機械とソフトなど）
- **説明の題材** — 説明する人が、自分の仕事の一場面を選んで題材にする。業務の機密に関わらない範囲にする
- **わからなかった言葉の書き留め** — 聞き手は、説明を聞きながら、わからなかった言葉を画面に書き留める。説明を止めずに書ける
- **言い換えの試し** — 説明が終わったら、わからなかった言葉の一覧を説明する人に見せる。説明する人はその場で一つずつ言い換え、聞き手が「わかった／まだわからない」を返す
- **言い換えの記録** — 通じた言い換えを、説明する人の記録として残す。本番の会議の前に見返せる

## User Stories

- **US-001 相手が聞き返さないので通じない言葉に気づけない問題**
  利用者（Bさん）は、別分野の人に自分の説明のどこが通じないかを、安心して教えてもらいたい。それにより、本番の会議で伝わったと思い込み、後でずれが見つかる事態を避けたい。
  背景: 現状は本番の会議で相手が聞き返さず、通じない言葉に気づけない。

- **US-002 本番の会議で聞き返せない問題**
  利用者（機械の担当者）は、別分野の人の説明でわからない言葉を、気兼ねなく聞き返す練習をしたい。それにより、本番の会議でも聞き返せるようになりたい。
  背景: 現状は本番の会議で聞き返すと話が止まり、知識不足を見せることになるので、聞き返さない。

## Open Questions

- 業務と切り離した練習の時間を、業務の中で確保できるか
- 題材を業務の機密に関わらない範囲にすると、練習が現実から離れないか
- **モックで確かめたいこと**: 聞き手が説明を聞きながら、わからなかった言葉を手早く書き留められるか
- **モックで確かめたいこと**: わからなかった言葉の一覧を見せられたとき、説明する人が責められていると感じず、言い換えを試したくなるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **続かない** — 業務が忙しくなる → 練習が飛ぶ → ペアが途切れる。軽減: 練習の日時を月の初めに2回分決めておく
- **遠慮が残る** — 練習でも「わからない」と言いにくい → 一覧が空になる → 練習の意味がなくなる。軽減: 「わからなかった言葉を3つ以上書く」を練習のルールにする
- **相手を傷つける** — わからなかった言葉が多い → 説明する人が落ち込む → 練習をやめる。軽減: わからなかった言葉を「直せる箇所」として示し、責める表示にしない
- **機密の漏れ** — 業務の内容を他部署の人に話す → 情報の扱いに問題が出る。軽減: 題材は業務の機密に関わらない範囲にすることを示す
