# PRD: 他部署で実際に手を動かしている作り手と、1対1でものづくりの相談ができる「作り手つなぎ」（A5xB1-2）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A5×B1（安心して練習・相談できる場所がない × やりたいものづくりができない）の版2。方向性は「2人の間をつなぐ（コミュニケーション設計）」。版1は個人の練習プラン、版3は社内ものづくりサークルを扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門の業務の多くは会議資料のパワーポイント作成で、実際に手を動かして作る機会は少ない。

2人は、ものづくりについて**安心して相談できる相手がいない**。部門の上司や先輩は、資料作成が中心の業務をしており、ものづくりの相談に乗れる人は少ない。それに、上司や先輩に「ものづくりがしたい」と相談すると、今の業務への不満のように聞こえないかと心配になる。一方、社内には、試作部門や生産技術部門など、日々手を動かしている作り手がたくさんいる。しかし、他部署の人とつながるきっかけがない。

**誤解の実態**: Bさんは、ものづくりの力をつけるために何をすればよいか、誰かに相談したかった。課長に話すと、今の業務に不満があると思われそうで言えなかった。同期に話しても、同じように資料作成の業務をしていて、答えは出なかった。同じ工場の試作部門には、Bさんと同じ電気電子出身で、毎日基板を作っている先輩がいた。その先輩は、若手の相談に乗りたいと思っていたが、Bさんの存在を知らなかった。Aさんも、治具づくりについて相談したかったが、生産技術部門に知り合いがいなかった。

**気づきの実態**: 相談相手は社内にいる。問題は、**相談したい人と、相談に乗りたい作り手が、出会う経路がない**ことである。直属の上司ではない相手なら、今の業務への不満と受け取られる心配も小さい。他部署の作り手は、ものづくりの具体的な相談に乗れる。経路さえあれば、安心して相談できる。

**練習機会の実態**: 社内にはメンター制度があるが、新入社員向けで、配属後の若手や中途入社の人は対象外である。他部署の人と知り合う機会は、全社の行事くらいしかない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。部署をまたいだ相談の経路がどれだけあるかは、社内で把握されていない。

## Goals / Non-Goals

**Goals**

- ものづくりについて相談できる相手が見つかる（相談を申し込んだ人のうち、作り手とつながった割合を効果指標とする）
- 相談が、具体的な練習や行動につながる（相談のあと、本人が新しい練習や提案を始めた割合を効果指標とする）
- 直属の上司に言いにくい相談を、安心してできる（「安心して相談できた」の自己申告を効果指標とする）

**Non-Goals**

- 異動の斡旋（相談は練習や行動の相談に限り、異動の仲介はしない）
- 正式なメンター制度の置き換え（新入社員向けの制度はそのまま残す）
- 個人の練習プラン（版1）、社内ものづくりサークル（版3）の範囲

## Proposed Solution / Feature Description

社内で**ものづくりの相談に乗ってもよいと登録した作り手と、相談したい人を、1対1でつなぐ**Webの仕組みを提供する。作り手は、得意な分野（基板、治具、3Dプリント、筐体など）と、相談に乗れる時間（月1回30分など）を登録する。相談したい人は、相談したいことを一行書いて作り手を選び、30分の相談を申し込む。相談の内容は直属の上司には知らされない。

**主要な構成要素**:

- **作り手の登録** — 相談に乗ってもよい作り手が、得意な分野、所属部署、相談に乗れる時間を登録する
- **相談の申し込み** — 相談したい人が、相談したいことを一行書き、分野から作り手を選んで申し込む。作り手は承諾か、別の作り手の紹介かを選ぶ
- **30分の相談** — 承諾されたら、30分の相談の日時を決める。対面かオンラインかを選べる
- **相談のあとの一歩** — 相談のあと、相談した人が「次にやること」を一行書く。作り手にも共有され、次の相談のきっかけになる
- **上司に知らせない** — 相談の内容と相手は、本人と作り手だけが見られる。直属の上司には知らされない

## User Stories

- **US-001 ものづくりの相談をする相手がいない問題**
  利用者（Bさん）は、ものづくりについて、実際に手を動かしている人に相談したい。それにより、何をすればものづくりの力がつくのかを知りたい。
  背景: 現状は部門の上司や先輩にものづくりに詳しい人が少なく、他部署の作り手とつながる経路もない。相談できないまま、ものづくりから遠ざかる。

- **US-002 上司に相談すると不満と受け取られそうで言えない問題**
  利用者（Aさん）は、直属の上司ではない相手に、安心してものづくりの相談をしたい。それにより、今の業務への不満と受け取られる心配なく相談したい。
  背景: 現状は上司に「ものづくりがしたい」と言うと不満に聞こえそうで、相談できない。

- **US-003 若手の相談に乗りたいのにきっかけがない問題**
  利用者（試作部門の作り手）は、ものづくりに興味のある若手の相談に乗りたい。それにより、自分の経験を若手に伝えたい。
  背景: 現状は他部署の若手とつながるきっかけがない。

## Open Questions

- 作り手が十分に登録してくれるか。作り手の部署の上司の理解が必要か
- 相談の時間を業務時間として扱えるか
- 直属の上司に知らせないことが、組織として受け入れられるか
- **モックで確かめたいこと**: 相談したいことを一行書いて作り手を選ぶ流れが、気軽に申し込めると感じられるか
- **モックで確かめたいこと**: 作り手の一覧を見て、「この人に相談したい」と思える情報が十分に載っているか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **作り手が集まらない** — 登録する作り手が少ない → 相談先が見つからない → 仕組みが使われない。軽減: 最初は試作部門と生産技術部門に声をかけ、数人の作り手から始める
- **作り手への集中** — 人気の作り手に相談が集まる → 負担が偏る → 作り手が登録をやめる。軽減: 一人あたりの月の相談件数に上限を設ける
- **上司との関係** — 上司に知らせない相談 → 上司が不信を抱く → 組織の中で問題になる。軽減: 相談は練習や行動の相談に限ることを明記し、制度の存在は部門長に説明しておく
- **異動の相談になる** — 相談が異動の希望に変わる → 作り手が困る → 仕組みの目的からずれる。軽減: 異動の相談は人事の窓口を案内する
