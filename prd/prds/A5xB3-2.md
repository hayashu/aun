# PRD: 同期どうしで週の目標と進み具合を見せ合い、評価と関係なく励まし合う進捗バディ（A5xB3-2）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A5×B3（安心して練習・相談できる場所がない × 自分で進める道筋を作れない）の版2。方向性は「2人の間をつなぐ（コミュニケーション設計）」。版1は個人のミニプロジェクト練習帳、版3は社内の進め方相談窓口を扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門ではマイルストーンを決めずに仕事が渡されることが多く、進め方は担当者に任されている。

自分で区切りを作って進めるのが苦手なBさんは、一人で仕事を進めていると、気づくと予定より大きく遅れていることがある。上司に進め方を相談すると、計画性がないと思われるのではないかと心配になる。**評価に関係なく、進め方を気軽に相談できる相手がいない**。Bさんは、研究室時代に同期と励まし合いながら研究を進めた経験があり、一人より誰かと一緒のほうが続くと感じている。

**誤解の実態**: Bさんは評価資料の作成を任され、自分で区切りを作れないまま2週間が過ぎた。気づいたときには締め切りの直前だった。上司に相談すれば早めに手を打てたが、計画性がないと思われるのが怖くて相談できなかった。同じ時期、別の部署にいるBさんの同期も、同じように進め方に悩んでいた。2人は、お互いが同じことで悩んでいることを知らなかった。研究室時代のように、週に一度でも目標と進み具合を見せ合っていれば、互いに早く気づけたはずである。

**気づきの実態**: 上司への相談は、評価に関わるので気が重い。しかし、同じ立場の同期なら、評価を気にせずに進め方を見せ合える。週に一度、目標と進み具合を見せ合うだけで、遅れに早く気づけ、互いの進め方から学べる。一人で抱え込まずに済むことで、進める意欲も続く。今は、同期と進め方を見せ合う場がない。

**練習機会の実態**: 入社時の同期研修は終わり、配属後は同期と会う機会がほとんどない。部署が違うと、互いの仕事の様子も知らない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。若手が評価に関係なく相談できる相手を持っているかは、社内で把握されていない。

## Goals / Non-Goals

**Goals**

- 進め方を、評価に関係なく見せ合える相手ができる（バディを組んだ組のうち、3か月以上続けた割合を効果指標とする）
- 遅れに早く気づける（バディとの見せ合いで「遅れそう」が出てから、本人が対策を取るまでの日数を効果指標とする）
- 一人で抱え込まずに進める意欲が続く（「一人で抱え込まずに済んでいる」の自己申告を効果指標とする）

**Non-Goals**

- 上司への進捗報告の代替（バディは励まし合う相手で、上司への報告は別に行う）
- 互いの評価（バディどうしで進み具合を比べたり評価したりしない）
- 個人の練習帳（版1）、社内の相談窓口（版3）の範囲

## Proposed Solution / Feature Description

同期どうし（または同じくらいの年次の人どうし）を**「進捗バディ」として2人組にし、週に一度、目標と進み具合を見せ合う**Webの仕組みを提供する。月曜に今週の目標を3つ書き、金曜にどこまで進んだかを書く。バディはそれを見て、一言の励ましや、進め方の工夫を返す。仕事の中身は書かなくてよく、進め方だけを見せ合う。

**主要な構成要素**:

- **バディの組み合わせ** — 希望者を、同期または同じくらいの年次の人と2人組にする。部署が違う人どうしを優先する
- **月曜の目標** — 今週の目標を3つ、一行ずつ書く。仕事の中身は伏せてよく、「評価資料の測定を終える」程度の書き方でよい
- **金曜の進み具合** — 金曜に、各目標が「できた／途中／できなかった」を選び、一言を添える
- **バディの一言** — バディは相手の進み具合を見て、一言の励ましか、進め方の工夫（「区切りを小さくしてみたら？」など）を返す
- **月に一度の15分** — 月に一度、15分だけ話す時間を予約できる。文字のやりとりでは伝わらない悩みを話す

## User Stories

- **US-001 上司に相談すると評価に響きそうで相談できない問題**
  利用者（Bさん）は、評価に関係のない相手と、進め方を気軽に見せ合いたい。それにより、遅れに一人で気づかずに締め切り直前になる事態を避けたい。
  背景: 現状は上司に相談すると計画性がないと思われそうで、相談できない。一人で抱え込み、遅れに気づくのが遅れる。

- **US-002 一人で進めると意欲が続かない問題**
  利用者（Aさん）は、誰かと励まし合いながら仕事を進めたい。それにより、一人で抱え込んで意欲が落ちる状態を変えたい。
  背景: 現状は配属後に同期と会う機会がなく、一人で仕事を進めている。

## Open Questions

- バディどうしの相性が合わない場合、どう組み替えるか
- 仕事の中身を伏せて目標を書くことで、進め方の工夫を返せるか
- 同期が少ない人（中途入社、外国籍の社員など）をどう組み合わせるか
- **モックで確かめたいこと**: 月曜の目標と金曜の進み具合を書くのが、それぞれ2分以内で終わるか
- **モックで確かめたいこと**: バディから一言が返ってきたとき、「一人じゃない」と感じられるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **続かない** — 忙しくなると書かなくなる → バディも書かなくなる → 関係が途切れる。軽減: 書かない週が続いたら、両者に軽く知らせる
- **比べ合いになる** — 進み具合を見せ合う → 相手と比べて落ち込む → 見せ合いが負担になる。軽減: 進み具合は自分の目標に対してだけ示し、相手との比較は表示しない
- **相性の問題** — バディと話が合わない → 一言を返さなくなる → 一方だけが書く。軽減: 3か月ごとに組み替えを選べるようにする
- **情報の扱い** — 仕事の内容を他部署の人に見せる → 情報の扱いに問題が出る。軽減: 仕事の中身は伏せ、進め方だけを書くよう示す
