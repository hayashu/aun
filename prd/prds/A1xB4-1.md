# PRD: 「電気側でなんとかならない？」の裏にある相手の分野の事情を読む制約カード学習（A1xB4-1）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A1×B4（相手の真意がわからない × 専門領域の違いで認識がずれる）の版1。方向性は「当事者の行動を支える（個人向けツール）」。版2は2分野の間で事情を見せ合う仕組み、版3は設計レビューの運用を扱う。A3×B4（伝え方）とは異なり、本セルは「相手の発言の裏を読む」側を扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）は、電気・機械の両チームにまたがるプロジェクトの調整役を担当している。同じプロジェクトには、電気電子出身で入社3年目のBさん（20代後半）がいる。Bさんの部署は機械系の社員が多い。

分野をまたぐ打ち合わせでは、相手の発言の**裏にある分野の事情**が読めないことが問題になる。機械側の「電気側でなんとかならない？」は、相談のように聞こえる。しかし実際には「金型がもう発注済みで、機械側は変えられない」という事情を含んだ、実質的な断りであることが多い。言葉の遠回しさと、分野の事情を知らないことが重なり、真意が二重に見えなくなる。

**誤解の実態**: 試作基板の発熱について、Bさんは筐体に通気口を追加してほしいと機械チームに頼んだ。機械の担当者は「うーん、電気側でなんとかならないかな」と答えた。Bさんはこれを「両方で考えよう」という相談だと受け取り、機械側でも検討してもらえると思って待った。同席していたAさんも、前向きな返事だと議事録に書いた。実際には、筐体の金型は前週に発注されており、機械側の変更は次の試作まで不可能だった。2週間後にそれがわかり、Bさんは部品の選び直しを急いで行うことになった。

**気づきの実態**: 「なんとかならない？」の裏には、その分野特有の動かせない事情がある。機械なら金型の発注時期、材料の在庫、強度試験の日程。電気なら基板の改版回数、部品の調達期間。この事情を知っていれば、「金型はもう出ていますか」と一言確かめられる。2人は相手の分野の事情を知らないので、確かめる問いを思いつかない。

**練習機会の実態**: 社内の技術研修は、自分の分野の知識を深めるものが中心で、隣の分野の「動かせない事情」を学ぶ機会はない。相手に直接聞くと、知らないことを露呈するようで聞きにくい。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。分野をまたぐ調整での手戻りの件数は、部門では測られていない。

## Goals / Non-Goals

**Goals**

- 分野をまたぐ返事の真意を読み違えて待つ期間が短くなる（返事を受けてから、相手の事情を確かめる一言を出すまでの日数を効果指標とする）
- 隣の分野の「動かせない事情」を知る（制約カードの設問で、相手の事情を事前に想定できた割合を効果指標とする）
- 分野をまたぐ打ち合わせで、確かめる問いを出す頻度が増える（打ち合わせ後の自己申告を効果指標とする）

**Non-Goals**

- 隣の分野の専門知識の体系的な教育（扱うのは、返事の裏にある典型的な事情に限る）
- 相手の真意の断定（事情は候補として示し、確かめる一言とセットにする）
- 2分野の間での事情の共有（版2）、設計レビューの運用（版3）の範囲

## Proposed Solution / Feature Description

分野をまたぐ場面の発言を示し、**先に自分で真意を選ばせてから、その分野の典型的な事情と、確かめる一言を返す**練習用Webツールを提供する。さらに、本人が実際に言われた言葉を入力し、同じ手順で読み解ける。隣の分野の事情を、設問を通じて少しずつ身につける。

**主要な構成要素**:

- **場面と発言の設問** — 「機械の担当者が『電気側でなんとかならない？』と言った」のような場面を示し、真意を「相談／断り／保留」から選ばせる。解説は答えたあとにしか出さない
- **制約カード** — 答えたあとに、その発言の裏にありうる分野の事情（金型の発注時期、部品の調達期間など）をカードで示す。カードは分野ごとにたまり、本人の「隣の分野の事情帳」になる
- **確かめる一言** — 「金型の発注はもう済んでいますか」「次の試作で変更できる範囲はどこまでですか」のように、事情を確かめる一言を選ばせ、自分の言葉に直させる
- **自分が言われた言葉** — 実際の打ち合わせで言われた言葉を入力し、同じ手順で読み解く。入力した内容は本人の端末にだけ残す
- **分野別の弱点** — 設問の結果を分野ごとに集計し、どの分野の事情をまだ想定できていないかを示す

## User Stories

- **US-001 実質的な断りを相談と受け取って待つ問題**
  利用者（Bさん）は、機械側の「なんとかならない？」が、機械側の事情による断りかどうかをその場で確かめたい。それにより、2週間待ったあとで機械側は変えられないと知る事態を避けたい。
  背景: 現状は相談と受け取って待つ。真意がわかるのは後工程が進んでからで、そのときには自分の側で急いで対応するしかない。

- **US-002 隣の分野の事情を知らずに議事録を書く問題**
  利用者（Aさん）は、調整役として、各分野の返事の裏にある事情を想定できるようになりたい。それにより、前向きに聞こえる返事を、そのまま「検討中」と記録する誤りを避けたい。
  背景: 現状は分野の事情を知らないため、返事を言葉どおりに記録する。

## Open Questions

- 制約カードの内容を誰が書くか。各分野のベテランに書いてもらう必要があるが、その手間を誰が負担するか
- 設問の場面を、本人の職場の分野構成（機械・電気・ソフト・品質など）にどこまで合わせられるか
- **モックで確かめたいこと**: 先に真意を選ばせてから制約カードを見せる順序で、「そういう事情があったのか」という納得が生まれるか
- **モックで確かめたいこと**: たまった制約カードを見返したとき、次の打ち合わせで使えそうだと感じられるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **事情の一般化** — 典型的な事情を示す → 「機械はいつもそう」と決めつける → 相手個人の状況を見なくなる。軽減: 事情は「ありうる候補」として示し、確かめる一言を必ず添える
- **教材との誤認** — 技術の学習ツールに見える → 研修と比べられる → 差別性を失う。回避: 技術知識ではなく「返事の裏にある事情」に絞る
- **カードの質** — 事情の書き方が浅い → 実務で使えない → 信頼を失う。軽減: 最初は一つの分野の組み合わせ（機械と電気）に絞り、ベテランの確認を経たカードだけを載せる
- **相手を疑う道具になる** — 返事を裏読みし続ける → 相手の言葉を信じなくなる → 関係が悪くなる。軽減: 「本当に相談」の候補も必ず示す
