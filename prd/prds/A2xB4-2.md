# PRD: 一緒に仕事を始める2人が「自分の分野の当たり前」を交換する分野の自己紹介シート（A2xB4-2）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A2×B4（暗黙の期待・ルールがわからない × 専門領域の違いで認識がずれる）の版2。方向性は「2人の間をつなぐ（コミュニケーション設計）」。版1は個人が隣の分野の作法を調べるカード、版3はプロジェクト開始時の取り決めを扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）は、電気・機械の両チームにまたがるプロジェクトの調整役を担当している。同じプロジェクトには、電気電子出身で入社3年目のBさん（20代後半）がいる。Bさんの部署は機械系の社員が多い。

分野の違う2人が一緒に仕事を始めるとき、**お互いの分野の「当たり前」を確かめる場面がない**。機械の担当者は、変更は図面への指示と設計変更依頼書で受けるのが当たり前だと思っている。電気のBさんは、チャットで頼んで担当者が対応するのが当たり前だと思っている。どちらも自分の当たり前を相手も共有していると思い込み、ずれは依頼が止まってから初めてわかる。

**誤解の実態**: Bさんは、基板のコネクタ位置と筐体の穴のずれに気づき、機械の担当者にチャットで「穴を3mm右に」と頼んだ。機械の担当者は「了解です」と返したが、正式な依頼が来るまで待っていた。2週間後に穴が変わっていないとわかった。2人はその後、話し合って初めて、お互いの当たり前が違うことを知った。機械の担当者は「最初に言っておけばよかった」と言い、Bさんも「電気ではチャットで済むと言っておけばよかった」と思った。

**気づきの実態**: 2人の当たり前は、どちらも間違っていない。違っているだけである。一緒に仕事を始める最初に5分話せば、ずれは防げた。しかし、何を話せばよいかの型がないので、その5分は使われない。お互いに「相手も同じだろう」と思っている限り、確かめる理由も生まれない。

**練習機会の実態**: プロジェクトのキックオフでは、日程と役割分担が決まるが、分野ごとの仕事の作法は話題にならない。2人の担当者が直接やりとりを始めるときには、何の準備もない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。分野の違う担当者どうしの作法のずれによる停滞は、部門では測られていない。

## Goals / Non-Goals

**Goals**

- 分野の違う2人のやりとりで、作法のずれによる停滞が減る（シートを交換した2人の間で、依頼が作法の違いで止まった件数を効果指標とする）
- お互いの当たり前が、やりとりの最初に言葉になる（一緒に仕事を始めた2人のうち、シートを交換した割合を効果指標とする）
- 相手の分野への理解が深まる（「相手の分野の進め方がわかった」の自己申告を効果指標とする）

**Non-Goals**

- 正式な手続きの変更（どちらの作法に合わせるかは2人で決めるが、正式な手続きは既存のものに従う）
- 人柄の紹介（扱うのは仕事の作法で、趣味や性格の自己紹介ではない）
- 個人の作法の学習（版1）、プロジェクト全体の取り決め（版3）の範囲

## Proposed Solution / Feature Description

分野の違う2人が一緒に仕事を始めるときに、**「自分の分野の当たり前」を5つの質問に答える形で書き、交換する**シートを提供する。質問は、「何で話すのが楽か（図面、回路図、口頭）」「頼みごとはどう受けたいか（チャット、書類、誰か経由）」「返事の『了解』は何を意味するか」「変更にかかる時間の目安」「急ぎのときの連絡方法」の五つ。交換したあと、違いがある項目について、2人のやり方を一つ決める。

**主要な構成要素**:

- **5つの質問** — それぞれが自分の分野の当たり前を、選択式と一行で答える。相手の答えは、自分が答え終えるまで見えない
- **並べて表示** — 2人の答えを左右に並べ、違う項目に印を付ける
- **2人のやり方** — 違う項目について、2人の間でどちらのやり方にするか、または新しいやり方を一行で決める（例:「寸法の変更はチャットで相談、確定したら依頼書」）
- **やり方のメモ** — 決めたやり方を2人がいつでも見返せる。どちらかが異動したり、新しい人が加わったりしたときにも引き継げる
- **調整役の一覧** — 調整役は、プロジェクト内で交換されたシートと、決まったやり方を一覧で見られる

## User Stories

- **US-001 自分の当たり前を相手も共有していると思い込む問題**
  利用者（Bさん）は、機械の担当者と仕事を始めるときに、お互いの当たり前の違いを知りたい。それにより、チャットで頼んだ変更が2週間止まる事態を避けたい。
  背景: 現状は確かめる場面がなく、ずれは依頼が止まってから初めてわかる。

- **US-002 最初に言っておけばよかったと後で思う問題**
  利用者（機械の担当者）は、新しい相手と仕事を始めるときに、自分の分野の受け方を最初に伝えたい。それにより、正式な依頼を待って何もしないまま時間が過ぎる事態を避けたい。
  背景: 現状は自分の当たり前を言葉にする機会がなく、相手が知らないとは思わない。

## Open Questions

- 5つの質問で足りるか。分野の組み合わせによって、必要な質問が違うかもしれない
- 一緒に仕事を始める瞬間をどう捉えるか。プロジェクトの途中から関わる人もいる
- **モックで確かめたいこと**: 5つの質問に答えるのが3分以内で終わるか
- **モックで確かめたいこと**: 2人の答えが並んだとき、違いが「どちらかが間違い」ではなく「やり方を決めればよい」と受け取れる見せ方になっているか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **形式的な交換** — シートを交換して終わる → 2人のやり方を決めない → ずれが残る。軽減: 違う項目には必ず2人のやり方を書かないと完了しない形にする
- **一方への合わせ込み** — 立場の強い分野の作法に合わせる → 弱い側の負担が増える → 不満が溜まる。軽減: 2人のやり方を決める欄に「どちらが合わせるか」ではなく「2人のやり方」と書く形にする
- **更新されない** — 一度決めたやり方が古くなる → 実態と合わなくなる → 信頼を失う。軽減: やり方のメモに最終更新日を表示する
- **分野の決めつけ** — 答えが分野の代表と見なされる → 「機械の人はみんなこう」と一般化される → 偏見を生む。軽減: シートは個人の答えとして扱い、分野の代表としない
