# PRD: 若手が持ち回りで1章ずつ説明し、わからない点を皆で埋める部署の輪講運営キット（A5xB2-3）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A5×B2（安心して練習・相談できる場所がない × ハードウェアの知識が足りず焦る）の版3。方向性は「場・仕組みを変える（チーム／組織向け）」。版1は個人の設計判断ドリル、版2は他部署のベテランへの匿名相談を扱う。A3×B2-3（質問タイム）は質問を持ち寄る場、本PRDは一冊の本を順に読み進める学びの場を扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門は機械系の社員が多く、筐体・機構・材料の知識が前提として会話が進む。

2人はハードウェアの知識を身につけようと、一人で教科書を読んでいる。しかし、**一人で読むと続かず、わからないところで止まってしまう**。わからないところを聞ける相手もいない。同じ部署の他の若手も、同じように一人で教科書を読んでいて、同じところで止まっている。部署全体で見れば、同じ教科書を別々に読み、同じところでつまずいている人が何人もいる。

**誤解の実態**: Bさんは筐体設計の教科書を一人で読み始めたが、第3章の応力集中のところで止まり、そのまま2か月が過ぎた。Aさんも熱設計の教科書を読み始めたが、熱抵抗の計算でつまずいて止まった。同じ部署の別の若手も、Bさんと同じ教科書の同じ章で止まっていた。3人とも、他の人が同じ教科書を読んでいることを知らなかった。部署のベテランは、若手が教科書で困っていることを知らなかった。

**気づきの実態**: 問題は個人の意欲ではなく、**一緒に学び、わからないところを聞ける場がない**ことである。同じ教科書を一緒に読み、一人ずつ担当の章を説明する場があれば、説明する人は理解を深め、聞く人は止まらずに進める。わからないところは皆で考え、それでもわからなければベテランに聞ける。

**練習機会の実態**: 部署には勉強会があるが、ベテランが用意したテーマを発表する形で、若手が教科書を読み進める場ではない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げ、職場側の「ローコンテキスト化」を対策に掲げている。部署の若手が自主的に学んでいる状況は把握されていない。

## Goals / Non-Goals

**Goals**

- 若手が、一人では続かなかった教科書を読み進められる（輪講で読み終えた章の数を効果指標とする）
- わからないところが、皆で埋められる（輪講で出た「わからない点」のうち、その回か次の回までに解決した割合を効果指標とする）
- 知識不足への焦りが和らぐ（「一緒に学べる場がある」の自己申告を効果指標とする）

**Non-Goals**

- 研修の置き換え（輪講は自主的な学びの場で、正式な研修ではない）
- 参加者の理解度の評価（説明の出来を評価しない）
- 個人の設計判断ドリル（版1）、匿名相談（版2）の範囲

## Proposed Solution / Feature Description

部署で**週に1回30分の輪講**を開き、その運営をWebで支えるキットを提供する。読む教科書を一冊決め、若手が持ち回りで1章ずつ担当して説明する。聞く人は、事前に読んでわからなかった点を書いておく。説明のあと、わからない点を皆で考え、解決しない点はベテランに聞く。

**主要な構成要素**:

- **教科書と担当の決定** — 読む教科書を一冊決め、章ごとの担当者と日付を一覧にする
- **わからない点の事前登録** — 参加者が、担当の章を読んでわからなかった点を事前に書く。匿名でも書ける
- **説明の進行** — 担当者が15分で章の要点を説明し、残りの15分でわからない点を皆で考える。進行役の画面に、わからない点の一覧と残り時間を表示する
- **ベテランへの質問** — 輪講で解決しなかった点を、ベテランに質問として送る。答えは次の輪講で共有する
- **読み進めの記録** — 読み終えた章と、解決したわからない点を一覧にする。部署の学びの記録になる

## User Stories

- **US-001 一人で教科書を読むと止まってしまう問題**
  利用者（Bさん）は、教科書を他の人と一緒に読み進めたい。それにより、わからないところで止まって2か月が過ぎる状態を変えたい。
  背景: 現状は一人で読み、わからないところで止まる。聞ける相手もなく、知識不足への焦りが増す。

- **US-002 わからないところを聞ける相手がいない問題**
  利用者（Aさん）は、教科書のわからないところを、皆で考え、必要ならベテランに聞きたい。それにより、つまずいたところを乗り越えたい。
  背景: 現状はわからないところを聞ける場がない。

- **US-003 若手が教科書で困っていることを知らない問題**
  利用者（部署のベテラン）は、若手がどこでつまずいているかを知り、必要なところで手助けしたい。それにより、若手が自分で学ぶのを支えたい。
  背景: 現状は若手が一人で読んでいて、困っていることがベテランに伝わらない。

## Open Questions

- 週に1回30分の時間を、若手が業務の中で確保できるか
- どの教科書を選ぶか。参加者の分野が違う場合はどうするか
- 担当の章を説明するのが負担にならないか
- **モックで確かめたいこと**: わからない点の事前登録と、輪講での一覧表示で、「自分だけがわからないのではない」と感じられるか
- **モックで確かめたいこと**: 進行役の画面で、説明15分と議論15分を時間どおりに進められるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **続かない** — 業務が忙しくなる → 輪講が休みになる → そのまま終わる。軽減: 担当と日付を先に決め、休んだ回は翌週にずらす
- **説明の負担** — 担当の章の説明に時間がかかる → 担当を嫌がる → 参加者が減る。軽減: 説明は要点だけでよく、15分以内に収めることを示す
- **ベテランの負担** — 質問がベテランに集中する → 負担が増える → 答えが遅れる。軽減: 輪講の場で解決しなかった点だけを送る
- **一部の人の集まりになる** — 常連だけが参加する → 新しい人が入りにくい → 広がらない。軽減: 新しい教科書を始めるときに部署全体に呼びかける
