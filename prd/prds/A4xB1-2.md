# PRD: 試作を見た上司が「どこが・なぜ・次はどう」を1分で返せるフィードバックカード（A4xB1-2）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A4×B1（失敗の原因がわからない × やりたいものづくりができない）の版2。方向性は「2人の間をつなぐ（コミュニケーション設計）」。版1は本人の指摘の振り返り、版3はチームの試作レビュー基準と次の機会の保証を扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門の業務の多くは会議資料のパワーポイント作成で、実際に手を動かして作る機会は少ない。

若手が試作を見せたとき、上司の指摘は**短い言葉で終わる**ことが多い。「使いにくいな」「詰めが甘い」。上司の頭の中には具体的な理由があるが、忙しさと、細かく言うと萎縮させるのではないかという気遣いから、言葉にしない。若手は理由がわからないまま、次にどう直せばよいかもわからない。上司は、若手が同じ失敗を繰り返すのを見て、次の機会を任せにくくなる。

**誤解の実態**: 課長はBさんの作った評価治具を見て「これだと現場では使いにくいな」と言った。課長の頭の中では、「作業者が片手で基板を押さえながら操作できない」「固定のネジに工具が要る」という具体的な理由があった。しかし次の会議があり、それを伝えないまま去った。Bさんは何が悪かったのかわからず、次の治具の製作は別の先輩に任された。課長はBさんに「もう少し考える力をつけてほしい」と思ったが、Bさんに必要だったのは、考える力ではなく理由だった。

**気づきの実態**: 課長が理由を言わなかったのは、伝える時間と型がなかったからである。具体的な理由を1分で返せる形があれば、課長は言葉にできた。若手が理由を知れば、次は改善できる。改善できれば、課長は次の機会を任せられる。今は、短い指摘が、ものづくりの機会を途切れさせる原因になっている。

**練習機会の実態**: 管理職向けのフィードバック研修はあるが、一般論で、試作を見たときにその場で何を伝えればよいかの型はない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。試作の指摘が、理由を伴わずに行われている割合は測られていない。

## Goals / Non-Goals

**Goals**

- 試作の指摘に、具体的な理由と改善点が含まれる（フィードバックのうち、「どこが・なぜ・次はどう」がすべて書かれた割合を効果指標とする）
- 若手が、指摘の理由を理解できる（「指摘の理由がわかった」の自己申告を効果指標とする）
- 一度うまくいかなかった若手にも、次の機会が回る（フィードバックを受けた若手が、3か月以内に次の試作を任された割合を効果指標とする）

**Non-Goals**

- 試作の評価・採点（点数を付けると、若手が試作を避ける）
- 上司のフィードバック力の評価（カードの使用状況を管理職の評価に使わない）
- 本人の振り返り（版1）、チームのレビュー基準（版3）の範囲

## Proposed Solution / Feature Description

上司が若手の試作を見たときに、**「よかった点」「直すとよい点（どこが・なぜ）」「次はこうするとよい」を1分で書けるフィードバックカード**を提供する。各欄は選択式の候補と一行の自由記述でできている。若手はカードを受け取り、わからない点があれば「ここをもう少し聞きたい」を返せる。

**主要な構成要素**:

- **よかった点** — まず、よかった点を一つ選ぶか書く。萎縮させないための最初の一言になる
- **直すとよい点** — 「どこが」を試作の部分から選び、「なぜ」を候補（作業者が使いにくい、強度が足りない、交換に手間がかかる、など）から選ぶか一行で書く
- **次はこうするとよい** — 次に同じような試作をするときの改善点を一行で書く
- **聞きたい点の返信** — 若手は、カードの各欄に「ここをもう少し聞きたい」を返せる。上司は一行で答えるか、5分話す時間を提案する
- **次の機会の一言** — カードの最後に、上司が「次はこれを任せたい」「次も声をかける」を選べる欄を置く。一度の失敗で機会が途切れないことを、言葉で伝える

## User Stories

- **US-001 短い指摘で理由がわからない問題**
  利用者（Bさん）は、試作を見せたときに、どこがなぜ悪かったのかを具体的に知りたい。それにより、次の試作で改善し、ものづくりの機会を失わないようにしたい。
  背景: 現状は「使いにくい」の一言で終わり、理由がわからない。次の機会は別の人に回る。

- **US-002 理由を伝える時間と型がない問題**
  利用者（課長）は、若手の試作を見たときに、具体的な理由を短い時間で伝えたい。それにより、若手を萎縮させずに、次の試作で改善してもらいたい。
  背景: 現状は忙しさと気遣いから理由を言わず、若手が同じ失敗を繰り返すのを見て次の機会を任せにくくなる。

## Open Questions

- 上司がカードを書く時間を取ってくれるか。口頭で伝えたあとに、カードで残す運用でもよいか
- 「よかった点」を必須にすると、形式的な褒め言葉になるおそれはないか
- 理由の候補を、試作の種類ごとにどこまで用意できるか
- **モックで確かめたいこと**: 上司がカードを1分以内で書けるか
- **モックで確かめたいこと**: 若手がカードを受け取ったとき、萎縮せずに「次はこうしよう」と思えるか。「次の機会の一言」がそれに効くか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **上司が使わない** — カードを書くのが面倒 → 口頭の短い指摘に戻る → 理由が伝わらない。軽減: 選択式を中心にし、1分で書ける量に絞る
- **形式的な褒め言葉** — よかった点が毎回同じになる → 若手が信用しない → カードの意味が薄れる。軽減: よかった点も試作の部分から選ぶ形にし、具体性を持たせる
- **評価への転用** — カードが記録される → 人事評価に使われる → 若手が試作を避ける。軽減: カードは若手と上司の2人だけが見られる設定にする
- **次の機会の空約束** — 「次も声をかける」を選ぶ → 実際には声がかからない → 若手が失望する。軽減: 「次の機会の一言」を選んだら、3か月後に上司に知らせる
