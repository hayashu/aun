# PRD: 実際の設計場面を模した選択問題で、外しても困らない場所で設計判断を練習する設計判断ドリル（A5xB2-1）

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門は機械系の社員が多く、筐体・機構・材料の知識が前提として会話が進む。

2人はハードウェアの知識が足りないことに焦っている。しかし、**知識を実際の設計判断に使う練習をする場がない**。教科書で知識を読んでも、実際の設計でどう使えばよいかがわからない。実際の設計で判断を外せば、設計レビューで指摘され、試作のやり直しになる。外してもかまわない場所で、設計の判断を何度も練習できれば、知識が判断の力に変わる。今は、本番の設計でしか判断の経験を積めない。

**誤解の実態**: Bさんは材料力学の教科書を読み、応力や強度の計算方法を覚えた。しかし実際の筐体設計で、基板を固定するボスの太さを決める場面になると、教科書のどの知識を使えばよいかがわからなかった。結局、先輩の過去の設計をまねて決めたが、設計レビューで「この荷重条件ならもっと太くないと割れる」と指摘された。Bさんは知識としては知っていたが、判断に使えなかった。Aさんも、熱設計の知識を勉強したが、実際の部品配置で放熱をどう考えればよいかがわからなかった。

**気づきの実態**: 知識を判断に変えるには、実際の場面で判断し、結果を知る経験が必要である。しかし、実際の設計では判断の経験は月に数回しかなく、外したときの代償も大きい。設計の場面を模した問題で、判断を選び、その結果と理由を知る練習ができれば、本番の前に何度も判断の経験を積める。

**練習機会の実態**: 社内の技術研修は知識を教えるもので、判断の練習はない。資格試験の問題集は、知識を問うもので、設計場面での判断を問うものは少ない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。若手が設計判断を練習する機会の有無は、部門では把握されていない。

## Goals / Non-Goals

**Goals**

- 知識を、設計の判断に使えるようになる（ドリルで練習した種類の判断について、設計レビューで指摘された件数を効果指標とする）
- 外してもかまわない場所で、判断の経験を積める（月あたりのドリルの回答数を効果指標とする）
- 知識不足への焦りが、具体的な練習に変わる（「何を練習すればよいかわかっている」の自己申告を効果指標とする）

**Non-Goals**

- 知識の教材化（ドリルは判断の練習で、知識は既存の教科書で学ぶ）
- 唯一の正解の提示（設計判断には複数の妥当な選択がありうる。理由とともに幅で示す）
- 他人との比較や点数化（自分のペースで練習する）
- 匿名の相談（版2）、部署の輪講（版3）の範囲

## Proposed Solution / Feature Description

実際の設計場面を模した**選択問題で、設計の判断を練習する**個人向けWebツールを提供する。問題は「基板を固定するボスの太さを、次の条件で決めよ」のように、場面と条件を示し、選択肢から判断を選ばせる。**選んだあとで**、それぞれの選択肢を選んだ場合に何が起きるかと、判断の理由を示す。外しても代償はなく、何度でも練習できる。

**主要な構成要素**:

- **設計場面の問題** — 筐体設計、熱設計、基板配置、材料選定などの分野ごとに、実際の設計場面を模した問題を示す。場面、条件、図を一枚示す
- **先に判断を選ぶ** — 解説を見る前に、本人が判断を選び、理由を一行書く。先に解説を見ると、判断の練習にならない
- **選択肢ごとの結果** — 選んだあとで、各選択肢を選んだ場合に何が起きるか（割れる、熱がこもる、組み立てられない、など）を示す。正解が一つでない場合は、条件によって変わることを示す
- **使った知識** — 判断に使う知識（応力の計算、熱抵抗の考え方など）を示し、教科書のどこを読めばよいかを案内する
- **分野ごとの練習状況** — 分野ごとに、練習した問題の数と、外した問題の種類を示す。外しやすい分野が次に練習する範囲になる

## User Stories

- **US-001 知識は知っているのに判断に使えない問題**
  利用者（Bさん）は、実際の設計場面を模した問題で、知識を判断に使う練習をしたい。それにより、本番の設計レビューで「この条件ならもっと太くないと割れる」と指摘される事態を減らしたい。
  背景: 現状は知識を教科書で学ぶだけで、判断に使う練習の場がない。判断の経験は本番の設計でしか積めず、外すと試作のやり直しになる。

- **US-002 何を練習すればよいかわからず焦る問題**
  利用者（Aさん）は、自分が外しやすい設計判断の分野を知りたい。それにより、焦りではなく、具体的な練習に時間を使いたい。
  背景: 現状は知識不足を漠然と感じ、何から練習すればよいかわからない。

## Open Questions

- 設計場面の問題を誰が作るか。部門のベテランに作ってもらう必要があり、その手間を誰が負担するか
- 実際の設計は条件が複雑で、選択問題に単純化すると現実と離れないか
- **モックで確かめたいこと**: 先に判断を選んでから結果を見る順序で、「外したけど理由がわかった」という納得が生まれるか
- **モックで確かめたいこと**: 分野ごとの練習状況を見て、次に練習する分野を自然に選びたくなるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **問題の質** — 問題が単純すぎる → 実際の設計に役立たない → 信頼を失う。軽減: 問題は部門の過去の設計レビューの指摘から作り、ベテランの確認を経たものだけを載せる
- **正解への依存** — 選択肢の正解を覚える → 条件が変わると判断できない → 本番で外す。軽減: 選択肢ごとの結果を示し、条件によって答えが変わることを強調する
- **教材との誤認** — 問題集に見える → 資格試験の問題集と比べられる → 差別性を失う。回避: 知識ではなく、設計場面での判断を問う形を守る
- **焦りの増幅** — 外した問題が多く見える → 焦りが増す → 練習をやめる。軽減: 外した問題は「次に練習する範囲」として示し、責める表示にしない
