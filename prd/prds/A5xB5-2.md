# PRD: 先輩が練習課題を出し、若手が試した結果を写真で返し、先輩が一言を返す練習課題の交換日記（A5xB5-2）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A5×B5（安心して練習・相談できる場所がない × 気軽に試して失敗できる場所がない）の版2。方向性は「2人の間をつなぐ（コミュニケーション設計）」。版1は一人で使う仮想ベンチ、版3は部署の練習課題カリキュラムを扱う。A2×B5-2（初回の付き添い）は同じ時間に隣にいる形、本PRDは時間をずらして課題と結果をやりとりする形を扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門には試作機や評価ボードがあるが、若手が自由に触れる機会は少ない。

若手が試作の練習をしたいとき、**何を試せばよいか、試した結果がよかったのかを相談できる相手がいない**。先輩に隣で見てもらえれば安心だが、先輩は忙しく、同じ時間を合わせるのは難しい。一人で試すと、何を試せばよいかわからず、試した結果がよかったのかも判断できない。うまくいかなかったときに相談する相手もいないので、試すこと自体が不安になる。

**誤解の実態**: Bさんは、はんだ付けの練習をしたいと思い、練習用の基板を手に入れた。しかし、何をどの順で練習すればよいかわからず、適当に部品を付けてみた。付けたはんだが良いのか悪いのか判断できず、誰にも見てもらえなかった。先輩に見てもらいたかったが、忙しそうで声をかけられなかった。先輩のほうは、若手の練習を見てあげたいと思っていたが、決まった時間を取るのは難しかった。もし先輩が都合のよいときに課題を出し、Bさんが都合のよいときに試して写真で返し、先輩が空いた時間に一言を返せれば、2人の時間を合わせる必要はなかった。

**気づきの実態**: 練習の相談は、同じ時間に隣にいなくてもできる。先輩が課題を出し、若手が試して結果を写真で返し、先輩が一言を返す。この往復を、それぞれの都合のよい時間に行えば、忙しい先輩も若手の練習を見られる。若手は、何を試せばよいかがわかり、結果がよかったのかも知れる。

**練習機会の実態**: 部門のOJTは業務を通じて行われ、業務の外の練習を先輩が見る仕組みはない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。若手の練習を先輩が見る機会の有無は、部門では把握されていない。

## Goals / Non-Goals

**Goals**

- 若手が、何を試せばよいかわかる課題を得られる（先輩から出された課題の数と、若手が取り組んだ割合を効果指標とする）
- 試した結果について、先輩から一言を得られる（若手が返した結果のうち、3日以内に先輩の一言が付いた割合を効果指標とする）
- 試すことへの不安が和らぐ（「相談できる相手がいるので試せる」の自己申告を効果指標とする）

**Non-Goals**

- 先輩による採点（一言は助言であり、点数を付けない）
- 業務の指導の置き換え（交換日記は業務の外の練習のためのもの）
- 一人の仮想ベンチ（版1）、部署のカリキュラム（版3）の範囲

## Proposed Solution / Feature Description

先輩と若手の2人で使う**練習課題の交換日記**を提供する。先輩が練習課題（「この基板に抵抗を5本はんだ付けしてみて」など）を一つ出す。若手は都合のよいときに試し、結果を写真と一行のメモで返す。先輩は都合のよいときに写真を見て、一言（「ここのはんだは量が多い、次はもう少し少なく」など）と次の課題を返す。同じ時間に合わせる必要はない。

**主要な構成要素**:

- **課題を出す** — 先輩が、練習課題を一行で書き、必要な部品と道具、目安の時間を添える。よくある課題の一覧から選ぶこともできる
- **結果を返す** — 若手が、試した結果を写真と一行のメモで返す。うまくいかなかったことも書く
- **一言を返す** — 先輩が写真を見て、一言の助言を返す。よかった点を一つ、次に気をつける点を一つ、選択式と一行で返せる
- **次の課題** — 先輩が、一言と一緒に次の課題を出す。課題が少しずつ難しくなる
- **日記の一覧** — 課題、結果、一言が日記のように並ぶ。若手は自分の上達を振り返れる

## User Stories

- **US-001 何を試せばよいかわからず、結果も判断できない問題**
  利用者（Bさん）は、先輩から練習課題をもらい、試した結果に一言をもらいたい。それにより、適当に試して良いのか悪いのかわからない状態を変えたい。
  背景: 現状は練習の課題も結果の判断もなく、一人で試して不安になる。先輩に見てもらいたくても、忙しそうで声をかけられない。

- **US-002 若手の練習を見たいが時間が合わない問題**
  利用者（先輩）は、自分の都合のよい時間に、若手の練習を見て助言したい。それにより、決まった時間を取らなくても若手を支えたい。
  背景: 現状は若手の練習を見るには同じ時間に隣にいる必要があり、忙しくて時間が取れない。

## Open Questions

- 写真だけで、先輩がはんだ付けなどの出来を判断できるか
- 先輩が3日以内に一言を返せるか。返事が遅れると、若手の練習が止まる
- 課題の難しさの上げ方を、先輩がどう判断するか
- **モックで確かめたいこと**: 若手が写真と一行で結果を返し、先輩が選択式で一言を返す往復が、それぞれ数分で済むか
- **モックで確かめたいこと**: 日記の一覧で課題と結果と一言が並んでいるのを見て、若手が自分の上達を感じられるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **先輩の返事の遅れ** — 先輩が忙しい → 一言が返ってこない → 若手の練習が止まる。軽減: 3日たっても返事がないときは、先輩に軽く知らせる
- **写真の限界** — 写真では細かい出来がわからない → 先輩が判断できない → 助言が曖昧になる。軽減: 写真の撮り方の例（近づいて、斜めから）を示す
- **安全上の事故** — 一人で練習する → はんだごてや電源で事故が起きる → 怪我をする。軽減: 課題ごとに安全上の注意を表示し、電源を使う課題は先輩の付き添いを条件にする
- **評価への転用** — 日記が記録される → 評価に使われる → 若手が失敗を書かなくなる。軽減: 日記は2人だけが見られる設定にする
