# PRD: 上司が1on1で部下の「やりたいこと」を引き出し、業務とつなげる質問カード（A3xB1-2）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A3×B1（適切なコミュニケーション方法がわからない × やりたいものづくりができない）の版2。方向性は「2人の間をつなぐ（コミュニケーション設計）」。版1は本人の提案の組み立て、版3は部署の公式な提案の場を扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門の業務の多くは会議資料のパワーポイント作成で、実際に手を動かして作る機会は少ない。

部門では月に一度、上司と部下の1on1がある。しかし1on1の話題は、進捗の確認や業務の相談が中心で、**部下が「やりたいこと」を出す流れになっていない**。部下は、1on1でキャリアの希望を言ってよいのか、どう切り出せばよいのかがわからない。上司は、部下に希望があるなら言ってくるだろうと思い、自分から聞かない。お互いに、相手が切り出すのを待っている。

**誤解の実態**: Bさんは、課長との1on1で毎月、進捗を報告していた。手を動かす仕事がしたいという希望はずっとあったが、1on1でそれを言うのは場違いな気がして、言わなかった。代わりに忘年会の席で伝えたが、雑談として流された。課長は後で人事面談の記録を見て、Bさんがものづくりを希望していることを初めて知った。課長は「1on1で言ってくれればよかったのに」と思った。Aさんも、評価治具を自作したいという案を、1on1で言い出せずにいた。

**気づきの実態**: 1on1は、部下の希望を業務とつなげる最もよい場である。しかし、その場で希望を出す型がないので、部下は切り出し方がわからず、上司は聞き方がわからない。上司が「最近、やってみたいことはある？」と一言聞けば、部下は話しやすくなる。しかし上司も、部下の希望をどう業務につなげればよいかがわからないと、聞いたあとに困るので聞かない。

**練習機会の実態**: 1on1のやり方の研修は管理職向けにあるが、一般論で、「ものづくりの希望を業務につなげる」ような具体的な聞き方は扱わない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、対策として「コミュニケーションのローコンテキスト化」を掲げている。1on1で部下の希望が話題になった割合は、部門では測られていない。

## Goals / Non-Goals

**Goals**

- 1on1で、部下のやりたいことが話題になる（1on1のうち、質問カードが使われた割合を効果指標とする）
- 部下の希望が、具体的な業務の機会につながる（話題になった希望のうち、試しにやってみる仕事が決まった割合を効果指標とする）
- 部下が、希望を切り出しやすいと感じる（「1on1でやりたいことを話しやすい」の自己申告を効果指標とする）

**Non-Goals**

- 1on1全体の進め方の改革（1on1の一部の時間で質問カードを使うだけで、他の話題は変えない）
- 人事評価やキャリア面談の置き換え（希望を業務の小さな機会につなげることに限る）
- 本人の提案の組み立て（版1）、部署の提案の場（版3）の範囲

## Proposed Solution / Feature Description

上司と部下が1on1で使う**質問カード**を提供する。1on1の最後の5分で、上司がカードを1枚引き、部下に質問する。質問は「最近、手を動かしてやってみたいと思ったことは？」「いまの業務で、自分で作れたら楽になりそうなものは？」のように、希望を業務とつなげやすい形にしてある。部下は事前にカードの質問を見て、答えを考えておける。

**主要な構成要素**:

- **質問カード** — 希望を引き出す質問と、業務とつなげる質問を組にしたカード。上司は1枚を選んで聞く。毎回違うカードが出る
- **部下の事前準備** — 1on1の前日に、部下にその回のカードの質問を知らせる。部下は答えを考えておける。いきなり聞かれて答えに詰まることを防ぐ
- **小さな試しの決定** — 部下の答えから、試しにやってみる小さな仕事（業務の一部、短い期間）を一つ決める欄。決まらなければ、次回までに上司が考えることを書く
- **希望の記録** — 部下の答えと、決まった小さな試しを2人で記録する。次の1on1で、試しの結果を話す
- **上司の聞き方の例** — 部下の答えを聞いたあと、業務につなげる聞き方の例（「それを今の評価業務で使うとしたら？」）を上司に示す

## User Stories

- **US-001 1on1で希望を切り出せない問題**
  利用者（Bさん）は、1on1で、自分のやりたいことを話してよい時間がほしい。それにより、希望を雑談の席で伝えて流される事態を避けたい。
  背景: 現状は1on1で希望を出す型がなく、場違いな気がして言い出せない。希望は伝わらないまま、手を動かす機会のない業務が続く。

- **US-002 部下の希望を聞いても業務につなげられない問題**
  利用者（課長）は、部下の希望を聞いたときに、業務の小さな機会につなげる方法を知りたい。それにより、聞いたあとに困るから聞かない、という状態を変えたい。
  背景: 現状は部下の希望をどう業務に結びつければよいかがわからず、自分から聞かない。

## Open Questions

- 上司が毎回カードを使ってくれるか。1on1の時間が足りない月に省かれないか
- 部下の希望が業務とつながらない場合、どう扱うか
- **モックで確かめたいこと**: 部下が事前にカードの質問を見て、答えを考えるのが負担にならないか
- **モックで確かめたいこと**: 上司がカードと聞き方の例を見て、部下の答えから小さな試しを決められるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **形式的な質問** — 上司がカードを読み上げるだけ → 部下が型通りに答える → 本音が出ない。軽減: 聞き方の例で、答えを掘り下げる質問を示す
- **希望の押し付け** — やりたいことがない部下に答えを求める → 部下が困る → 1on1が負担になる。軽減: 「今はない」も答えとして受け入れることをカードに明記する
- **小さな試しが実行されない** — 決めたのに業務に追われる → 試しが流れる → 部下が失望する。軽減: 次の1on1で必ず試しの結果を話す流れにする
- **評価への転用** — 希望の記録が人事評価に使われる → 部下が正直に答えなくなる → 本来の目的を失う。軽減: 記録は2人だけが見られる設定にする
