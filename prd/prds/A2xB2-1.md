# PRD: 「知っていて当然」とされる前提知識を自分で見つけて順に埋める前提チェックリスト（A2xB2-1）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A2×B2（暗黙の期待・ルールがわからない × ハードウェアの知識が足りず焦る）の版1。方向性は「当事者の行動を支える（個人向けツール）」。版2は新人と先輩の間、版3は部署の暗黙知の文書化を扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門は機械系の社員が多く、社内規格や図面の読み方、部門独自の略語が前提として会話が進む。

部門には、**「知っていて当然」とされている知識**がある。図面の公差の書き方、社内規格の番号の意味、「DR」「QA」「ES」のような略語、試作の段階の呼び方などである。誰も教えないが、知らないと会話についていけない。2人は、自分が何を知らないのかがわからないため、何から学べばよいかも決められず、焦りだけが増えていく。

**誤解の実態**: Bさんは設計会議で「この部品はES品だから、DR2までに差し替えて」と言われた。ES品（評価用の試作品）もDR2（2回目の設計審査）も知らなかったが、周りが当然のように話していたので聞けなかった。会議のあとに一人で調べたが、社内の略語だったため検索しても出てこなかった。差し替えの期限を取り違え、1週間遅れで対応することになった。Aさんも、図面の「一般公差は社内規格による」という注記の意味がわからず、規格書を探すのに半日を使った。

**気づきの実態**: 2人とも、わからない言葉に出会った瞬間には気づいている。しかし、それを記録せず、その場をやり過ごす。後で調べようと思っても、忘れるか、調べ方がわからない。わからないことが一つずつ積み重なり、「自分は何もわかっていない」という漠然とした焦りになる。焦りが大きくなるほど、何から手をつければよいかが見えなくなる。

**練習機会の実態**: 新人研修では会社の概要と安全教育を受けたが、部門ごとの略語や規格は扱わなかった。他分野から来た人や中途入社の人は、新人研修の対象からも外れる。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。配属後に前提知識を身につけるまでの期間は、部門では測られていない。

## Goals / Non-Goals

**Goals**

- わからない言葉をその場で記録し、後で解消できる（記録した言葉のうち、1週間以内に意味がわかった割合を効果指標とする）
- 前提知識の取り違えによる手戻りが減る（略語や規格の取り違えで対応が遅れた件数の自己申告を効果指標とする）
- 漠然とした焦りが、具体的な「次に学ぶこと」に変わる（「次に何を学ぶべきかわかっている」の自己申告を効果指標とする）

**Non-Goals**

- 部門の用語集の作成（部門全体の文書化は版3の範囲。本書は本人の手元の記録に限る）
- ハードウェアの体系的な教育（既存の教科書と研修の領域）
- 先輩に質問する仕組み（版2の範囲）

## Proposed Solution / Feature Description

会議や資料でわからない言葉に出会ったら、**その場で一語だけ記録し、あとで「どこで調べるか・誰に聞くか」を決めて埋めていく**個人向けWebツールを提供する。記録した言葉は分類（略語／規格／図面／工程）ごとに並び、自分の知らない前提の地図になる。焦りを、埋めるべき項目の一覧に置き換える。

**主要な構成要素**:

- **その場の一語記録** — 会議中でも数秒で書けるように、言葉と、出てきた場面（会議名や資料名）だけを記録する
- **分類と調べ先** — あとで、記録した言葉を分類し、「社内規格書」「部門の共有フォルダ」「先輩に聞く」のどれで調べるかを決める。分類ごとに、よく使われる調べ先を候補として示す
- **意味のメモ** — わかった意味を自分の言葉で一行で書く。書けたら、その言葉は「わかった」に移る
- **前提の地図** — 分類ごとに、わかった言葉とまだの言葉を並べる。まだの言葉が多い分類が、次に学ぶ範囲になる
- **よく出る言葉の印** — 何度も記録された言葉に印を付ける。何度も出る言葉ほど優先して埋めるよう示す

## User Stories

- **US-001 会議の略語がわからず期限を取り違える問題**
  利用者（Bさん）は、会議でわからない略語に出会ったら、その場で記録して後で確実に意味を知りたい。それにより、意味を取り違えたまま作業して対応が遅れる事態を避けたい。
  背景: 現状はわからない言葉をその場でやり過ごし、後で調べようとして忘れる。取り違えは作業の期限で結果として現れ、そのときには遅れが確定している。

- **US-002 何を知らないのかがわからず焦る問題**
  利用者（Aさん）は、自分が知らない前提知識を一覧で見たい。それにより、漠然とした焦りではなく、次に学ぶことを決めて動きたい。
  背景: 現状はわからないことが積み重なり、何から手をつければよいかが見えなくなっている。

## Open Questions

- 会議中に記録する余裕があるか。手元のスマートフォンで数秒で書けることが前提になる
- 調べ先の候補が、本人の部門の実態に合うか。社内規格書の置き場所は部門ごとに違う
- **モックで確かめたいこと**: 会議中の一語記録が、話を聞きながら数秒で終えられるか
- **モックで確かめたいこと**: 前提の地図を見たとき、「まだの言葉の多さ」に焦るのではなく、「次に埋める範囲」が見えると感じられるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **記録が溜まるだけ** — 記録はするが調べない → まだの言葉が増え続ける → かえって焦りが増す。軽減: 1週間たった言葉に印を付け、先輩に聞く候補として示す
- **一人で抱え込む** — 調べることを一人でやる → 社内の略語は検索しても出ない → 時間を無駄にする。軽減: 社内の略語は「先輩に聞く」を初期の調べ先にし、版2と組み合わせる
- **教材との誤認** — 学習ツールに見える → eラーニングと比べられる → 差別性を失う。回避: 教材を持たず、本人が出会った言葉だけを扱う
- **会議中の操作が失礼に見える** — 会議中にスマートフォンを触る → 話を聞いていないと思われる → 本人が気まずくなる。軽減: 紙のメモから後でまとめて入力する使い方も示す
