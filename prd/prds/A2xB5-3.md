# PRD: 試作室の使い方ルールを入口の画面で明文化し、予約なしで試せる「お試し枠」を設ける試作室の運用改善（A2xB5-3）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A2×B5（暗黙の期待・ルールがわからない × 気軽に試して失敗できる場所がない）の版3。方向性は「場・仕組みを変える（チーム／組織向け）」。版1は個人の初回利用ナビ、版2は先輩の初回付き添いを扱う。

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門には試作室があり、はんだ付けの設備、オシロスコープ、恒温槽などが置かれている。

試作室の運用は、**常連の人たちの暗黙の了解で回っている**。予約は紙の予約表、恒温槽は前日に一声、昼休みは常連の先輩が使う。このやり方は、試作室を毎日使う人たちには便利だが、たまにしか来ない人や新しく来た人には見えない。さらに、予約表は数日先まで埋まっていることが多く、「ちょっと試したい」ときに使える時間がない。結果として、試作室は常連のための場所になり、若手が気軽に試す場所にはなっていない。

**誤解の実態**: Bさんは恒温槽を使おうとして、前日の一声を知らずに注意された。Aさんはオシロスコープの設定を戻さずに苦情を受けた。別の若手は、予約表が埋まっているのを見て、試作室を使うのをあきらめた。実際には、予約された時間の多くは常連の人が「念のため」押さえたもので、使われていない時間も多かった。部門長は「若手が試作室に来ない」と感じていたが、原因は運用にあった。

**気づきの実態**: 問題は個人がルールを知らないことだけではない。**ルールが暗黙のままで、しかも気軽に使える時間がない**という運用の問題である。ルールを入口に書けば、外して注意されることは減る。予約なしで使える時間を設ければ、「ちょっと試したい」ときに使える。

**練習機会の実態**: 試作室の入口には安全上の注意書きだけがある。予約表は紙で、使われなかった予約は記録されない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げ、職場側の「ローコンテキスト化」を対策に掲げている。試作室の予約のうち、実際に使われた割合は測られていない。

## Goals / Non-Goals

**Goals**

- 試作室のルールを外して注意される件数が減る（試作室の使い方についての注意の件数を効果指標とする）
- 若手が気軽に試作室を使える時間が増える（お試し枠の利用件数を効果指標とする）
- 予約が実際に使われる割合が上がる（予約のうち、実際に使われた割合を効果指標とする）

**Non-Goals**

- 試作室の設備の追加購入（今ある設備の使い方を変える）
- 常連の利用の制限（常連の人の利用を減らすのではなく、使われない予約を減らす）
- 個人の利用状況の評価（誰がどれだけ使ったかを評価に使わない）
- 個人の初回利用ナビ（版1）、先輩の付き添い（版2）の範囲

## Proposed Solution / Feature Description

試作室の**入口にタブレットを置き、設備ごとの使い方のルールと予約状況を表示する**仕組みを提供する。ルールは常連の人たちと一緒に書き出して明文化する。あわせて、週に数時間の**お試し枠**（予約なしで、30分以内なら誰でも使える時間帯）を設ける。使われない予約は、開始時刻から15分たつと自動で解放する。

**主要な構成要素**:

- **入口のルール表示** — 設備ごとに、予約の方法、事前の一声が必要な場合、使ったあとの片付けを表示する。タブレットで設備を選ぶと、その設備のルールが出る
- **ルールの書き出し** — 常連の人たちが、試作室の暗黙のルールを書き出す。書き出したルールは、理由を一行添えて入口の表示に載る
- **電子予約** — 紙の予約表をタブレットとWebの予約に置き換える。予約の開始から15分たっても「使い始め」が押されなければ、自動で解放する
- **お試し枠** — 週に数時間、予約なしで30分以内なら誰でも使える時間帯を設ける。お試し枠の時間帯は入口に表示する
- **運用の振り返り** — 一か月ごとに、予約の使用率、お試し枠の利用件数、注意の件数を部門に返す。個人別には出さない

## User Stories

- **US-001 試作室のルールを外して初めて知る問題**
  利用者（Bさん）は、試作室の入口で、使いたい設備のルールを確かめたい。それにより、前日の一声を知らずに注意され、試作室に入れなくなる事態を避けたい。
  背景: 現状はルールが常連の人の暗黙の了解で、新しく来た人には見えない。

- **US-002 ちょっと試したいときに使える時間がない問題**
  利用者（Aさん）は、予約表が埋まっていても、短い時間なら気軽に試せる時間がほしい。それにより、「ちょっと試したい」ことをあきらめずに済ませたい。
  背景: 現状は予約表が数日先まで埋まり、実際には使われない時間も多いのに、若手には使える時間がない。

- **US-003 若手が試作室に来ない原因がわからない問題**
  利用者（部門長）は、試作室の使われ方を数字で知りたい。それにより、若手が来ない原因が運用にあるのかを確かめたい。
  背景: 現状は紙の予約表で、使われなかった予約が記録されない。

## Open Questions

- 常連の人たちが、予約の自動解放を受け入れるか。「念のため」の予約ができなくなることに反発しないか
- お試し枠の時間帯をいつにするか。常連の人の利用と重ならない時間帯で、若手が使いやすい時間はあるか
- 入口のタブレットの設置と管理を誰が行うか
- **モックで確かめたいこと**: 入口のタブレットで設備を選んで、ルールと予約状況がひと目でわかるか
- **モックで確かめたいこと**: お試し枠の表示を見て、若手が「今なら使える」と気軽に入れるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **常連の反発** — 自動解放で予約が消える → 常連の人が不満を持つ → 運用が止まる。軽減: 解放までの時間を常連の人と相談して決め、試験中の設備は除外できるようにする
- **お試し枠の空洞化** — お試し枠を設けても若手が来ない → 枠が使われない → 常連の人に戻される。軽減: 版2の付き添いと組み合わせ、お試し枠で付き添いを行う
- **ルールの古さ** — 書き出したルールが更新されない → 実態と合わなくなる → 外す人が出る。軽減: ルールに最終更新日を表示し、注意が出たらルールを見直す
- **特定の人のための運用と見られる** — 若手への配慮に見える → 常連の人が面倒がる → 協力が得られない。回避: 予約の使用率を上げる運用改善として、部門全員に説明する
