# PRD: 「いいね、そのうちね」を読み解いて次の一手を決める返事ノート（A1xB1-1）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A1×B1（相手の真意がわからない × やりたいものづくりができない）の版1。方向性は「当事者の行動を支える（個人向けツール）」。版2は提案者と承認者の間、版3はチームの制度を扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門の業務の多くは会議資料のパワーポイント作成で、実際に手を動かして作る機会は少ない。

2人はどちらも、ものづくりの仕事をしたいと上司に伝えている。しかし、**返ってきた言葉が「許可」なのか「やんわりとした断り」なのかを読み分けられない**。そのため、待つべきか、別の手を打つべきかを決められないまま時間が過ぎる。

**誤解の実態**: Bさんは課長に「試作基板の評価を自分でやってみたい」と申し出た。課長は「いいね、落ち着いたらやろうか」と答えた。Bさんはこれを許可と受け取り、資料作成の合間に評価手順を調べて待った。3か月たっても声はかからず、評価は外部の協力会社に発注された。Aさんも同じ時期に小さな治具の改善を提案し、「前向きに考えておくよ」と言われて待っていた。2人とも、待った期間と準備した手順書が無駄になった。

**気づきの実態**: 課長の返事には、本当に忙しいだけの場合と、予算や担当の都合で実質的に難しい場合がある。言葉だけでは区別できない。しかし、「いつ頃か」「何があれば進められるか」をその場で一言確かめれば、どちらかはわかる。2人ともその一言を出す発想がなく、出すとしても失礼にならない言い方を知らない。

**練習機会の実態**: 上司の返事の読み方を教える研修はない。同僚に聞けば教えてもらえるが、自分のキャリアの希望に関わる話なので相談しにくい。読み違えに気づくのは数か月後で、そのときには機会が別の人や外注に移っている。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。若手技術者が希望の業務に就けないことによる離職は、社内では測られていない。

## Goals / Non-Goals

**Goals**

- 曖昧な返事のまま待ち続ける期間が短くなる（返事を受けてから、確認の一言を出すまでの日数を効果指標とする）
- ものづくりの機会につながる次の一手を、本人が自分で選べるようになる（返事ごとに記録された「次の一手」のうち、実際に実行したものの割合を効果指標とする）
- 返事の読み方の幅を知る（設問で示した返事の解釈候補のうち、本人が事前に想定できていた数を効果指標とする）

（上司の判断そのものは変えられない。変えられるのは、待つか動くかを早く決めることである。一つめを中心に置く）

**Non-Goals**

- 上司の本心の断定（言葉から本心は確定できず、断定すれば誤った確信を与える）
- 上司への働きかけの代行（ツールが代わりに連絡すると、本人の関係づくりにならない）
- 転職・異動の勧め（キャリアの判断は本人のもので、ツールの役割を超える）
- 提案と承認の仕組みづくり（版2・版3の範囲）

## Proposed Solution / Feature Description

上司や先輩から受けた返事を記録すると、**先に自分で「許可／保留／断り」のどれに近いかを選ばせ、そのあとで解釈の幅と、確かめるための一言を返す**個人向けWebツールを提供する。さらに、返事が保留や断りに近い場合でも、ものづくりに近づくための**縮小版の次の一手**（規模を小さくした提案、業務時間外の練習など）を本人に選ばせる。

**主要な構成要素**:

- **返事の記録** — 誰に何を頼み、どんな言葉が返ってきたかを書く。そのときの相手の様子（すぐ答えた／間があった／話題を変えた）も選ぶ
- **自分の読み** — 解説を見る前に、本人が「許可／保留／断り」のどれに近いと思うかと、その理由を選ぶ。先に解説を見せると、読む練習にならない
- **解釈の幅** — 同じ言葉が職場でどんな意味になりうるかを、候補と手がかりで示す。一つに決めず、何がわかれば絞れるかを示す
- **確かめる一言** — 「いつ頃に、何がそろっていれば進められそうでしょうか」のように、相手を問い詰めずに意味を確かめる一言の候補を出し、本人に選ばせて自分の言葉に直させる
- **縮小版の次の一手** — 断りや保留に近い場合に、規模を小さくした提案（評価の一部だけ担当する、既存品の分解調査をする）を候補として出す。本人が選んだ一手には期日を付ける
- **返事の振り返り** — 記録した返事が、後で実際にどうなったかを書く。自分の読みが当たった型と外れた型を返す

## User Stories

- **US-001 「そのうちね」を許可と受け取って待ち続ける問題**
  利用者（Bさん）は、上司の曖昧な返事が許可なのか断りなのかを、その場で確かめる一言を持ちたい。それにより、数か月待ったあとで機会が外注に移っていたと知る事態を避けたい。
  背景: 現状は返事を許可と受け取って待ち、準備も進める。読み違えに気づくのは機会が別の人に移ったあとで、そのときには待った期間と準備がすでに無駄になっている。

- **US-002 断られたあとに打つ手がない問題**
  利用者（Aさん）は、提案が実質的に断られたとわかったとき、ものづくりに近づくための別の一手を選びたい。それにより、断られたことで希望そのものをあきらめずに済ませたい。
  背景: 現状は断りに気づいても次の手を思いつかず、資料作成だけの業務に戻る。

## Open Questions

- 解釈の幅の候補を何に基づいて作るか。職場ごとに言葉の使い方が違うため、一般的な候補が本人の職場に合わないことがある
- 上司の言葉を記録することに、本人が後ろめたさを感じないか。相手の言葉を残す行為が、相手を疑うことに感じられるかもしれない
- 縮小版の次の一手の候補を、職種ごとにどこまで用意できるか
- **モックで確かめたいこと**: 先に自分の読みを選ばせてから解釈の幅を見せる順序が、もどかしさより納得感を生むか
- **モックで確かめたいこと**: 確かめる一言の候補を見て、本人が実際に上司に言えそうだと感じられるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **上司を疑う道具になる** — 返事を分析する → 上司の言葉をすべて裏読みする → 関係が悪くなる。軽減: 解釈の幅は「確かめるための材料」として示し、断定しない
- **記録の負担** — 返事のたびに書く → 面倒になる → 使われなくなる。軽減: 返事の言葉と様子の選択だけで記録できる最短の入力にする
- **縮小案が本人の希望とずれる** — 小さい一手ばかり勧める → 本当にやりたいことから遠ざかる → 意欲が下がる。軽減: 次の一手は本人が選び、勧める候補に順位を付けない
- **文化的な単純化** — 「日本の上司は遠回しに断る」と一般化する → 上司個人の実態と合わない → 偏見を強める。軽減: 振り返りから本人の上司の傾向を学び、固定の対応表を中心にしない
