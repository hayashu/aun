# PRD: 各分野が「他分野の人に知ってほしい10のこと」を月1回15分で話す、海外拠点も参加できる分野横断の入門会（A5xB4-3）

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）は、電気・機械の両チームにまたがるプロジェクトの調整役を担当している。同じプロジェクトには、電気電子出身で入社3年目のBさん（20代後半）がいる。Bさんの部署は機械系の社員が多い。

部門の中で、分野の違う人どうしは**互いの分野の基本を学ぶ場がない**。電気の人は機械の基本を知らず、機械の人は電気の基本を知らない。だから分野をまたぐ会議では、互いの専門用語が通じず、話が噛み合わない。一人で別分野の教科書を読むのは大変で、何が大事なのかもわからない。互いの分野の人から、本当に大事なことだけを教わる場があれば、会話の土台ができる。Bさんは、異なる背景を持つ人の話を聞くのが好きで、そうした場には自然と参加したいと思っている。

**誤解の実態**: Bさんは設計会議で、機械チームの「ボスの肉厚」「ドラフト角」の話についていけなかった。一方、機械チームは、Bさんの「コモンモードノイズ」「リターンパス」の話についていけなかった。互いに相手の分野の教科書を読もうとしたが、どこが大事なのかわからず、途中でやめた。もし機械の人が「電気の人に知ってほしい機械の10のこと」を、電気の人が「機械の人に知ってほしい電気の10のこと」を、それぞれ15分で話してくれれば、互いの会話の土台になったはずである。

**気づきの実態**: 問題は個人の努力ではなく、**分野の違う人どうしが互いの基本を学ぶ場が、部門に組み込まれていない**ことである。各分野の人が、他分野の人に本当に知ってほしいことを絞って話す場があれば、会話の土台が部門全体にできる。海外拠点の技術者も同じ問題を抱えており、オンラインで参加できれば、拠点をまたいだ土台にもなる。

**練習機会の実態**: 部門の勉強会は分野ごとに分かれており、他分野の人が参加する場はない。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げ、職場側の「ローコンテキスト化」を対策に掲げている。分野をまたぐ会議で専門用語が通じずに話が進まない状況は測られていない。

## Goals / Non-Goals

**Goals**

- 分野の違う人どうしが、互いの分野の基本を学べる（入門会の参加者数と、参加者の分野の多様さを効果指標とする）
- 分野をまたぐ会議で、専門用語が通じやすくなる（「別分野の人の話についていける」の自己申告を効果指標とする）
- 拠点をまたいだ技術者どうしの交流が生まれる（海外拠点からの参加者数を効果指標とする）

**Non-Goals**

- 体系的な研修の置き換え（入門会は基本を絞って紹介する場で、研修ではない）
- 参加の義務化（参加は自由とする）
- 一人の説明ドリル（版1）、説明練習ペア（版2）の範囲

## Proposed Solution / Feature Description

部門で**月に1回、30分の「分野横断の入門会」**を開き、その運営をWebで支える仕組みを提供する。毎回一つの分野が担当し、その分野の人が「他分野の人に知ってほしい10のこと」を15分で話す。残りの15分は質問の時間。オンラインで参加でき、海外拠点の技術者も参加できる。話した内容は、10のことの一覧として残し、後から読める。

**主要な構成要素**:

- **担当分野の予定** — 月ごとの担当分野（機械、電気、ソフト、品質、生産技術など）と日時を一覧にする
- **10のことの準備** — 担当の分野の人が、「他分野の人に知ってほしい10のこと」を一行ずつ書く。他分野の人から「これを知りたい」を事前に募り、参考にする
- **事前の質問** — 参加者が、事前に担当分野への質問を書ける。匿名でも書ける
- **当日の進行** — 15分で10のことを話し、15分で質問に答える。オンライン参加者の質問も受け付ける
- **10のことの一覧** — 各回の10のことを、分野ごとに一覧で残す。分野をまたぐ会議の前に見返せる
- **言語の配慮** — 海外拠点の参加者向けに、10のことの一覧を英語でも用意する。第2段階に置き、現時点のプロトタイプには入っていない

## User Stories

- **US-001 別分野の基本がわからず会議についていけない問題**
  利用者（Bさん）は、機械の人から、電気の人に知ってほしい機械の基本を教わりたい。それにより、設計会議で機械の話についていけるようになりたい。
  背景: 現状は別分野の教科書を一人で読んでも何が大事かわからず、会議で話が噛み合わない。

- **US-002 他分野の人に自分の分野の基本を伝える場がない問題**
  利用者（機械の担当者）は、電気の人に、機械の基本を絞って伝えたい。それにより、会議で毎回同じ説明をしなくて済むようにしたい。
  背景: 現状は別分野の人に基本を伝える場がなく、会議のたびに説明が必要になる。

- **US-003 拠点をまたいだ技術者どうしがつながらない問題**
  利用者（海外拠点の技術者）は、日本の拠点の各分野の基本を学び、技術者とつながりたい。それにより、拠点をまたいだ仕事を進めやすくしたい。
  背景: 現状は拠点をまたいで学ぶ場がない。

## Open Questions

- 担当の分野の人が、「10のこと」の準備に時間を使ってくれるか
- 海外拠点との時差がある場合、開催の時間をどうするか
- 10のことの選び方が、話す人によって偏らないか
- **モックで確かめたいこと**: 担当分野の予定と10のことの一覧を見て、別分野の人が「参加してみたい」と思えるか
- **モックで確かめたいこと**: 事前に「これを知りたい」を募る画面で、担当分野の人が10のことを選びやすくなるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **担当者が見つからない** — 準備の負担が大きい → 担当を引き受ける人がいない → 入門会が開けない。軽減: 10のことは一行ずつでよく、スライドは不要とする
- **参加者が集まらない** — 業務が忙しい → 参加しない → 会が成り立たない。軽減: 30分に限り、オンラインでも参加できるようにし、録画を後から見られるようにする
- **内容の偏り** — 話す人の得意な内容に偏る → 他分野の人が知りたいことと合わない → 役に立たない。軽減: 事前に「これを知りたい」を募り、担当者に示す
- **言語の壁** — 海外拠点の参加者が日本語の話についていけない → 参加しなくなる → 拠点をまたいだ交流が生まれない。軽減: 10のことの一覧を英語でも用意する（第2段階）
