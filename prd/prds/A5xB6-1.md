# PRD: 抽象的な問いに具体例を出し、具体例の束から共通点を言う往復を一人で練習する往復ドリル（A5xB6-1）

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）は、電気・機械の両チームにまたがる製品改良プロジェクトの調整役を担当している。同じプロジェクトには、電気電子出身で入社3年目のBさん（20代後半）がいる。2人の上司の課長は、方針や考え方を抽象的な言葉で語ることを好む。

2人は、**抽象と具体を行き来する力を、失敗しても困らない場所で練習する機会がない**。Bさんは、具体的な事実を積み上げるのは得意だが、「つまり何か」を言うのが苦手で、抽象的な問いに具体例を出すのにも時間がかかる。Aさんは、日本語の抽象的な言葉の幅をつかみきれず、具体例に降ろすときに迷う。練習の場は実際の会議や上司との会話しかなく、そこで失敗すると評価に響きそうで、試すことができない。

**誤解の実態**: Bさんは課長との会話で「君にとって良い設計って何？」と聞かれ、言葉に詰まった。頭の中には、過去に良いと感じた設計の例がいくつもあったが、それを「つまり、こういうことです」とまとめられなかった。逆に、試作の報告で「結局、この3つの不具合に共通するのは？」と聞かれても、すぐに答えられなかった。Bさんは、自分が抽象と具体の行き来が苦手だと自覚していたが、練習の仕方がわからなかった。Aさんも、課長の「本質」「筋」といった言葉の具体例を、その場で思い浮かべられずにいた。

**気づきの実態**: 抽象と具体の行き来は、短い問題を繰り返せば慣れる。「『使いやすい』の具体例を3つ」（下げる）、「『部品点数削減』『配線短縮』『ネジの共通化』に共通するのは？」（上げる）のような問いを、1問1分で解けばよい。正解は一つではなく、自分の答えと他の答え方の例を比べることで、幅がつかめる。しかし、そうした練習の素材は職場にない。

**練習機会の実態**: 論理的思考の本には練習問題があるが、題材がビジネス一般で、ものづくりの現場の言葉ではない。上司に練習相手を頼むのは気が引ける。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げ、職場側の「ローコンテキスト化」を対策に掲げている。抽象と具体の行き来を練習する機会の有無は、部門では把握されていない。

## Goals / Non-Goals

**Goals**

- 抽象と具体を行き来する練習を、失敗を気にせず続けられる（週に解いた問題の数と、続けた週の数を効果指標とする）
- 上げる問い・下げる問いに答えるまでの時間が短くなる（1問にかかった時間の推移を効果指標とする）
- 実際の会話で詰まる場面が減る（「つまり？」「たとえば？」と聞かれて詰まった回数の自己申告を効果指標とする）

**Non-Goals**

- 正解の判定・採点（答えは一つではない。点数を付けると、正解探しになって幅がつかめない）
- 実際の会話の分析（扱うのは練習の問題で、本人の会話は記録しない）
- 2人の練習（版2）、部署のワークショップ（版3）の範囲

## Proposed Solution / Feature Description

一人で使う**往復ドリル**をWebで提供する。ものづくりの現場の言葉を使った短い問いを、「下げる（抽象→具体）」と「上げる（具体→抽象）」の2種類で出す。本人が答えを書いたあと、他の答え方の例を3つ見せ、自分の答えとの違いを本人に見つけさせる。点数は付けない。

**主要な構成要素**:

- **下げる問い** — 「『量産しやすい設計』の具体例を3つ書いてください」のように、抽象的な言葉から具体例を出す問い。1問1分の目安を示す
- **上げる問い** — 「『部品点数を減らす』『配線を短くする』『ネジを共通にする』に共通することを一言で」のように、具体例の束から抽象の一言を出す問い
- **答え方の例** — 本人が答えたあとに、他の答え方の例を3つ見せる。例は「正解」ではなく「こういう答え方もある」として示す。本人の答えと例の違い（高さが違う、観点が違う）を、本人が選んで記録する
- **自分の言葉の帳面** — 課長の口癖など、実際に詰まった言葉を本人が足し、自分用の下げる問いにできる
- **続けた記録** — 解いた問題の数と、1問にかかった時間の推移だけを本人に返す

## User Stories

- **US-001 「つまり？」と聞かれて詰まる問題**
  利用者（Bさん）は、具体例の束から共通点を言う練習を、失敗しても困らない場所で繰り返したい。それにより、課長に「共通するのは？」と聞かれたときに詰まらないようにしたい。
  背景: 現状は練習の場が実際の会話しかなく、失敗すると評価に響きそうで試せない。

- **US-002 抽象的な言葉の具体例を思い浮かべられない問題**
  利用者（Aさん）は、日本語の抽象的な言葉に、いくつもの具体例を出す練習をしたい。それにより、課長の「本質」「筋」といった言葉の幅をつかみたい。
  背景: 現状は抽象的な言葉の具体例を、その場で思い浮かべられない。

## Open Questions

- ものづくりの現場の言葉を使った問題を、誰が作るか。最初の問題の質がドリルの信頼性を左右する
- 答え方の例を見たとき、本人が「自分の答えは間違い」と感じないか
- 一人の練習を続ける動機をどう保つか
- **モックで確かめたいこと**: 上げる問い・下げる問いを1問1分で解き、答え方の例と比べる流れが、昼休みの5分で数問できる長さに収まるか
- **モックで確かめたいこと**: 答え方の例を見たとき、本人が「正解と違った」ではなく「こういう高さもある」と受け取れるか

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **正解探し** — 答え方の例を正解と受け取る → 例をまねるようになる → 幅がつかめない。軽減: 例は高さや観点の違う3つを並べ、どれも「答え方の一つ」と示す
- **続かない** — 一人の練習は飽きる → 数日で止まる → 効果が出ない。軽減: 自分の言葉の帳面で、実際に詰まった言葉を問題にできるようにし、練習と仕事をつなぐ
- **現場とのずれ** — ドリルの問題が実際の会話と違う → 練習しても会話で使えない。軽減: 部署の言葉を問題に足せるようにする
