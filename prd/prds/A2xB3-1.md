# PRD: 「どこまでやれば完了か」を先に書き出し、相談の区切りを組み込む完了条件プランナー（A2xB3-1）

版: v1（2026-11-22） / 形式: Alpha+ PRD 101（Slide 27 テンプレート順）
※ セル A2×B3（暗黙の期待・ルールがわからない × 自分で進める道筋を作れない）の版1。方向性は「当事者の行動を支える（個人向けツール）」。版2は上司との週次の期待合わせ、版3はチームの進め方の明文化を扱う。A1×B3（依頼の言葉に隠れた期限）とは異なり、本セルは「完了の基準」と「相談のタイミング」という進め方の暗黙ルールを扱う。

---

## Overview / Problem Statement

日本の製造業A社で、外国籍社員のAさん（30代、日本での滞在10年、JLPT N1保持）と、電気電子出身で入社3年目のBさん（20代後半）は、同じ製品開発部門で働いている。部門ではマイルストーンを決めずに仕事が渡されることが多く、進め方は担当者に任されている。

部門の仕事には、**完了の基準と相談のタイミングについての暗黙のルール**がある。調査なら「比較表と推奨案まで」、評価なら「測定条件と再現性の確認まで」が完了とされる。詰まったら「半日以上悩まずに聞く」、方向が決まったら「一度見せる」が当然とされる。どれも書かれておらず、2人は知らない。Bさんはさらに、区切りを自分で作って進めるのが苦手で、完了がわからないまま延々と続けてしまう。

**誤解の実態**: Bさんは「新しい電源ICの候補を調べて」と頼まれた。どこまで調べれば終わりなのかわからず、候補を20個集め、それぞれのデータシートを読み込んだ。3週間たって課長に見せると、「3つに絞って推奨を付けてくれればよかった。もっと早く見せてほしかった」と言われた。Aさんは、評価で詰まったまま2日間一人で悩み、課長から「なんで早く言わなかったの」と言われた。2人とも、それが当然のルールだとは知らなかった。

**気づきの実態**: 完了の基準と相談のタイミングは、仕事の種類ごとにだいたい決まっている。2人がそれを知らないのは、誰も教えないからである。そして、知らないことに気づくのは、課長から指摘されたときだけである。指摘は仕事の最後に来るので、そのときには時間がすでに使われている。

**練習機会の実態**: タスク管理アプリは、自分で決めたタスクを並べるものであり、「この種類の仕事はどこまでやれば完了か」は教えてくれない。先輩に毎回聞くのは気が引ける。

**背景**: 経済産業省「高度外国人材研究会 報告書」（2024年7月26日）は、外国人材の職場への不満として「暗黙の了解が理解できない」を挙げている。完了の基準のずれによる過剰な作業や手戻りは、部門では測られていない。

## Goals / Non-Goals

**Goals**

- 完了の基準を超えて作業を続ける時間が減る（仕事の種類ごとに、最初の提出までにかかった日数を効果指標とする）
- 詰まったまま一人で悩む時間が減る（詰まってから相談するまでの時間の自己申告を効果指標とする）
- 仕事を自分で区切って進められる（仕事のうち、本人が最初に区切りを決めてから始めた割合を効果指標とする）

**Non-Goals**

- タスク管理ツールの置き換え（本人の仕事の始め方を支えるだけで、日々のタスク管理はしない）
- 唯一の完了基準の提示（部署や上司によって違い、候補として示す）
- 上司との期待合わせ（版2）、チームの進め方の明文化（版3）の範囲

## Proposed Solution / Feature Description

仕事を受けたら、仕事の種類（調査／評価／設計／資料）を選ぶと、**その種類で暗黙に期待されやすい「完了の基準」と「相談の区切り」を候補で示し、本人に選ばせて自分の計画にする**個人向けWebツールを提供する。計画には、「方向を見せる」「詰まったら聞く」の区切りが最初から組み込まれる。

**主要な構成要素**:

- **仕事の種類の選択** — 調査、評価、設計、資料などから選ぶ。種類によって、完了の基準と相談の区切りが違う
- **完了の基準の候補** — 選んだ種類に対して、「候補を3つに絞り、推奨を付ける」「測定条件と再現性を書く」のような完了の基準を候補で示す。本人は合うものを選び、足りないものを書き足す
- **相談の区切り** — 「方向が決まったら一度見せる」「半日以上詰まったら聞く」のような区切りを、計画に日付付きで組み込む
- **詰まり時計** — 作業中に「詰まった」ボタンを押すと時計が動き、決めた時間（例: 半日）がたつと「相談の時間です」と知らせる。相談の言い方の例も示す
- **基準の更新** — 仕事が終わったら、上司から言われたことをもとに、完了の基準を自分用に書き換える。次に同じ種類の仕事を受けたときは、書き換えた基準が出る

## User Stories

- **US-001 どこまでやれば完了かわからず作業を続ける問題**
  利用者（Bさん）は、調査の仕事を受けたときに、どこまでやれば完了なのかを最初に決めたい。それにより、候補を20個集めて3週間使い、「3つでよかった」と言われる事態を避けたい。
  背景: 現状は完了の基準を知らないまま始め、終わりがわからずに続ける。指摘は最後に来て、そのときには時間がすでに使われている。

- **US-002 詰まっても相談するタイミングがわからない問題**
  利用者（Aさん）は、詰まったときに、どれくらいで相談すべきかの目安を持ちたい。それにより、2日間一人で悩んで「早く言えばよかった」と言われる事態を避けたい。
  背景: 現状は相談のタイミングのルールを知らず、迷惑をかけたくないと一人で抱え込む。

## Open Questions

- 完了の基準の候補を、仕事の種類ごとにどこまで用意できるか。候補が的外れなら使われない
- 詰まり時計を押すこと自体を忘れないか
- **モックで確かめたいこと**: 仕事の種類を選んでから、完了の基準と相談の区切りを決めるまでが、仕事を受けた直後の3分で終わるか
- **モックで確かめたいこと**: 詰まり時計の「相談の時間です」の知らせを受けて、相談してよいと感じられるか（責められている感じがしないか）

## Risks（教材外補強 — PRD 101 に Risks の形式は無い）

- **候補の押し付け** — 一般的な完了の基準を示す → 本人の部署の基準と合わない → かえって外す。軽減: 候補は選択式にし、仕事が終わったら本人用に書き換えられるようにする
- **時計の圧迫感** — 詰まり時計が動く → 焦りが増す → 作業に集中できない。軽減: 時計は相談の目安として示し、時間を過ぎても責める表示にしない
- **計画で終わる** — 計画は作る → 区切りで相談しない → 行動が変わらない。軽減: 区切りの日に知らせ、相談の言い方の例を一緒に示す
- **文化的な単純化** — 「日本の職場では早く相談する」と一般化する → 上司個人の実態と合わない → 偏見を強める。軽減: 基準の更新で、本人の上司の傾向を学ぶ形にする
